# Atom Workbench：布居求解器交付说明

所有请求（`rb87-full/2`）只走一条路径：`rust-solver/population-core` 的折叠 Fourier 晶格。有限时间轨迹和长期平均在同一个晶格上求解，误差按收敛估计控制到 ε = 0.005（概率尺度的绝对误差，即 0.5%；固定值，每个请求都发送 `populationTolerance: 0.005`，不是用户设置），不会静默放宽。每个结果都带估计误差：所有输出都在 ε 内时为 `estimated-converged`，否则返回最好的检查点并标为 `estimated-partial`（附原因）；算出的结果从不扣下，只有什么可用的都没算出时才报 `not-converged`。物理模型由 TypeScript 构建；求解器不按失谐、流形或"禁戒"标签删除模型给出的任何耦合，也不依赖矩阵元恰好为零。

## 物理模型（`src/full-master-model.ts`）

输入模型在 32 态内部不做先验近似，取舍都交给求解器的误差估计；判断只看量级，不依赖恰好为零的矩阵元。没有任何激光被移出主方程。

- **所有激光都是显式驱动**：每束开启且强度非零的激光都耦合 D1、D2 全部允许电偶极跃迁，旋转项和反旋转项都保留（不作 RWA），不分近/远失谐，也没有按失谐拒绝的规则。激光的 `showLightShift`（检查器"能级图 · 显示光移"）只决定能级图背景是否画它的静态光移，不影响动力学，也不进入请求或缓存键。
- **旋转系与频率坐标**：激发态以参考光载频旋转，基态不旋转（统一光学旋转系）。参考光取 Rabi/(|失谐|+线宽) 最大的一束；这只是精确坐标的选择。旋转系由两处选定：这里的统一光学旋转系由 TypeScript 模型选取，求解核再把远离它的激发流形（例如 D2 参考光下约 7 THz 外的 D1 流形）各自换到自己的旋转系（见算法部分"各激发流形的旋转系"）；两处都是精确的坐标变换，不改变物理。激光间拍频沿用最小距离生成树；参考载频（约 3.8×10⁸ MHz）本身是一条声明的频率轴，所以反旋转项频率 ν_L+ν_ref = 2ν_ref+(ν_L−ν_ref) 是各轴的整数组合，不会把 768 THz 的相位舍入成拍频。完全相消的同频光（例如相位相反）不发送。
- **自发辐射**：每个光子球分量 q 一个塌缩算符，同时包含 D1、D2 两条线和两个基态 F 通道，幅度 d_eg·sqrt(Kω_eg³)（Born–Markov 形式，无 secular 近似）。在上述旋转系中它们是静态的，F=1/F=2、D1/D2 之间的交叉项在同一个塌缩算符内精确保留。按 D 线分开的算符等于在 7 THz 精细结构上做 secular 近似，会丢掉 D1/D2 干涉：852 nm 光镊的自旋翻转 Raman 率因此高估约 40 倍（见下）。
- **静态 H0**：磁场 + 每束光经 32 态以外能级（5S 的 6–9P；5P 的 6–10S、4–9D）的二阶（van Vleck）光移 + Rb⁺ 芯极化 −α|E|²/4（Arora & Sahoo, PRA 86, 033416 (2012) 表 II/IV/V：α_c = 9.1 au，5S 另有 α_vc = −0.26 au，5P 的 α_vc ≈ 0；数据源写在 `spectroscopy-data.ts`），见 `spectroscopy.ts` 的 `staticModelBackground`。这些耦合要求耦合/失谐比 ≤ 0.01、失谐 ≥ 10 GHz，否则模型拒绝构建。D 线的旋转与反旋转耦合全部是显式驱动，静态部分不含 D 线项，不重复计入。未包含更高价态尾项（5P 约 13 au，强烈依赖频率）和连续谱。
- **基矢**：主方程、初态和返回布居都在上述静态 H0 的本征基中；态标签 F、mF 指与之重叠最大的磁场本征态。D 线光学缀饰不进入基矢，而由动力学给出。能级图的显示基是磁场加打开"显示光移"的激光的全阶静态光移（见下文"静态光移"）。
- **初态**：`dynamics.initialState`（`state` / `unpolarized`(ground、F1、F2) / `thermal`(静态 H0 基态本征能量上的 Boltzmann 分布) / `weights`），在模型基中对角；求解器收到完整初始密度 `initialReal/initialImag`，结果附带 `initialState` 与 `initialPopulations`。缺省时等同 `{kind:'state', id: initialStateId}`；场景文件把 `state` 类合并进 `initialStateId`；请求标识包含完整初态。
- 返回的是瞬时布居，含光频微运动（反旋转项约 (Ω/ω)²；远失谐光与共振光作用在同一对能级上时还有一阶的拍频项）；有激光时长期结果总是时刻 T 的相位平均（`time-average`：只平均掉快振荡，不是 0 到 T 的平均）。
- **旧场景**：带 `regime` 的场景照常读入，全部按显式驱动解释；原来 `far`（静态光移）的光打开"显示光移"。场景中的 `populationTolerance`（任何值）被忽略。

### 请求格式

`scripts/native-protocol.mjs` 发给求解器的 `model` 与 `claude/atom-model` 的构建器逐位相同：`claude/atom-research` 的 `research/population/models/gen_model.mjs` 用那个构建器生成的、晶格核据以验证的请求（`research/population/inputs/*_new.request.json`，6 个场景：probeTweezer、singleProbe、twoNearNoTrap、threeNearStrong、fourNear、fiveNearPrepared），本版从同一场景文件（经当前场景迁移）重建后逐位一致。`tests/research-requests.test.mjs` 对其中 3 个场景按字段的 SHA-256 检查。与 `gen_model.mjs` 的输出相比，应用的请求只多两处：`options` 写明 `durationUs`、`samples`、`populationTolerance: 0.005`、`includeAsymptotic`、`steadyOnly` 和 `meanHorizonUs`（`gen_model.mjs` 写 `{}`），每个驱动另带 `laserIds`（求解器不读）。

### 物理验证（ε 见各项）

以下数值由上一版求解器（ε 可调）求得，验证的是模型本身。

- **Bloch–Siegert（反旋转）位移**：σ⁺ 探测光扫 |2,2⟩→|3′,3⟩（B ∥ k ∥ z，3 G），加 852 nm、3.5 mW/1 µm 光镊。完整模型与去掉反旋转驱动的对照之间的谱线中心差：π 光镊 0.66480 MHz，解析二阶反旋转位移 0.66479 MHz；σ⁺ 光镊 0.66755 / 0.66752 MHz（10 µs 有限时间，ε = 2e-5，7 点 Lorentz 拟合）。
- **光镊光移**：π 光镊下谱线中心 23.27454 MHz，二阶预言（D 线旋转+反旋转、32 态外能级、芯极化）23.27447 MHz，差 0.07 kHz；无芯极化时为 23.27662 MHz，差值 −2.16 kHz 即芯极化的 5S/5P 差分（α_vc）。σ⁺ 光镊下差 11 kHz，来自 10 µs 采样点上的一阶拍频微运动。
- **光镊散射**（只开 π 光镊，3 G，初态 ground-2-0，0–10 ms）：求解器测得自旋翻转 Raman 0.253/s、改变 F 的 0.062/s；由同一模型绝热消去得 0.246/0.062/s；含 D1/D2 干涉的 Kramers–Heisenberg 估计（只取旋转项，散射光 ω³）0.247/0.062/s。总散射（含 Rayleigh）主方程 21.1/s，KH 16.6/s：差别是 Lindblad 模型的 ω³ 取原子频率而非散射光频率（(ν₀/ν_L)³ ≈ 1.27），另外主方程中反旋转散射与旋转散射不相干叠加（KH 中相干叠加，约 +8%）。若按 D 线分开塌缩算符，自旋翻转 Raman 为 10.1/s（高估约 40 倍）。
- **非 secular 辐射**：三束近共振光（无光镊）20 µs，非 secular 与 secular（按 F 和 D 线分开）的布居最大差 3.3e-5，稳态 3.1e-5（量级为 Γ/ω_hfs ≈ 9e-4 乘以激发与相干的权重）；只差 D1/D2 交叉项时为 1.8e-7。

## 算法（`rust-solver/population-core/src/lattice`）

交接说明（流水线、删掉的部分、常数及其来历、验证与工作量、开放问题、下一步）：`population-core-handoff.md`。

- **频率坐标与晶格**：模型在请求自己的旋转系中按 Fourier 电荷（各频率轴的整数组合）分解为生成元分量 L_t（完整的非 secular Lindblad 形式）。场是每个电荷（晶格模式）上的一个 32×32 块。每个请求的晶格是显式集 P 及其环 Q（P 外一个结构步的电荷），P ∪ Q 之外的电荷省略。
- **各激发流形的旋转系**（`preparation.rs`）：激发能级（H0 对角元排序后）在比两侧能级展宽大 100 倍以上的间隙处分成流形；某个驱动电荷 g 的频率 ν(g) 落在流形中心能量 E 的 1/100 以内、且 |E| 至少是流形自身和基态展宽的 100 倍时，这个流形改在自己的旋转系 ν(g) 中描述（只有一条光学线的模型、以及落在折叠间隙以内的流形都不换系：它们的偏移是失谐，不是精细结构分裂）。这是精确的规范变换 ρ = Vρ′V†，V = diag e^{iν(g_i)t}：(i, j) 上电荷 q 的分量移到 q − g_i + g_j，H0 的对角加上 ν(g_i)，塌缩算符的 (i, j) 元移到 g_j − g_i（同时到达两个流形的通道保留交叉项，以其拍频进入生成元）；结果中这些态的实验室系频率指标按 f − g 换回。不换系时 ‖L0‖ 是流形间的光学间距，拍频、光镊和反旋转项之间找不到折叠间隙。
- **显式与折叠**：每个非零电荷步只按大小和频率分类，不依赖恰好为零的矩阵元。一个步能折叠，要求它的块离 L0 的谱足够远（|ν_s| ≥ 2‖L0‖，远块逆的 Neumann 级数比 ≤ 1/2），且混合比 m = ‖L_s‖/(|ν_s| − ‖L0‖) 满足 m² ≤ ηε：折叠丢掉远模式的从动幅度（微运动），对布居是 m² 阶；否则是显式步，晶格精确携带它的模式和微运动（两态玩具 H = 200 cos(1000t) σx：原来按频率折叠、误差 3.95e-2 而界为 0，现在显式、误差 3.5e-7）。能折叠的显著频率排序后，在所有不能折叠的频率之上、比值至少 1/√(ηε) = 44.7 的最大间隙处切开：折叠只保留 ν_q 的 0、1 阶，第一个略去的阶相对为 (ν_q/ν_s)² ≤ ηε。远步用精确的 (L0 − iν_s)⁻¹ 静态折叠为 Σ_o (iν_q)^o K_t^(o)（o = 0, 1，所有目标），每个模型一次（`fold::FoldLibrary`）；两个远步之和落在近电荷上时为交叉折叠。
- **运行的折叠**（`fold::RunFold::screened`）：可吸收部分（光移及其频率依赖，A X + X B）一律保留——它在每个模式的块因子里，作用不花钱。存储的余项（扇区稠密块与 CSR）中布居行以外的部分和整个交叉折叠，按迹范数界 ‖P‖₁→₁ ν_max^o T（存储片段取 √n·√(最大行和·最大列和)）从小到大略去，总和 ≤ ηε/2：与初态无关（真实传播子逐相位是迹范数压缩）。余项的布居行总是保留，迹按构造守恒。光镊场景在 20 µs 就一片也丢不掉，所以四束光的晶格算子每次作用 35M 乘加（main 3M）；这是正确性的代价（原来按 x0 的响应丢掉了整个光镊对角折叠，b0 20 µs 误差 0.78）。
- **远壳环**（三阶以上，`fold::FoldLibrary::far_shell_sources`、`ring_targets`）：x0 在 L0′ 本征基中的显著分量 E_j 作源，逐环求远壳落回晶格的部分，每环的一阶 Duhamel 响应读成运行采样时刻的布居。环在下面两种情况之一停止：所略去部分（每块按源的 |c_j| 加权的迹范数界乘 T）≤ ηε/4；或连续两环的响应都 ≤ ηε/8（要求连续两环，是因为一环的落点在两组电荷之间交替；三束光 20 µs 上，第二环的响应是第一环的 27 倍）。期间下一环最小的远模式在剩余份额的一半内略去；各组按环同步推进，下一环的远块在决定继续之后才形成，并受内存预算限制（r26 有 42 个远步，原来一环就有 1e5 个远模式，内存用完）；最外的环在响应之和 ≤ ηε/4 内丢掉，保留的环建成环目标进入算子（其远模式按剩余份额修剪）。这是唯一与初态有关的先验规则；冻结集上只有 both_tweezer 和 r27 保留了第一环（both_tweezer 的均值因此正确，10.28.5 在这里差 0.115）。
- **显式集**（`charge_set`）：P 从 {0} 和一阶混合 |L_s|/|ν_s| > ηε 的显式步开始（带 −s，平移门槛）；环条件闭包：环内部边 ρ = ‖C_t‖‖D_q⁻¹‖ > 0.1 时把 ρ 之和最大的环电荷连同镜像升入 P（至多 4 次）；覆盖：从 x0 和中心块稳态逐层奴役得到的种子振幅 > ηε 而 P ∪ Q 漏掉的电荷升入 P。每个请求只建一次，均值和轨迹两次运行共用。
- **极点求解**（`poles`）：每个极点在整个晶格上求解：实极点 ξ 的 (A − ξ)w = f，极点 0 是加边稳态系统 (A + u τ0ᵀ)w = u（迹行约束）。内解是右预条件 GMRES（实坐标，只算正则半，镜像其余），预条件为每个块上的 Floquet 框架（中心带 Woodbury 项）；停止看重算的真残差（移位解 1e-7，稳态 1e-9），一个重启周期没有把真残差减半就返回（r07 的小移位内解原来每次跑满 900 步，20 µs 用 322 s 且部分收敛；现在 20.5 s 收敛）。
- **有理 Krylov 空间**（`space`）：每个运行一个从 x0 出发的空间。基的第一列是迹载体 u/|u|（u = I/n 在中心块），其余每一列都先投影到块迹为零的子空间 K（正交投影，基保持正交归一）：块迹是晶格算子的精确左本征矢，每个块迹按构造守恒。先激活过门槛的显式步的平移（副本 S_s v ± S_-s v 直接入基，不用求解），再做加边稳态列（加边系统奇异时改为 x0 上的 0⁺ 极点）；第一轮之前加入 x0 在中心生成元本征矢上、在第一个输出时刻布居权重仍 ≥ ηε 的分量（单模式晶格的精确方向：强驱动的 Rabi 振荡，实极点分辨得慢）；之后按比特反序的固定循环解实极点梯子：σ 从顶到 1/T，每十倍 2 个（每十倍 1 个时三、四、五束光 20 µs 少用三成求解，但停滞或卡在 ε 边上）。顶 = max(10/t₁, P 的最快频率)：10/t₁ 是 shift-and-invert 在时刻 t 的极点 t/10（van den Eshof–Hochbruck），t₁ 为第一个采样时刻（均值取最短视界）；轨迹的读出看得到各模式的旋转，所以再取显式集 P 的最快频率（P 的模式携带 ≥ ηε 的幅度，环 Q 的在其下）。由 x0 在 L0′ 本征基中推的顶不成立：两态玩具 L0′ = 0、b0 的 x0 在 L0′ 下静止，动力学全来自晶格耦合，误差分别 7.9e-3（被接受）与 0.25。正交化为带 Kahan–Parlett 判据的分块 Gram–Schmidt；低于噪声地板（100 × 内解容差）的方向不入基；基与像受内存预算限制。
- **约化模型**（`reduced`）：欧氏 Galerkin，H = Wᵀ(AW)，像 AW 随基增长存下（每列一次作用、两次 Gram）。A 把一切映入 K，H 的载体行为零，块迹守恒。本征分解 H s_j = θ_j s_j 给出模式；|θ_j|T ≤ ηε 的在运行时长内视为守恒。增长模（Re θ > 0）是投影的伪影，因为生成元的谱在左半平面：它被反射，Re θ → −Re θ。如果钳到虚轴，它会不衰减地留到视界——r21 的 1 s 均值因两个被钳的模式差 2.0e-2，反射后为 1.6e-8。所有输出（网格上的轨迹、各视界的态、最慢弛豫）都从同一个模型读出。单模式晶格（只有中心）走同一条路：稠密本征分解的慢本征值绝对误差约 eps·‖L0′‖（D1 + D2 系 ‖L0′‖ = 4.5e7 rad/µs，即 1e-8 /µs），1 s 时只开探测光的 p(1 s) 偏 1.1e-3，所以不用它读输出。
- **接受与停止**（`pipeline`，确定性，不看墙钟）：稳态列之后一个检查点，之后每个整轮一个。输出的估计 = 与上一个检查点之差（ε 的度量；轨迹采样点另加投影到概率单纯形的改变量）：一轮访问梯子的每个尺度一次，整轮的变化就是收敛检查——QuTiP 式的估计，不是严格界。所有估计 ≤ ε、这一轮确实加入了新方向、且稳态列和这一轮的内解都收敛（真残差 ≤ ηε；内解失败的极点等于没有访问那个尺度：r07 曾因此以 5.7e-3 的误差被接受）时接受（r00 曾在一个没有新方向的检查点"变化为 0"而被接受，误差 0.97）。否则当一轮没有加入方向、或最大变化在一轮内没有减小、或基内存用完时停止，返回最好的检查点：轨迹每个采样点的估计都 ≤ ε 时为 `estimated-converged`，否则为 `estimated-partial` 并附原因（含超出的采样点范围），每个采样点带自己的估计；算出的结果从不扣下。
- **最慢弛豫与视界**：最慢弛豫取种群权 ≥ ηε 的最慢衰减模式（残差由其向量的像直接算），只报告，不参与接受：残差 ≤ 0.1 × 速率时为已解析，否则只报告范围。视界为 p̄(100 ms)、p̄(1 s)，一次运行同时给出；p̄(T) 是 T 时刻态的中心块，即实验室系相位平均，投影到密度矩阵，改变量计入估计。
- **先验份额**（`accuracy::A_PRIORI_SHARE`，η = 0.1）：收敛检查看不到的先验截断——晶格的门与覆盖、折叠的资格与间隙、运行折叠的余项与远壳环（各一半）、守恒阈值、最慢弛豫的候选——各自 ≤ ηε；同时用满仍在 ε 的三分之一以内。它取代了原来的 GATE、SEED_AMPLITUDE、FOLD_SHARE、CANDIDATE_WEIGHT、GROWTH_BUDGET 和环的份额。
- **内存保护**（`pipeline`）：一个请求约占 0.5 GB 加它每个运行的每个晶格模式 32 MB（在旧估计器下测得，现在是上界）；完整请求的轨迹和均值两个运行同时执行，超出时在第一次求解前停止并说明原因。预算是安装的物理内存的一半；基和它的像用预算剩下的部分。
- **模型缓存**（`lattice_core_adapter`）：worker 保留最近一次准备的模型（键是算子与相位元数据的全部数值，按位比较；初态与选项不在键中）：同一模型的下一次请求（换初态、网格或视界）重用模型准备与本征基。
- **轨迹范围**：轨迹最长 10 s（1e7 µs），2 至 2000 个采样点；更长或更密的网格由适配器拒绝并写明原因（核心同样拒绝），界面的输入也限在这个范围内。
- **请求与检查点**：均值总是自己单独一次运行，一次运行同时给出两个标准视界 T = 100 ms 和 1 s（没有 t → ∞），结果写在 `meanHorizons` 中：每项 `{horizonUs, populations, densityReal, densityImag, estimatedError, withinTolerance, status, reason}`。请求的 `meanHorizonUs` 只能是这两个之一，它指明界面显示的一项；只算均值的请求为 `meanOnly: true`，均值已在缓存中时轨迹请求带 `includeMean: false`；协议版本为 `atom-lindblad-jsonl/3`。完整请求的均值在自己的线程上与轨迹运行并行；轨迹运行的空间只覆盖网格时间。每个检查点都以 `checkpoint` 进度发出，最终结果是最好的检查点。
- **静态模型**（没有激光）：晶格只有中心块，走同一条流水线。

## 代码

- 结果契约在 `rust-solver/src/lattice_core_adapter.rs` 一处定义（文件开头的说明），`solver-client.ts` 只按它读取；求解器的方法与失败说明由 `src/solver-words.ts` 译成中文。
- BLAS 固定单线程，唯一线程设置是 `ATOM_SOLVER_THREADS`（桌面版缺省 8）。线程数只在舍入层面影响结果，不是逐位相同；输出的前后对比须用同一线程数。
- worker 保留最近一次准备的模型（`lattice_core_adapter::prepared_model`）：同一模型换初态、网格或视界的请求重用它。
- worker 启动自检为 `op:"warmup"`。
- 每个请求的 ε 固定为 0.005；请求只能重述它，其它值报错。

验证：`cargo test --workspace`（晶格各模块对稠密参考的单元测试、协议测试）与 `npm test`。其中 `tests/research-requests.test.mjs` 检查请求与晶格核验证请求逐位一致，`tests/display-switch.test.mjs` 检查"显示光移"经全阶静态光移进入能级图背景，`tests/scene-file.test.mjs` 检查带 `regime` 和 `populationTolerance` 的旧场景，`tests/population-tolerance.test.mjs` 检查每个请求都是 0.005，`tests/format.test.mjs` 检查求解器写出的方法说明都有中文。

## 静态光移（`src/floquet-background.ts`，能级图背景）

打开"显示光移"的激光，其静态光移画在能级图的背景中（仅显示，动力学不用它）。

- **方法**：这些激光的各载频为 Floquet 电荷；基态与激发态副本按电荷奇偶交替，8 个基态与 24 个激发态各成一个问题。P 为电荷 0 的能级，Q 为 |n|₁ ≤ L（先取 L = 2）的副本和 32 态以外能级的副本；后者彼此不耦合，按其预解式精确消去。每个近简并簇在自己的能量 E_c 上用分层 Gauss–Seidel 求缀饰列 Φ(E_c)，线性化的 Brillouin–Wigner 方程即缀饰空间上的 Rayleigh–Ritz 问题；E_c 迭代到簇的能级，界不达标时分裂簇或加层。
- **数值误差界**（每个能级）：缀饰空间上的 Kato–Temple 界（逐副本取能隙），加上漏到未保留副本的部分（二阶）和未保留的高态虚跃迁对（一阶），再乘 2；另加浮点舍入下限。目标 0.05 Hz。不含原子数据的不确定度。
- **验证**：截到一阶时与 v2026.10.27.1 的二阶结果在 1e-9 MHz 内一致（9 个场景）；与直接构造的截断 Floquet 矩阵（|n|₁ ≤ 4，全部高态 Raman 对，移位求逆子空间迭代）在 1.4 mHz 内一致，每个能级都在其界内，包括混合比 2%、B = 0、近 4D5/2 与 6P3/2 线的远失谐光和两束远失谐光。π 光镊谱线中心（σ⁺ 探测 |2,2⟩→|3′,3⟩，3 G）由二阶的 23.274469 MHz 变为 23.274455 MHz（−13 Hz），界 < 0.01 Hz。
- **耗时**（能级图一次更新，Node，中位数）：1 / 2 / 3 / 4 / 5 束静态光约 7 / 15 / 39 / 60 / 100 ms；此前的二阶为 11 / 21 / 27 / 33 / 46 ms。主要花在 32 态外能级的副本和多光拍频副本上。
- 测试：`tests/static-shift.test.mjs`；完整对照表：`node scripts/static-shift-report.mjs`。
- 1% 混合比限制没有数值原因（分块在 2% 处照样收敛并给出界），是静态光移能否代表一束光作用的物理判断：超过 1% 或虚跃迁失谐低于下限时，能级图不画这束光的光移，检查器写"离共振太近，静态光移不能代表它的作用"。

## 已知限制

- 误差估计是整轮变化的收敛估计（QuTiP 式），不是严格上界。
- 部分收敛并如实报告的：随机场景 r02 的 10 ms、r07 的 10 ms 与均值，以及 r07 20 µs（它的小移位内解没有收敛，所以按规则不接受）；强 D1 + D2（2000 mW/cm²，20 µs，最早 3 个采样点）。r01 带原因停止：远失谐光的组合落在 L0 的谱内。
- r00 的 p(1 s) 与冻结参考差 1.2e-2；两种处理与 10.28.5 一致，但参考自身有负布居，所以哪一个对尚未确定（见交接说明）。
- 光镊场景的晶格算子比 main 重约 10 倍；10 ms 轨迹和均值比 10.28.5 慢约 2 倍（今天的负载下测；安静机器上复测）。
- OpenBLAS 为每个调用 BLAS 的线程保留约 110 MB 私有提交内存；工作集不受影响。
- 旧版本保存的场景若 `durationUnit` 为 `us`，当前场景校验会拒绝加载（现行单位写作 `μs`）。
