# Atom Workbench：布居求解器交付说明

所有请求（`rb87-full/2`）只走一条路径：`rust-solver/population-core`。有限时间轨迹和长期平均共用同一个规范 pencil `E x' = F x`，误差由 a-posteriori 估计控制到用户给定的 ε（概率尺度绝对误差，默认 0.005，范围 0 < ε ≤ 0.02），达不到就报错，不会静默放宽。物理模型仍由 TypeScript 构建；求解器不按失谐、流形或"禁戒"标签删除模型给出的任何耦合，也不依赖矩阵元恰好为零。

## 物理模型（`src/full-master-model.ts`，发布版）

发布版沿用 2eb09df 的物理模型，另加 Rb⁺ 芯极化和完整初态。每束光的 `regime` 决定它怎样进入动力学，也是请求标识的一部分：

- **近共振光（`near`）**：主方程中的旋转波（RWA）驱动，耦合两个基态 F 与 D1、D2 全部允许电偶极跃迁，只去掉光学反旋转项。统一光学旋转系，F=1、F=2 各取共振的基态旋转系；激光间拍频按最小距离生成树的整数相位坐标进入。
- **远失谐光（`far`）**：只贡献静态二阶（van Vleck）光移：D 线旋转与反旋转项、32 态以外能级（5S 的 6–9P；5P 的 6–10S、4–9D）和 Rb⁺ 芯极化 −α|E|²/4（Arora & Sahoo, PRA 86, 033416 (2012)：α_c = 9.1 au，5S 另有 α_vc = −0.26 au，5P 的 α_vc ≈ 0；数据源写在 `spectroscopy-data.ts`）。能级图显示的就是这一背景。不含远失谐光的散射。芯极化只加给远失谐光：对近共振光它只有 0.26 au 的差分，远小于同样未计入的反旋转项和 32 态外光移。
- **有效性**（与 2eb09df 相同，超出即拒绝，不放宽）：远失谐光要求每个允许跃迁 |Δ| ≥ 100·max(Γ/2π, Ω/2π)，且静态光移的混合比 |Ω/2Δ| ≤ 1%、虚跃迁失谐 ≥ 100 MHz（D 线）/ 10 GHz（其他能级）；近共振光要求最近跃迁在 max(1 GHz, 10·Ω/2π) 以内。`laser-regime.ts` 的 `farValidity` 对单束光给出混合比、两项检查和结论，供界面标注；默认 852 nm 光镊先触到第一条（约在 |Ω/2Δ| = 0.53% 处）。
- **自发辐射**：每条 D 线、每个光子偏振分量 q、每个基态 F 一个塌缩算符（对基态超精细发射频率 secular），变换到背景本征基。
- **基矢与初态**：主方程、初态与返回布居都在远失谐背景（磁场 + 远失谐静态光移）的本征基中。`dynamics.initialState`（`state` / `unpolarized`(ground、F1、F2) / `thermal` / `weights`）在此基中对角；求解器收到完整初始密度 `initialReal/initialImag`，结果附带 `initialState` 与 `initialPopulations`。

逐光显式驱动（含反旋转项）和非 secular 辐射的研究模型在 `claude/atom-model` 分支，未进入发布版。

### 发布版验证

- **与 2eb09df 逐位比较**：16 个场景的旧模型请求，把芯极化置零时与 2eb09df 构建器的输出逐位相同；含芯极化时，没有远失谐光的场景仍逐位相同，有光镊的场景只有 H0 对角改变（至多 2.7 kHz），其余矩阵元只有背景基重新对角化带来的约 1e-14 相对舍入差。
- **π 光镊谱线中心**（σ⁺ 探测 |2,2⟩→|3′,3⟩，3 G，852 nm 光镊，10 µs，ε = 2e-5，7 点 Lorentz 拟合）：本版 23.27447 MHz（静态预言 23.274469 MHz），显式驱动模型 23.27454 MHz，差 70 Hz；无芯极化时为 23.27662 MHz。
- **芯极化**：852 nm π 光镊下 8 个基态光移的平均值与独立的标量极化率求和（D1、D2 含反旋转项，32 态外能级，芯极化 8.84 au）相对差 1.3e-8。

## 算法

- **精确变量变换**：规范相位、块 Hilbert 基、光学剪切 S、回收剪切 K̂ 和 Fourier 包络都是精确变换，不是近似。剪切按它消去什么来选：电荷只有在一阶混合或二阶位移显著时才剪切，按有效失谐分层；K̂ 只在它制造的每个耦合都不值得剪切时使用。禁戒元扰动到 1e-9–1e-6 时结果连续变化。
- **有限时间**：在 pencil 上构造 rational Krylov 试探空间（快极点 20/µs；T > 40 µs 时再加慢极点 200/T），用 Galerkin 约化模型在输出网格上递推。pencil 核跳过系数块内恰好为零的子块，薄系数压缩存储；这只影响速度，不影响结果。
- **误差控制**：以慢流形对偶做 dual-weighted residual 估计，基误差与 Fourier 截断（halo）分开估计。halo 覆盖从域内经耦合可达的全部域外模式，用 CPTP 传播不增加迹范数给出的压缩性界兜底；非基态的回跳经 Markov 消去后计入，快回跳多算一跳。接受条件为 `1.5·|basis + halo| + 投影改变量 ≤ ε`。halo 指标决定加入哪些 Fourier 模式。
- **长期平均**：同一 pencil 的零空间向量，经 Newton 修正和 halo 凝聚。凝聚修正再做一次 halo（二阶自洽检查），比值 ≥ 0.5 时不接受、改为扩域。另有唯一性检查：确认极限唯一，并给出最慢弛豫时间。多束光频率不可公度时没有真正的稳态，结果是准周期态的长时间平均（状态 `time-average`）。
- **观察时长**：长期布居可选 p̄(100 ms)、p̄(1 s)（默认）或 p̄(∞)（请求 `meanHorizonUs`，响应 `horizonUs`）。p̄(T) 把慢流形在 T 内精确传播、快部分弛豫，用于光镊散射等极慢过程使 t→∞ 的态忘记初态的场合。
- 均值与轨迹在同一 worker 内并发求解。

## 性能（与 v2026.10.26.2 = 2eb09df 对比）

同一批请求（6 个场景，1–5 光）× 3 种时长网格（20 µs/200、10 µs/2000、10 ms/200）× 3 档 ε（0.001、0.005、0.02）共 54 个有限时间用例，加 6 个稳态。两个 EXE 两轮交错、轮间换序，HIGH 优先级，固定在 6 个 P 核，`ATOM_PENCIL_THREADS=6`，取两轮平均墙钟。

| 用例 | v2026.10.26.2 | 本版 |
|---|---:|---:|
| 1 光（全部网格） | 0.12–0.74 s | 0.97–1.06 倍 |
| 2 光，有限时间 | 0.29–0.63 s | 0.71–0.92 倍 |
| 3 光，20 µs/200、10 µs/2000 | 1.6–2.3 s | 0.41–0.59 倍（如 1.99 → 0.87 s） |
| 3 光，0–10 ms，ε = 0.005/0.02 | 0.79–0.87 s | 0.58–0.66 倍 |
| 4 光，20 µs/200、10 µs/2000 | 3.7–4.5 s | 0.60–0.69 倍（如 4.53 → 2.71 s） |
| 4 光，0–10 ms，ε = 0.005/0.02 | 1.65–1.70 s | 0.63–0.67 倍 |
| 5 光，20 µs/200、10 µs/2000 | 7.1–8.6 s | 0.92–1.06 倍，峰值工作集 207–221 → 333–365 MB |
| 5 光，0–10 ms，ε = 0.005/0.02 | 2.8 s | 0.90–0.93 倍 |
| 4 光 / 5 光，0–10 ms，ε = 0.001 | 1.63 / 2.69 s | 2.31 / 5.58 s |
| 稳态 1 / 2 / 3 光 | 0.09 / 0.14 / 0.45 s | 0.13 / 0.27 / 0.50–0.59 s |
| 稳态 4 / 5 光 | 0.78 / 1.21 s | 1.30 / 3.09 s |

两版结果在全部 60 个用例上互相一致：|差| ≤ 两边估计之和。

变慢的用例及原因（都留给统一误差控制的研究处理，见文末）：
- **完整 halo 与稳态二阶自洽检查**：在旧模型上估计只变化 1–16%，但 5 光每个用例多约 2 s halo 时间和约 150 MB。它们是为显式远失谐模型发现的漏估而加的，保留。
- **10 ms、ε = 0.001 的起始域**：起始 Fourier 域更小，加模式后从头重算，应用次数翻倍。只影响速度。
- **唯一性检查**：每个稳态 +0.3–0.4 s，换来极限唯一的证明和最慢弛豫时间。
- 测试矩阵之外，稳态 ε = 1e-4 时 5 光由 2.1 s 增到 11.6 s（剪切选择使模式数由 29 增到 105）。

更紧的容差反而变好：ε = 1e-5 时 v2026.10.26.2 在 4 光、5 光 0–10 ms 上达不到要求而报错，本版 4 光 3 s 完成。

## 精度

独立参考：截断 Fourier 扩展的 Lindblad 方程，块对角预条件 GMRES 求稳态，两阶比较给出参考自身的不确定度。旧模型稳态，ε = 0.005：

| 用例 | 墙钟 | 声称估计 | 实际误差 | 参考不确定度 |
|---|---:|---:|---:|---:|
| 1 光 | 0.2 s | 8.5e-6 | 2.2e-7 | 2e-16 |
| 2 光 | 0.2 s | 6.9e-4 | 2.4e-6 | 3e-13 |
| 3 光（强） | 0.5 s | 4.3e-3 | 1.8e-4 | 1e-8 |
| 3 光（斜） | 0.5 s | 4.2e-3 | 5.4e-5 | 3e-10 |
| 4 光 | 1.1 s | 4.5e-3 | 1.5e-4 | 1e-6 |
| 5 光 | 2.7 s | 4.7e-3 | 2.0e-4 | 9e-6 |

没有实际误差超过估计的用例。ε = 1e-5 时本版稳态与参考相差 1e-9–3.4e-7。

有限时间：
- 5 光 0–10 ms、ε = 0.001：上一版声称 1.9e-4，与本版紧参考相差 3.2e-4（仍在 ε 内，但超过声称值）。本版的紧参考在两种剪切选择之间、以及与单独的 50 µs 求解之间一致到 1e-5 以内，上一版自身收紧到 ε = 2e-4 也不动，所以判断是上一版漏估。
- 4 光 0–10 ms、ε = 0.001：开发中途的版本（新核、未合估计器修正）声称 1.4e-5，实际 2.5e-4（低估 18 倍）；快回跳多算一跳后估计 1.1e-4，实际 7.4e-5。本版含这项修正。

## 代码

- 结果契约在 `population_core_adapter.rs` 一处定义，`solver-client.ts` 只按它读取。
- BLAS 固定单线程，唯一线程设置是 `ATOM_PENCIL_THREADS`。
- worker 启动自检为 `op:"warmup"`。

验证：population-core 66 个、worker 15 个 Rust 测试，152 个 JS 测试；单文件 EXE 的应用自检（`--self-test`）、`--chrome-test` 和真实 Worker/IPC 冒烟测试（默认场景，以及探测光 + 远失谐光镊）均通过；界面在 1536、1000、900 px 宽度下逐项检查过（处理方式控件、背景光移、观察时长、初态、参考频率、3D、计算详情、模型说明、场景保存与载入）。

## 已知限制

- 误差估计是经独立参考校准的 a-posteriori 估计，不是严格上界。
- 4–5 光时误差控制（halo、慢对偶）已占求解时间的一半左右，比例不合理；这是下一轮研究的首要目标。
- OpenBLAS 为每个调用 BLAS 的线程保留约 110 MB 私有提交内存；工作集不受影响。要降低需要用更小的 BUFFERSIZE 重编 OpenBLAS。
- 旧版本保存的场景若 `durationUnit` 为 `us`，当前场景校验会拒绝加载（现行单位写作 `μs`）。
