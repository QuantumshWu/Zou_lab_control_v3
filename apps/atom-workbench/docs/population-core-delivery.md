# Atom Workbench：布居求解器交付说明

所有请求（`rb87-full/2`）只走一条路径：`rust-solver/population-core`。有限时间轨迹和长期平均共用同一个规范 pencil `E x' = F x`，误差由 a-posteriori 估计控制到用户给定的 ε（概率尺度绝对误差，默认 0.005，范围 0 < ε ≤ 0.02），达不到就报错，不会静默放宽。物理模型仍由 TypeScript 构建，求解器不按失谐、流形或"禁戒"标签删除任何耦合，也不依赖矩阵元恰好为零。

## 物理模型（`src/full-master-model.ts`）

输入模型在 32 态内部不做先验近似，取舍都交给求解器的误差估计；判断只看量级，不依赖恰好为零的矩阵元。

- **所有激光都是显式驱动**：每束开启且强度非零的激光都耦合 D1、D2 全部允许电偶极跃迁，旋转项和反旋转项都保留（不作 RWA），不再分近/远失谐。`regime` 只决定能级图是否显示该光的光移（`far` = 显示），不影响动力学，也不再报"激光类型与失谐不匹配"。
- **旋转系与频率坐标**：激发态以参考光载频旋转，基态不旋转（统一光学旋转系）。参考光取 Rabi/(|失谐|+线宽) 最大的一束；这只是精确坐标的选择。激光间拍频沿用最小距离生成树；参考载频（约 3.8×10⁸ MHz）本身是一条声明的频率轴，所以反旋转项频率 ν_L+ν_ref = 2ν_ref+(ν_L−ν_ref) 是各轴的整数组合，不会把 768 THz 的相位舍入成拍频。完全相消的同频光（例如相位相反）不发送。
- **自发辐射**：每个光子球分量 q 一个塌缩算符，同时包含 D1、D2 两条线和两个基态 F 通道，幅度 d_eg·sqrt(Kω_eg³)（Born–Markov 形式，无 secular 近似）。在上述旋转系中它们是静态的；求解器的规范相位再把 F=1/F=2、D1/D2 之间的交叉项作为不同 Fourier 电荷精确保留。按 D 线分开的算符等于在 7 THz 精细结构上做 secular 近似，会丢掉 D1/D2 干涉：852 nm 光镊的自旋翻转 Raman 率因此高估约 40 倍（见下）。
- **静态 H0**：磁场 + 每束光经 32 态以外能级（5S 的 6–9P；5P 的 6–10S、4–9D）的二阶（van Vleck）光移 + Rb⁺ 芯极化 −α|E|²/4（Arora & Sahoo, PRA 86, 033416 (2012) 表 II/IV/V：α_c = 9.1 au，5S 另有 α_vc = −0.26 au，5P 的 α_vc ≈ 0；数据源写在 `spectroscopy-data.ts`）。原有的有效性检查（耦合/失谐比 ≤ 0.01、失谐 ≥ 10 GHz）保留。D 线的旋转与反旋转耦合全部是显式驱动，静态部分不再含 D 线项，不重复计入。未包含更高价态尾项（5P 约 13 au，强烈依赖频率）和连续谱。
- **基矢**：主方程、初态和返回布居都在上述静态 H0 的本征基中；态标签 F、mF 指与之重叠最大的磁场本征态。D 线光学缀饰不进入基矢，而由动力学给出。能级图的显示背景仍用原二阶模型（含 D 线项，仅显示）。
- **初态**：`dynamics.initialState`（`state` / `unpolarized`(ground、F1、F2) / `thermal`(静态 H0 基态本征能量上的 Boltzmann 分布) / `weights`），在模型基中对角；求解器收到完整初始密度 `initialReal/initialImag`。缺省时等同 `{kind:'state', id: initialStateId}`；场景文件把 `state` 类合并进 `initialStateId`；请求标识包含完整初态，而不再包含只影响显示的 `regime`。
- 返回的是瞬时布居，含光频微运动（反旋转项约 (Ω/ω)²；远失谐光与共振光作用在同一对能级上时还有一阶的拍频项）；有激光时长期结果总是时间平均（`time-average`）。

### 物理验证（同一求解器，ε 见各项）

- **Bloch–Siegert（反旋转）位移**：σ⁺ 探测光扫 |2,2⟩→|3′,3⟩（B ∥ k ∥ z，3 G），加 852 nm、3.5 mW/1 µm 光镊。完整模型与去掉反旋转驱动的对照之间的谱线中心差：π 光镊 0.66480 MHz，解析二阶反旋转位移 0.66479 MHz；σ⁺ 光镊 0.66755 / 0.66752 MHz（10 µs 有限时间，ε = 2e-5，7 点 Lorentz 拟合）。
- **光镊光移**：π 光镊下谱线中心 23.27454 MHz，二阶预言（D 线旋转+反旋转、32 态外能级、芯极化）23.27447 MHz，差 0.07 kHz；旧静态模型（无芯极化）23.27662 MHz，差值 −2.16 kHz 即芯极化的 5S/5P 差分（α_vc）。σ⁺ 光镊下差 11 kHz，来自 10 µs 采样点上的一阶拍频微运动（两种模型的差仍为 30 Hz）。去掉光镊时新旧模型的有限时间布居差 3e-5。
- **光镊散射**（只开 π 光镊，3 G，初态 ground-2-0，0–10 ms）：求解器测得自旋翻转 Raman 0.253/s、改变 F 的 0.062/s；由同一模型绝热消去得 0.246/0.062/s；含 D1/D2 干涉的 Kramers–Heisenberg 估计（只取旋转项，散射光 ω³）0.247/0.062/s。总散射（含 Rayleigh）主方程 21.1/s，KH 16.6/s：差别是 Lindblad 模型的 ω³ 取原子频率而非散射光频率（(ν₀/ν_L)³ ≈ 1.27），另外主方程中反旋转散射与旋转散射不相干叠加（KH 中相干叠加，约 +8%）。若按 D 线分开塌缩算符，自旋翻转 Raman 为 10.1/s（高估约 40 倍）。
- **非 secular 辐射**：三束近共振光（无光镊）20 µs，非 secular 与 secular（按 F 和 D 线分开）的布居最大差 3.3e-5，稳态 3.1e-5（量级为 Γ/ω_hfs ≈ 9e-4 乘以激发与相干的权重）；只差 D1/D2 交叉项时为 1.8e-7。

### 显式远失谐驱动的求解器代价

ε = 0.005，20 µs/200 点，fresh worker。机器与其他任务共用、负载很重，所以给出 CPU 时间；“上一版”是本模型首次交付时的数字：

| 用例 | 上一版 | 本版（CPU / Fourier 模式 / 列 / 峰值工作集） |
|---|---:|---:|
| 3 光 + 光镊 | 超过 120 s 工作上限（19 模式） | 26 s / 5 / 62 / 200 MB |
| 3 光 + 光镊，ε = 0.001 | 超限 | 49 s / 7 / 72 / 223 MB |
| 4 光 + 光镊 | 超限（31 模式） | 53 s / 9 / 56 / 362 MB |
| 5 光 + 光镊 | 超限（45–59 模式，1.4 GB） | 137 s / 15 / 74 / 736 MB |
| 3 光（无光镊） | 9.5 s（9 模式） | 4.2 s / 3 / 40 / 114 MB |

原因与修正（都是精确变量变换的选择，输入模型不变）：
1. **剪切按作用量选择**：只有一阶混合 ≥ 1e-3 或二阶位移 ≥ 1e-6 线宽的电荷才剪切。近共振光的反旋转项（混合约 1e-8）留在 pencil 中精确计算，不再带来大量中间模式；光镊的旋转与反旋转项都剪切。
2. **分层剪切**：按有效失谐分层，远失谐层在外、近共振层在内（x = T_远(T_近(y))），只在层间交叉耦合显著时分层；同层内互不显著的电荷对分成不同的类。同时剪切会留下 ½[V_光镊, S_近] 约 1.5e3/µs 的交叉耦合，分层后近共振剪切作用在已去掉光镊耦合的生成元上，这一项不再出现。
3. **回收剪切 K̂ 只在不制造新耦合时使用**：T = (I+K̂)J2(S) 中 K̂ 部分不被 S 剪切，光镊耦合 1.2e5/µs 乘 |K̂| ≈ 0.019 会在光镊电荷上制造约 2e3/µs 的耦合，迫使 halo 再加 8 个模式（halo 指标 [1,0,1,0]、[0,0,1,0] 等约 1.4e-2 正是它）；而 K̂ 去掉的回收耦合所在的近共振模式本来就在域内。现在 K̂ 只有在它去掉的耦合值得剪切、且它制造的每个耦合都不值得剪切时才使用。
4. **起始 Fourier 域**由变换后 pencil 对中心模式的残余耦合实测（逐分量速率，含 Raman 共振的慢分量），已被剪切消去的耦合不再进入起始域。
5. **读出对偶**按 4 个态一批回拉，每批只保留超过下限的元素：同一估计器版本下，5 光 + 光镊的峰值工作集由 3.4 GB 降到 0.43 GB（表中 736 MB 含估计器新版慢对偶的内存）。
6. **P0 的参考算子**取剪切坐标下生成元的电荷 0 分量（`preparation::effective::EffectiveGenerator`，与误差估计的 J_eff 同一对象）：含各层光移、散射损失和回到基态的 Raman/Rayleigh 回收。GMRES 每列 5.9 步（有光镊）/ 3.9 步（无光镊），与之前相同。

仍未解决：
- 有光镊的稳态（时间平均）：最慢弛豫约 27 ms（光镊 Raman 0.25/s），近零极点未分辨时按传播求极限，3 / 4 光 + 光镊需 51 / 160 s CPU。
- ε ≤ 5e-4 时有光镊的有限时间用例基误差估计停在 4e-4–8e-4（3 光 9 模式 92 列、4 光 19 模式 168 列、5 光 43 模式 216 列），因此没有更紧的自参考来检验 ε = 0.005 的真实误差。
- 旧模型 3 光、4 光在 10 ms、ε = 0.001 时，真实误差 1.8e-4 / 2.5e-4 在 ε 内，但大于声称的估计 9.4e-6 / 1.4e-5：域外模式 [±2,±1]（经域内模式 [1,0] 再走 Raman 共振电荷一步可达）的 halo 指标只有 7.5e-7，把它放进起始域后真实误差降到 2.9e-6。

## 算法

- **精确变量变换**：规范相位、块 Hilbert 基、光学剪切 S、回收剪切 K 和 Fourier 包络都是精确变换，不是近似。在等价的选择之间按耦合强度挑选；把禁戒元扰动到 1e-9–1e-6 时结果连续变化。
- **有限时间**：在 pencil 上构造 rational Krylov 试探空间（快极点 20/µs；T > 40 µs 时再加慢极点 200/T），用 Galerkin 约化模型在均匀输出网格上递推，起始 Fourier 域取一阶混合幅度显著的步。
- **误差控制**：以慢流形对偶做 dual-weighted residual 估计，基误差与 Fourier 截断（halo）分开估计。远离收敛的检查点只做不含驱动回跳项的廉价筛查，接近门槛时才做完整估计；接受条件为 `1.5·|basis + halo| + 投影改变量 ≤ ε`。halo 指标决定加入哪些 Fourier 模式。
- **长期平均**：同一 pencil 的零空间向量，经 Newton 修正和 halo 凝聚；零空间退化时取初态投影（resolvent 外推）。多束光频率不可公度时，没有真正的稳态，结果是准周期态的长时间平均（状态 `time-average`）。

## 性能（单文件 EXE 内同一求解器，fresh worker 进程墙钟）

ε = 0.005，20 µs/200 点，除注明者外。旧值来自上一版交付说明，新值来自本次最终矩阵；这次测量时机器比几小时前整体慢约 25%，未做修正。

| 用例 | 旧版 | 本版 | 峰值工作集（旧 → 新） |
|---|---:|---:|---:|
| 3 光 | 6.38 s | 1.59 s | 221 → 73 MB |
| 4 光 | 11.2 s | 5.05 s | 444 → 131 MB |
| 4 光，ε = 0.001 | 63.6 s | 6.06 s | 1468 → 133 MB |
| 4 光，0–10 ms | 120 s 超时 | 2.17 s | 2577 → 119 MB |
| 4 光，10 µs/2000 点 | 偶发预算耗尽 | 5.82 s | — → 132 MB |
| 5 光 | 未测 | 8.33 s | 215 MB |
| 5 光，0–10 ms | 未测 | 3.43 s | 191 MB |

## 精度

最终矩阵：6 个场景（1–5 光）× 3 种时长（20 µs/200、10 µs/2000、10 ms/200）× 3 档 ε 共 54 个有限时间用例，加 6 个稳态，全部完成。有独立参考（ETDRK4 加慢子空间传播，精度 1e-8–5e-4）的用例里，实际误差都在 ε 以内，且不超过声称的估计值。

| 用例 | 声称估计 | 实际误差（态 / F 组） |
|---|---:|---:|
| 3 光 20 µs，ε = 0.001 | 3.1e-4 | 2.1e-4 / 8.1e-5 |
| 4 光 20 µs，ε = 0.005 | 3.4e-3 | 1.5e-3 / 1.6e-3 |
| 4 光 10 µs/2000 点 | 3.5e-4 | 2.4e-4 / 1.9e-4 |
| 4 光 0–10 ms | 2.2e-5 | 1.7e-5 / 1.7e-5 |

未乘安全系数的估计与真误差之比在 0.77–1.66 之间，乘上 1.5 后覆盖全部参考用例。5 光以及 10 µs/2000 点的部分场景没有独立参考，只有自身估计。

## 代码

Rust 代码由 37,735 行减到 14,366 行。删除了周期 CPTP 通道、Floquet 稳态、谱分解求解器、`generic-lindblad/1` 稠密求解器、`rb87-dipole/2` 辐射模型、SuperLU，以及开发开关、计时插桩和研究夹具。

- 结果契约在 `population_core_adapter.rs` 一处定义，`solver-client.ts` 只按它读取。
- BLAS 固定单线程，唯一线程设置是 `ATOM_PENCIL_THREADS`。
- worker 启动自检为 `op:"warmup"`。

验证：population-core 54 个、worker 15 个 Rust 测试，116 个 JS 测试；最终 EXE 的冒烟测试（真实 Worker/IPC 通道）和完整应用自检均通过，界面在常规与 1000 px 宽度下检查过。

## 已知限制

- 误差估计是经独立参考校准的 a-posteriori 估计，不是严格上界。
- OpenBLAS 为每个调用 BLAS 的线程保留约 110 MB 私有提交内存，每个 worker 约 1.2 GB 提交量；工作集不受影响。要降低需要用更小的 BUFFERSIZE 重编 OpenBLAS。
- 旧版本保存的场景若 `durationUnit` 为 `us`，当前场景校验会拒绝加载（现行单位写作 `μs`）。

## 可选的后续优化（暂不做）

预计合计约 25–35%：
- 界面路径上均值与轨迹并发，界面等待减少 13–20%；
- 更强的预条件器以减少 GMRES 迭代，约 15%，不确定；
- 读出对偶批量乘，约 5%；
- 省去接受点前多余的粗筛，约 3%。

若要再快一倍以上，需要新的算法思路（例如减少所需的 Krylov 列数）。
