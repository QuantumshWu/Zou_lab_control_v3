# 布居求解器：交接说明（claude/popcore-unified，2026-11-02）

一条流水线、一个先验份额 η、一种接受规则；没有开关，没有按场景的特例。算法见 `population-core-delivery.md` 的"算法"，模块说明在 `rust-solver/population-core/src/lattice/pipeline.rs` 开头。本分支同时修正了 v2026.10.30.1–10.31.1 的回归：b0 / b1 / ex_three 的 20 µs 与均值被判收敛，误差却达 0.78 / 3.4e-2 / 1.0e-2。原因是运行折叠按 x0 的响应丢掉了整个光镊对角折叠，并且只用 K^(0)。

## 流水线（`pipeline::solve`）

1. **晶格**：显式集 P 及其环 Q（`charge_set`）。每个请求一次，轨迹与均值共用。
2. **运行的算子**：模型级的折叠（K^(0)、K^(1)，全部目标）。与初态无关的迹范数筛在 ηε/2 内略去余项片段；可吸收部分始终保留。远壳环（三阶以上）按 x0 的 Duhamel 响应，在另一半份额内保留或丢弃。各组按环同步推进，在严格尾界达到、或连续两环响应 ≤ ηε/8 时停止。
3. **空间**：x0、过门槛显式步的平移副本、加边稳态列；之后按比特反序整轮求解实极点梯子。梯子顶 = max(10/t₁, P 的最快频率)；均值只读中心，取 10/最短视界。每十倍 2 个极点。单模式晶格在第一轮前另加 x0 在其生成元本征矢上的可见分量。
4. **模型**：欧氏 Galerkin，存像。所有输出从同一个模型读出。
5. **接受**（2026-11-02 起，QuTiP 式近似收敛）：稳态列后一个检查点，之后每 4 次求解一个（梯子循环跨检查点继续）。估计 = 与上一个检查点之差，再加单纯形投影的改变量；增长的 Ritz 值反射到左半平面。全部 ≤ ε 且基的列数比上一个检查点多时接受。否则在空间不再增长、内存用完或求解次数用满（48）时停止，返回最好的检查点并写明原因。最慢弛豫时间直接给 Ritz 估计。

## 删掉的部分

- 先验补全与滑移起始块（`apriori`）。
- Schrieffer–Wolff 帧：`kernels`、`blocks`、`frame`、度量与类匹配。
- 簇本征系统、算子伴随、度量 Petrov–Galerkin（τ、K/H/Fm）。
- 每运行重建的折叠和按 x0 响应的片段筛：`FoldRule`、`ResponseRule`、`DroppedPieces`。
- 几何外推收敛与平台规则：STAGNATION、ROUNDOFF、PLATEAU、MAXIMUM_SOLVES、BASIS_BYTES、CHECKPOINT。
- 增长计入（GROWTH_*）、LADDER_TOP、LADDER_SAMPLES、FAR_PRUNE。

`lattice` 模块从 5633 行减到 4427 行（−2188 / +838）。

## 常数及其来历

| 常数 | 值 | 来历 |
|---|---|---|
| ε | 1e-2 | 产品给定（2026-11-02 起；ηε = 1e-3，折叠间隙 1/√(ηε) ≈ 31.6）。下文的表格是 ε = 5e-3、整轮接受时的测量 |
| η（`A_PRIORI_SHARE`） | 0.1 | 收敛检查看不见的先验截断各自 ≤ ηε，同时用满仍在 ε/3 以内（有意留的余量） |
| 折叠资格 | m² ≤ ηε，且 \|ν_s\| ≥ 2‖L0‖ | 微运动对布居是 m² 阶；远块逆的 Neumann 级数比 ≤ 1/2 |
| 折叠间隙 | 1/√(ηε) = 44.7（原 100） | 只保留 ν_q 的 0、1 阶，第一个略去的阶相对为 (ν_q/ν_s)² ≤ ηε |
| 运行折叠 / 远壳环 | 各 ηε/2（环：尾部 ηε/4，丢环与修剪 ηε/4，连续两环 ≤ ηε/8 即停） | η 的分配 |
| 梯子顶 | max(10/t₁, ν_max(P)) | shift-and-invert 在时刻 t 的极点取 t/10（van den Eshof–Hochbruck）；轨迹的读出看得到 P 的旋转 |
| 每十倍极点 | 2 | 实测：取 1 时三、四、五束光 20 µs 停滞，或卡在 ε 边上 |
| 守恒阈值 | \|θ\|T ≤ ηε | 运行时长内与守恒不可分 |
| 增长的 Ritz 值 | 反射（Re θ → −Re θ），无参数 | 生成元的谱在左半平面；钳到虚轴会不衰减地活到视界（r21） |
| 内解 | 1e-7（稳态 1e-9）；噪声地板 100×；一个重启周期没把真残差减半就返回；真残差 ≤ ηε 才算收敛（接受用） | 列的代数误差远低于 ε；减半是"重启还有用"的最低要求；失败的内解停在 0.6–1 |
| 环闭包 | ρ > 0.1，至多 4 次提升 | 沿用，未推导（见开放问题） |
| 内存 | 物理内存的一半 | 另一半留给系统和其它程序 |

## 已知限制与开放问题

- **r00 p(1 s)**：与冻结参考差 1.2e-2（p(100 ms) 差 1.4e-3）。反旋转项显式和折叠两种处理给出同一结果，也与 10.28.5 一致。参考自身有负布居（−1.1e-3），并丢掉过一个伪增长模（maxRe 1.2e-3 /µs）。这个场景的最慢弛豫约 30 s，周期映射的稳态（`verify_b0/steady.py`）无法仲裁 p(1 s)。所以两边哪一个对都不确定；需要一个独立的时域参考。
- **r02 10 ms、r07 10 ms 与均值**：部分收敛，如实报告。r02 的估计 3.2e-2、实际 4.6e-2；r07 的估计 0.6 / 2.5e-2。r07 20 µs 也是部分收敛：估计 6.7e-4、实际 4.5e-4，但它的小移位内解没有收敛，按规则不接受。这两个场景都有强的远失谐光（6e5 rad/µs），离显式步只有 2–4 倍频率，所以不能折叠；晶格频率跨 12 个量级，Floquet 框架预条件在小 σ 上失效。
- **r01**：远失谐光的组合落在 L0 的谱内（−1.1e7 rad/µs，‖L0‖ ≤ 4.5e7），远壳不再是远壳。请求带原因停止，和 10.28.5 一样；之前它会无界地展开远壳环。
- **强 D1 + D2（单模式）**：部分收敛，3/2000 个采样点（t = 0.02–0.05 µs）超出 ε。实极点分辨强 Rabi 振荡很慢；x0 的本征分量把误差从 0.24 降到 6.6e-3。streamline 的单模式稠密路径在 20 µs 能收敛，但在 1 s 的均值上会因 eps‖L0′‖T 偏 1.1e-3，所以没有采用。
- **算子重量**：光镊的余项在 20 µs 也一片丢不掉（迹范数 × T ≫ ηε/2），四束光每次作用 35M 乘加（main 3M），五束光带光镊 66M。这是正确性的代价；还没找到更紧、又与初态无关的余项规则。
- **ν 展开只到 1 阶**：折叠只存 K^(0)、K^(1)。间隙 1/√(ηε) 保证的是相对精度，长 T 的绝对误差没有逐运行检查。
- **环闭包至多 4 次提升**：沿用，没有推导出来（不封顶时四、五束光级联到 47–73 个显式电荷）。

## 下一步（按价值）

1. **轨迹的求解次数**（40 对 10.28.5 的 16）：要两个整轮（每轮 13 个极点）才能比较。复共轭极点放在 x0 的主要频率上，可以缩短梯子；在单模式以外加入 x0 的本征分量时，轨迹 40 → 27 次求解，但均值变成 11 次，r07 被误导，所以没有采用。
2. **算子重量**：余项的算子 Schmidt 分解，或按模式频率逐边筛 K^(1) 的余项（现在全部按 ν_max）。
3. **投影存像**：求解列的像可以由 A w = σw + v 直接得到，不必再作用一次；副本的像仍要作用。预计投影省两成，总时间省 3–5%。
4. **强耦合的预条件**（r02、r07）。
5. 在安静机器上复测墙钟。
