# R3：内层求解与预条件——Floquet 框架

2026-10-27，分支 `claude/unified-precond`（基于 main）。所有数字都在 Rust 里实测：线程数 6，BelowNormal 优先级，一次只跑一个任务。
标注规则：**推导**是代数结论；**实测**是本分支的计数和计时；**推断**是未单独验证的判断。
因为同机还有其他代理在跑，毫秒数有 ±30% 的噪声。可靠的量是步数、MAC 计数和同一进程内的对照。

## 0. 结论

1. **瓶颈是电荷之间的近邻耦合，不在块内（实测）。** 括号实验（研究三光 + 光镊，σ = 20）：
   - 精确的块对角逆（含回收和折叠 rest）每列 13.25 步，与今天的 13.5 步相同；
   - 精确的"可分离晶格"逆（所有左右因子，含近邻步）5.75 步；
   - 精确的"无 rest 晶格"逆 4.75 步。

   今天的预条件下，预条件算子的谱均匀分布在 |θ−1| ≲ 0.35 的圆盘里（30 步 Arnoldi 收敛到 1e-15；没有离群值，min |θ| = 0.75）。因此 GMRES 稳定地按每步约 0.3 收缩：1e-6 需要 12–14 步。**deflation 和回收对这种谱没有用。**
2. **Floquet 框架（推导 + 实测）。** 晶格的可分离部分是左、右两个 Floquet 算子的 Kronecker 和，可以被电荷卷积（微动核）精确对角化。今天的本征框架就是核支撑 {0} 的特例。核取一阶（Brillouin–Wigner 自洽），再在中心块加一个 Woodbury（回收、GG rest、迹行）。效果（实测）：
   - 稳态：主解 31–43 → 18–22 步，每次应用的预条件成本 ≤ 今天（Woodbury 只放在中心块）；
   - 小极点 σ = 0.02：35–42 → 14–15 步；
   - 复移位 0.5–2 + 13i：23–28 → 7.8–9.1 步；
   - σ = 20：13–14 → 7–9 步。

   **内层步数对移位几乎不再敏感**（Re σ ≥ 0.5 时 6–9 步，0.02 时约 14 步）。这对 R1 的自适应极点、近零极点和复极点是关键。
3. **成本账（实测）。** Floquet 预条件每次应用 ≈ |K| × 今天的框架成本（K = 核支撑大小，3–7）。
   - 光镊研究模型：算子以折叠 rest 为主（三光的 5.8M MAC 中 rest 占 86%）。σ = 20 时每列内层 MAC 减少 20–36%。
   - 无光镊模型：算子与框架同价（约 3–6M MAC）。σ = 20 时 MAC 增加 20–67%（把核限制在中心一壳时持平）；墙钟大致持平，因为正交化（受内存带宽限制，∝ 步数²）省下了一部分。
   - 小极点、稳态、复移位：所有用例都大幅受益。
4. **目标"每列 3–5 步、单次应用 ≤ 1.5× 成本"没有达到。** σ = 20 时只到 7–9 步、1.2–4.6×。剩余步数来自光镊折叠 rest（约 1 → 4.75 步）和回收（约 1 步）；可分离部分的一阶截断只差约 1 步。
5. **内层容差不能放松（实测）。** 1e-4 时三光需要 2 倍列数。配 Floquet 时 1e-5 已经让五光的外层不收敛；1e-6 在两个五光用例上也不收敛，1e-7 在全部 5 个用例上都与今天的结果一致（同样的列数和估计）。残差准则依赖预条件器：同样 1e-6 的残差下，Floquet 的总误差更小，但中心布居里的误差更大。机制没有弄清（第 6 节）。
6. **Krylov 回收（GCRO-DR）。** σ = 20 时无用（13.85 → 12.2，墙钟反而增加）；只有小极点有用（Floquet 下 13.8 → 11.9，块框架下 41.7 → 30.0）。

## 2. 方法（推导）

**2.1 Kronecker 和。** 记左因子为 A_t：电荷 0 时是 NL'（L0 加上可吸收的折叠），t ≠ 0 时是显式步的左部分；右因子 B_t 同理。可分离晶格算子为

  (S x)_q = Σ_t (A_t x_{q−t} + x_{q−t} B_t) − iν_q x_q。

定义左、右 Floquet 算子（两侧都带 −iν_k）：

  (𝔄f)_k = Σ_t A_t f_{k−t} − iν_k f_k，  (g𝔅)_k = Σ_t g_{k−t} B_t − iν_k g_k。

取中心族的本征向量 𝔄P = PΛ、Q𝔅 = MQ，按电荷分量写成 n×n 矩阵 P_k、Q_l。代入可得（ν 对电荷线性）：

  S 𝒫𝒬 c = 𝒫𝒬 (Λc + cM − iν_q c)，其中 (𝒫𝒬c)_q = Σ_{k,l} P_k c_{q−k−l} Q_l。

所以在无穷晶格上 (S − σ)⁻¹ = 𝒫𝒬 D⁻¹ 𝒬⁻¹𝒫⁻¹，D 是逐元素的对角：D(α,β,q) = λ_α + μ_β − iν_q − σ。逆卷积核取符号 P(θ)⁻¹ 的 Fourier 系数。核支撑 K = {0} 时，这正是今天的本征框架预条件（单元测试 `lattice_floquet_frames_with_the_central_support_are_the_eigenframes` 验证到 1e-10）。

**2.2 Hermitian 半。** Lindblad 形式下右侧数据是左侧的共轭（第 1 节实测），由此得 Q_l = P_{−l}^†、M = conj Λ + c。因此帧坐标满足 c_{−q} = c_q^†：每个双侧变换只需在规范模（canonical）上算外层一侧，内层一侧在"规范模需要的邻居"上算。

**2.3 一阶核（Brillouin–Wigner）。** 设 A_0 = V Λ₀ V⁻¹。对每个强步 s，取

  P_s = V X，X_{aα} = −(V⁻¹A_s P_0)_{aα} / (λ₀_a − λ_α − iν_s)，A_eff = A_0 + Σ_s A_{−s} P_s P_0⁻¹。

两式自洽迭代：每次重对角化 A_eff，上限 12 次；本征值变化停在约 8e-10（实测），停滞的原因是本征值配对的噪声。单遍构建约 6 ms。逆核用 Neumann 级数到二阶：P̃_s = −P_0⁻¹P_s P_0⁻¹，P̃_0 = P_0⁻¹ + Σ_s P_0⁻¹P_sP_0⁻¹P_{−s}P_0⁻¹。若某个元素的 |分子/分母| > 0.5（近共振），就从核里剔除，留给 GMRES；每个用例剔除 1 对。

**2.4 支撑规则（强度规则）。** 先用全部 mixing > 1e-4 的显式步算出一阶核，再保留 ‖P_s‖_F/‖P_0‖_F ≥ κ 的步对，用它们重建框架。实测核大小只分两档：主拍频对约 0.08–0.11，其余约 0.008–0.011。
- κ = 0.05：只保留主拍频对，|K| = 3；
- κ = 0.005：保留全部，|K| = 3/5/7。

注意：按先验 mixing（size/ν）排序会选错步对（四光时取到 0.011 的那对，完全无效），所以必须按核范数选。

**2.5 中心 Woodbury。** 把回收和折叠 rest 的 GG 行与 GG 列（秩 128，与 `StructuredDressed` 相同）变换到中心 Floquet 帧，只修正中心块。稳态再加迹行；roundoff 级的分母移到 −σ_reg 并精确修正。非中心块的 GG 布居分母含 −iν_q（|ν_q| ≥ 576 ≫ Γ），回收在那里只是小扰动，所以不需要在每块都放 Woodbury。

**2.6 复移位（推导 + 实测）。** 分母变成 λ_α + μ_β − iν_q − σ。帧本身不依赖 σ，条件数不变（实测 2.1–3.8）；Re σ > 0 时 |D| ≥ Re σ。复 σ 下场不再 Hermitian 对称，必须用复 GMRES 覆盖全部模。每步需要 2 次实算子应用（x 的两个 ‡-对称部分）加一次全模预条件（约为半模的 1.4×）。一次复求解给出一对共轭极点的两列实方向，所以每个实列的成本与实极点相当。平移极点 σ + iν_s 实测同样便宜（6.2 步）。

## 4. 对任务六个条目的回答

1. **块三对角 / 成对块。** 电荷对的稠密块是 2048 维，单次分解约 3 GMAC、单次求解约 4M MAC，代价远超今天的整个块预条件。真正需要的结构是 Floquet 微动；它就是"沿强步的块三对角"的解析形式，成本只有 |K| × n³。
2. **Schur 补（把下一近邻壳折进中心）。** 第 2.3 节的 A_eff = A_0 + Σ A_{−s}P_sP_0⁻¹ 就是这个 Schur 补，即 Brillouin–Wigner 有效生成元。单独用它而不配微动核，只改善中心块，效果有限（推断：支撑 {0} 而 A_eff 有效时，相当于"框架 + 二阶光移"）。必须与微动核成对使用。
3. **两层 / deflation。** σ = 20 时谱没有离群值（实测），deflation 无效。在小极点处，"慢子空间"由中心 Woodbury 精确给出，比数值 deflation 更便宜也更准；GCRO-DR 在此基础上还能再省约 15%。
4. **跨移位 Krylov 回收。** 同一移位跨列：见第 3.5 节，只在小极点有价值。跨不同移位（GCRO-DR 的移位不变子空间）：σ 与 0.02 交替时，σ = 20 一侧没有可回收的东西；推断收益限于小极点一侧。
5. **复移位。** 见第 2.6 节和第 3.4 节。Floquet 框架下复移位成本与实移位相当，步数几乎不随 Im σ 和 Re σ（≥ 0.5）变化；条件数由帧决定（2–4），与 σ 无关。今天的框架在 Re σ ≤ 2 时退化到 23–28 步。
6. **内层容差。**
   - 推导：不精确解满足 (σ−A)V H̄ = V + F，残差中多出 −F c(t)。它被基于像的精确 Galerkin 残差完整包含，所以误差估计不会被骗。实测也是如此：失败时估计一直很大，从未错误接受。
   - 松弛理论要求 η_j ∝ ε/|c_j(t)|。σT = 400 时有理 Krylov 坐标 c_j 在最后约 20% 列之前不衰减（推断），可放松的空间几乎为零。
   - 实测更强的结论：放松破坏的是外层收敛（产生伪增长 Ritz 值），不是估计。而且敏感性依赖预条件器：同样的残差下，更强的预条件把剩余误差集中到中心布居方向。
   - 建议：Floquet 框架下固定 1e-7（五个用例全部验证，每列 7.7–9 步）；不做跨列松弛。按误差而非残差停机是对的方向，但阈值要按用例标定（τ_pop = 3e-9），还不够原则化。

## 5. 它替换今天流水线的哪部分

- 替换 `preconditioner.rs` 的 `StructuredDressed` 和 `StructuredBatch`：本征框架 → Floquet 框架；每块的秩 128 Woodbury → 只在中心块。同一个对象服务所有场景：
  - 稳态（σ = 0 + 迹行）；
  - 实移位（任意 σ > 0，包括 0.02）；
  - 复移位；
  - 慢模的 shift-invert（推断：与稳态同一系统）。
- `finite.rs` 的 INNER_RTOL：1e-6 → 1e-7，并与预条件器绑定。
- 不需要：成对块、多重网格、σ = 20 时的 GCRO-DR。

## 6. 风险

- **内层误差方向敏感（未解释）。** 残差 1e-6 时五光外层停滞，原因未查清；1e-7 在 5 个用例 × 20 µs 和 2 个用例 × 10 ms 上验证过，没有覆盖更多场景：三阶只测了内层，没跑端到端；Raman 共振和更多激光都没测。
- **无光镊模型在 σ = 20 时不划算。** 需要成本感知的 κ / 壳选择（第 7 节）。
- **框架构建：流水线里实测 100–230 ms。** 单遍框架只要约 6 ms；大头是 κ 规则的两遍构建，加上稠密 W（1024² 复数）和秩 128 的帧变换（朴素循环实现）。可以优化：复用 `StructuredDressed` 的 W 和 GEMM。
- **稳态估计依赖 Krylov 空间。** 五光的 GCRO 延续估计从 4.48e-3 变成 4.71e-3，离 5e-3 更近，这是 R2 的问题。
- **近共振的帧对被剔除。** 每个用例 1 对，Raman 共振场景可能更多，会退化为 GMRES 负担。
- **小 GEMM 效率。** 每次应用的预条件耗时约为 MAC 比例的 1.2–1.3×：32³ 的小 GEMM 加 4 级串行。把同一级的 |K| 个核拼成一个 n×(|K|n) GEMM 可以改善。
- **微动核低秩。** 核在相对 1e-2 下秩约 9–11（共 32），低秩应用能把 |K| = 7 时的成本降约 30%（推断，未实现）。

## 7. 给综合的建议

1. **采用 Floquet 框架 + 中心 Woodbury 作为唯一预条件器。** 强度规则用核范数 κ：步对的一阶核 ‖P_s‖/‖P_0‖ ≥ κ 才进入支撑。这与显式/折叠/略去的规则同构，都由运行时的小参数决定。
2. **κ 和壳要成本感知。** 每步成本 = 算子 + |K|·框架 + 正交化(m)。
   - 小极点、稳态、复移位：一律 κ = 0.005（2–3 倍收益）；
   - σ ≥ 10 时，算子 ≥ 2× 框架才扩大支撑。
   - 实际划分：有光镊 κ = 0.005；无光镊只放中心一壳，或用 κ = 0.05。
3. **R1 可以自由放极点（推断）。** 内层成本几乎与移位无关：Re σ ≥ 0.5 的复极点每列 7–9 步；近零极点约 14 步，加 GCRO-DR 约 12 步。平移极点 σ + iν_s 同样便宜。
4. **内层残差容差 1e-7，并且固定。**
5. **正交化受内存带宽限制。** 无光镊用例中它占内层时间 30–45%。DCGS2（每步一次同步、一次基读取）可以减半，这是实现项。
6. **剩下的大头是光镊折叠 rest。** 约 1 → 4.75 步，同时占算子成本 86%。它和 R4 的折叠表示是同一个问题：在 rest 更便宜或可预条件的表示下，每列 3–5 步才有可能。
