# atom-motion：3D 半经典运动求解器（CPU 版）规格

本文件是新求解器的唯一规格。代码里的每个量、每个决策都要能对应到这里的一条；对应不上的，要么删，要么先改本文件。
推导和证据在提炼稿里（`C:\Users\eadri\WorkCode\motion3d_status\rewrite\`：field、internal、propagation、decisions、contract），本文件只写结论和规则。

## 0 范围与原则

- 取代 `atom-motion-3d`（冻结于 62d4d206，只读参考，不再修改）。与界面的契约不变（§9）。只做 CPU；GPU 等 CPU 版完整、正确、优化之后再议。
- 硬约束：没有特判，没有 magic number，没有多套实现，没有冗余。
- 每个量只有一个定义（下文标出定义处）；每类决策只有一条规则（§5）；决策只有三种结果：在内、细化、标记。
- 允许的常数只有这几类，每个写明来源：
  - 用户的目标：布居与损失 0.05（绝对），T 0.10（相对）。只描述被俘获原子的量（T、模型误差）按持有份额 1 − L 计权，损失按自身：这是用户对目标的定义，不是推导；
  - 格式的阶 p = 2（对称分裂）；统计置信度 z = 2；
  - 物理常数；浮点格式（ε）；
  - 由以上推导出的值（写出推导）；
  - 经典区边界 k_BT ≥ 4ħω：方法的验证范围，与界面镜像（文字、灰带）。它只用于报告，不参与求解的任何决定（T 的目标在总温度上，§3）。
  - 契约定义的量：区域的光强判据 1/20（界面文字里的损失定义，REGION_INTENSITY）；资源上限：轨迹 2¹⁴；步长的下限是时长/2²⁴（到了照常返回并标记）；时长上限 10 s、输出点数上限 2000；直方图的 21 个时刻；检查点间隔 60 s（界面 120 s 规则的一半）。
  - 已发表算法自带的常数（Philox 的乘子与轮数、QR 迭代的例外位移）。
  - 结构量：拉丁超立方的组大小 8（§2.5），它也是 jackknife 每次删去的块。组内每条轨迹的分布与独立抽样相同，各组相互独立，所以组大小取多少，估计所用的各个均值的期望都是系综的，jackknife 的方差都是各组均值的方差。在同样的轨迹数下，组大小只是拿每个变量的分层数（等于组内条数）和每个输出保存的和（每组一份）去换读离散用的组数（Student 的自由度是组数减一）。
- 单位：长度 µm，时间 µs，能量与频率 rad/µs，κ = p/ħ（1/µm），温度 µK，场 V/m，波数 rad/µm。

## 1 物理模型

### 1.1 原子
- 32 态：8 个基态（5S½ F=1、2），D1 8 个、D2 16 个激发态。H0 由请求给出，必须在模型基里对角。
- 发射算符 C_a（a = x, y, z，基 ← 激发），D = Σ_a C_a†C_a。

### 1.2 光场（定义：`field`）
- 光束振幅 a_l(r)：焦点在原点的傍轴高斯光束（含 Gouy 相位与波前曲率），或平面波；∇a_l 解析。
- 每束光的焦点场 E_l（球分量 q = −1, 0, +1，含偏振与初相）由请求给出，**必需**。
- 每个频率一个相干场：E_ω(r) = Σ_{l∈ω} a_l(r) E_l；耦合对场线性：V_ω(r) = Σ_q E_{ω,q}(r) D_q。同频光束彼此相干，相位取请求的值（前提：相对相位的漂移比原子动力学慢得多）。
- 相干矩阵 T_ω = E_ω E_ω†（每个频率至多 9 个实数坐标 x_{ω,i}）。
- 光不分“远光”与“近光”。每个频率的光有同旋、反旋两个分量；一个分量把一个基态 g 耦合到一个激发态 e 的那个矩阵元叫一个**驱动**。每个驱动各自取三级之一（§1.4），由它自己的分母决定（§1.5、§5.2）：不看频率，不看谱线（D1/D2），不看是哪束光，也不看是不是阱光。
- 按裸能级折叠的驱动：响应取在裸能级上，R = (K₀ − E_b − ν)⁻¹V，K₀ = H0_ee − (i/2)D，分母里没有光，所以 R 对场线性、各项是常数，在原子处精确计算，不进表。
  它与 §1.4 的折叠是同一个二阶消去，只是响应取的能级不同：基态块就是 §1.4 的那个缩并 −½(V′†R + R′†V)，散射是同一个响应的跳跃算符 C_a R（散射不丢）；激发态块是经基态的 van Vleck 式（基态不衰减，实分母）。
  激发态块的分母取在“读它的态”的能量上：消去折叠驱动 U（e ← b，频率 ν）的基态 b，激发态得到自能 |U|²/(z − E_b − ν)，z 是读它的那个态的能量。自己也被折叠的激发态在自己的能量上读（z = E_e，分母是单光子距离 β = E_e − E_b − ν）；被另一个保留驱动 V（e ← a，频率 ν_V，失谐 ε）变成显式的激发态由它所在的簇读：它的振幅跟着簇的基态转，z = E_a + ν_V，分母是拉曼对 (a, b) 的双光子距离 d_R = E_a + ν_V − E_b − ν = β − ε（簇有几个基态时取它们在簇的帧里的平均，`Model::read`；按原子处能级折叠的驱动同样，取原子处的能级）。不用单光子的实分母 1/β（β = 0 处有极点而那里什么都不共振），也不用单光子的复分母 1/(β − iΓ/2)（那是寿命 1/Γ 的瞬态的读法）。三能级精确对照（V = 0.5Γ，ε = Γ，U = 0.2Γ）：保留谱线的速率用 1/β 在 β = 0.5/0.1/0.02 Γ 处低 14/38/82 %，用复分母低 16–18 %，用 1/d_R 在 0.1–3.8 % 内（拉曼对自己的下一阶）。1/d_R 的极点是拉曼共振，那里这个折叠不存在，由拉曼对的门拒绝（§1.5）。|β| ≫ |ε| 时两个距离相同。
  基态块含线宽：失谐 Δ 的一条线上它是色散型的 −|V|²Δ/(Δ² + Γ²/4)，比实分母的 −|V|²/Δ 小 (Γ/2Δ)²（失谐几十 THz：约 1e-14；20 GHz：约 2e-8）。光移与散射出自同一个响应。
- 常数形式：两个频率 ω′、ω 的场在拍频 δ_ω′ − δ_ω 上给出同一种形式 Σ e′_k′* e_k C_k′k，由三项组成：外层形式的交叉项（取两个频率外层形式的平均）、同旋的二阶项（发射 ω′、吸收 ω）、反旋的二阶项（发射 ω、吸收 ω′）。
  - ω′ = ω（拍频为零）就是该频率的静态形式：Σ_i x_{ω,i}(r) O_{ω,i}（请求给出的外层形式）+ 它按裸能级折叠的驱动的二阶移。
  - 它的每个矩阵元 a ← b 是一个耦合单元（§5.2），不静默丢弃：在簇的帧里残余拍频恰为零，或该单元被保留，它才进入生成元；否则折叠，误差记账。
- 同旋与反旋的交叉项以两倍光频拍动，不在模型里（请求的外层形式里也没有这一项）；两个折叠都存在时它的混入是两者之积，四阶。反旋驱动只按裸能级折叠：这是模型的适用范围，它的折叠不存在（同一个门，每束光取峰值）的请求被拒绝。
- 坐标图：每个频率的场用有界坐标（光强 I ∈ [0,1]，偏振超球角，相对相位）；表只用于近光消去的非线性部分（§2.3）。

### 1.3 势（定义：`model::potential`，全程只此一个）
V_L(r; p) = Σ_b p_b [h_L(r) − h_{L∖阱光}(r)]_bb
- h = 消去后生成元的静态厄米部分（与动力学用的是同一个）；p = 基态布居（只在基态上归一）；L = 当时开着的光；阱光 = 光镊所在频率的整个场。
- 派生量全部由它给出：
  - 损失能量 E_s = ħ²κ²/2m + V_run(r; p(ψ))。p(ψ) 是 ψ 衰变回基态之后的基态布居：p_b = (|ψ_b|² + Σ_e β_{b←e}|ψ_e|²)/‖ψ‖²，e 取簇里的显式激发态，β_{b←e} = Σ_a|C_a[b,e]|²/D_ee 是它的分支比。显式激发态只存在 1/Γ，远短于任何运动的时间，原子之后感受的是它落到的基态的势。这个定义对布居线性、和为 1，对任何 ψ ≠ 0 都有值：没有显式激发布居时就是 ψ 的基态布居；全部在显式激发态上时（没有基态布居）是它将落到的基态的布居；
  - 准备势 V_prep(r; ref)（t = 0 之前只开阱光）；
  - 阱心 = V_prep 从焦点下降到的局部极小；不存在极小 → 拒绝（"光镊不约束原子"），不退回焦点；
  - 阱频与主轴：准备阱（V_prep 在其极小处的 Hessian）给初始系综的 Wigner 因子；运行阱给报告的 `trapFrequencyKHz`、n̄、经典区判据与 T 的窗口周期——它们描述把原子困住的阱：阱光的势（保留阱光自身的干涉，所以反射光镊按格点报），加上其他光的平滑光移（每束光只取自身光强，光束之间的相位全部平均，所以没有波长尺度的条纹；近共振光的条纹属于冷却动力学，不是阱），参考态，在其极小处的 Hessian。其他光的平滑光移就是它的驱动按原子处能级折叠时的光移，只要这个折叠在阱心处存在（同一个门，取在准备阱的阱心、原子静止；把这些驱动都放到原子处，同一基态的驱动按尾和规则，门不成立的驱动改为显式，直到都成立；两个基态之间的耦合照模型已保留的那些，它们决定读光移的簇），就按它读，不论动力学把该驱动放在哪一级：这种光移在阱内的变化全部来自阱光对它的谱线的移动，按裸能级折叠的驱动只有常数、不含这一项（它是那个级数的首项，误差在动力学里记账），显式保留的驱动在模型里是簇内的动力学；报告量属于场景，不能随求解把哪个驱动留在哪一级而变。在阱心处折叠不存在的驱动（例如在阱心共振的推出光）没有光移可言，仍是动力学，不进这个势。经典区判据 k_BT ≥ 4ħω 正是在光镊加冷却光的一维量子参照上、以这个 ω 验证的；V_run 没有极小时（运行的势不束缚原子），这些量按准备阱报告并标记“运行中的势没有极小”；
  - 区域：光镊的光（与光镊同频的各束光：光镊、它的反射光、同一激光的交叉光束）在原子处的强度都低于焦点处的 1/20 即为区域外（与界面文字一致）。区域内的原子不论能量都被持有，区域外的在损失能量不高于远处值时也被持有（§1.7），可达范围据此在区域上截取（§1.8）。只有阱光构成光阱：按束腰给出的探测光、冷却光也是聚焦光，但束腰在毫米量级，被它推出光镊的原子沿它飞出几米（√19 z_R）都还在它的 1/20 光强区里，若按它算就永远不会丢失（v2026.11.11.2/.3 的错误）。

### 1.4 内态生成元（定义：`model`）
- 簇：被保留的耦合连通的态集合（基态加显式激发态）。哪些耦合保留由 §5.2 决定。
- 一个驱动的三级。每一级是前一级更精确的一级；一个驱动恰好取一级，即它被保留的单元给出的最高一级；簇内两态之间残余拍频恰为零的驱动不需要单元就是显式的：
  - 按裸能级折叠（§1.2）：常数；
  - 按原子处的能级折叠（下面的缀饰消去，进表）；
  - 显式：V 直接进入生成元。
  “载波”是有驱动不取裸能级的同旋分量：由各驱动的级推出，不列出。
- 按原子处能级的折叠（二阶 Reiter–Sørensen，按构造是 Lindblad 形式）：
  R_c = (K + Σ_b(z) − z)⁻¹ V_c^a，K = H_ee − (i/2)D，z = E_b + δ_c + 缀饰移；V_c^a 是载波 c 取这一级的那些驱动。
  自能 Σ_b(z) 是激发态通往别的基态的通道：通往簇外基态、按原子处能级折叠的通道，以及保留（显式）驱动的通道——后者只要与 b 这条通道不是同一个 Floquet 态（a 在别的簇，或在同一簇的帧里两者的残余拍频不恰为零）。被保留驱动 V 缀饰的显式激发态因此在 b 的响应里是 U/(β̃ − |V|²/d_R)，不是未缀饰的 U/β̃（后者的光移差 |V|²/(β d_R)、速率差两倍；三能级 V = 2Γ、β = 27.4Γ、共振：−0.53 % 与 −1.06 %，带上这一项 1.6e-4）。
  有效项 X_ab = −½(V′^f†R + R′†V^f)：两个频率各出一条腿，耦合 V^f 取该频率全部折叠驱动（裸的也在内），响应 R 取原子处的。折叠项对耦合与响应是双线性的，所以裸折叠的常数（§1.2：同一个 V^f 配裸响应）加上这一项就是全部，没有“混合对”的特例。衰减是跳跃自己的乘积 −(i/2)Σ J†J，J = C_a R；读出度规 Y = Σ R′†R。
- 折叠的下一阶（四阶，按需，§5.2）：簇里只有基态、按原子处能级折叠的驱动同属一个频率时，该簇的折叠可以取到四阶。
  - 无跳生成元的慢不变子空间 Ψ = (x, Wx)，W = −R + W3，W3 = −R2 N；在正交坐标 y = (1 + X)^{1/2} x 下，用二阶自己在簇上的三个矩阵——N = −V†R（厄米部分是光移 S，反厄米部分是模型的衰减 −½ΣJ†J）、Y = V†R2（多普勒伙伴 D 的两倍）、X = R†R（读出度规）：
    H⁽⁴⁾ = Herm[−Y N + ½[X, N]]，跳跃 L̃_a = J_a(1 − ½X) + J2_a N，衰减仍是跳跃自己的乘积 −(i/2)ΣL̃†L̃。
  - 三个矩阵在该点各算一次（连同梯度；同一线程上一步的中点与它的散射共用这一次）：S、D 之外，这样的簇里每个光束对的形式还带度规 X 与损耗 L = T′†D T，与 S 一样进表。由它们：
    - 中点的 H⁽⁴⁾ 及其梯度是 n × n 矩阵的几次乘积；衰减的改变量 Σ L̃†L̃ − Σ J†J 由生成元自己在该点的衰减（按多普勒标志分开读出）与 B = 1 − ½X、N 算出。按标志读出的每一个都是生成元自己各项的反厄米部分：Λ = i(P − P†)（不带多普勒的项之和 P）；带一阶多普勒时响应是 R − wR2、跳跃是 J − wJ2，“吸收分量取多普勒移”的各项之和 G_R = ½V^f†R2 + (i/2)ΣJ†J2，“发射分量取”的各项之和 G_L = ½R2†V^f + (i/2)ΣJ2†J，厄米耦合的多普勒伙伴 ½V^f†R2 在两者里都有，所以 Λ_R = ΣJ†J2 = −i(G_R − G_L†)，不论 V^f 里有哪些频率的腿。（不能用 G_R 减去本频率自己的 Y：簇里保留了两个频率的静态耦合对时，V^f 含另一个频率按裸能级折叠的那条腿而 Y 不含，它的厄米多普勒伙伴会被读成衰减——R6_RAMAN_CO 保留拉曼对并取四阶时，生成元的衰减与光子速率相差 ±6e-3，符号随哪条腿在原子处而变；改后 1e-12–2e-11，与没有这种对时相同。）两者在步内与该点的形式一样取在中点（在簇的多普勒参考系里）：节点上加 n² 个数，力每个轴加 n² 个数。力仍是生成元厄米部分的梯度。
    - 光子：跳跃的矩阵作用在 (1 − ½X)ψ 上，伙伴的矩阵再作用在 Nψ 上；簇的每一个跳跃（裸折叠的、远光的也在内）都作用在弯过的态上，因为基态振幅就是 (1 − ½X) y。
    - 跳到一个四阶簇的裸基态 f 之后（`Model::landed`）：慢态是 Π f，Π = 1 + ½X − Y，轨迹带着它的范数继续，不归一。裸态 = 慢态 + 在 1/Γ 内消失的快部分；此后 ‖ψ(t)‖² → ‖Π f‖² e^{−γt}，所以 ‖Π f‖²/‖f‖² = 1 − p 是裸态的存活概率外推回跳跃时刻的值。一条线上 p = 2Re Y − X = (s/2)(Δ² − 3Γ²/4)/(Δ² + Γ²/4)，两种符号都有：远离谱线 p > 0（s/2）——快部分立刻再发一个光子；|Δ| < 0.866Γ 时 p < 0（共振处 −3s/2）——发完光子原子在基态，激发振幅要 1/Γ 才建立起来，下一个光子来得晚（反聚束）。两种情形是同一句话：范数与下一次跳跃的阈值 θ 比（`step` 的 `jump`），等待时间的分布是 P(T > t) = min(1, (1 − p)e^{−γt})。范数高于阈值就等：等于 1 时与二阶一样（二阶的运行不变）；低于 1 时按阈值分布剩下的部分等；高于 1 时多等衰减到 1 所需的 ln(1 − p)/γ。范数已经不高于阈值（只有范数低于 1 时才会，概率 p）就由裸态立刻再发一个光子（类、偏振、方向、反冲与有界的踢都与任何光子一样），重抽阈值，再落一次。没有按符号的分支，也不把 p 钳在 0（钳位时 p < 0 被丢掉，共振处速率高 1.52 s，比二阶的 +s 还差，而记账的是 s²）。平均间隔：p ≥ 0 时 (1 − p)/γ，p < 0 时 (1 + ln(1 − p))/γ，两者都与精确值差 s² 量级（二能级对精确稳态速率 1/(1+s)：共振处 +1.07 s²，远失谐 −0.99 s²，任何失谐下不超过 9/8 s²）。与精确消去的谱投影对照，p 差 0.6 s²。
  - W3 每列只用一个分母：簇内基态能级之差远小于驱动的距离时精确，其余记在该级的误差里（§1.5）。

### 1.5 消去的存在与误差（推导见 internal.md 1B）
- 一条规则，对每一种单元都是同一句话：把大小为 size 的耦合跨过距离 distance 折叠，m = size/distance。
  - 静态：S = 2m² < ½ 时折叠存在（Stewart 1973：m < ½ 时不变子空间存在）。
  - 运动：a = rate/distance² < ½，rate = |dΔE/dt| = v·∇ΔE + q·v̇（q 是该项的波矢，v̇ 取原子所在簇里力的界）。这是与静态边界同一相对误差（约 0.7）的门，不是存在性定理。
  - 两个条件互不蕴含，都要满足；不满足就必须保留（数学门，不是取舍）。½ 是唯一的阈值。
  - 扫过是折叠自身效果的相对误差：线性扫过的精确响应是瞬时折叠乘 I(a) = ∫₀^∞ e^{−x + iax²/2} dx，任何 a 下 |I| ≤ 1（internal.md 1B.1），所以运动中的折叠至多差它自己振幅的两倍，(2m)² = 2S 的布居，不论扫得多快。所以扫过对着这个量与任何输出分辨得出的最小份额 unseen(2¹⁴)（§5.4：账本感受不到的份额）中较大的一个读：a·min(1, 2S/unseen)（`Gate::resolved`；驱动在状态上记账的运动项同样）——折叠的效果分辨得出时就是扫过本身，低于分辨时随它一起缩小。连续而单调，格子上的界才趋于点上的值（在 2S = unseen 处截断时，界是跳的：一个耦合在格子上的 S 稍高于截断、扫过 0.8–8，格子中心稍低于截断、读 0，证明永远不结束）。（用户 lin⊥lin 场景：H0 本征态混合给回泵光的 1e-9 量级耦合，在光镊光移梯度上扫过，a = 0.5000，它的证明占 473 µK 那次证明 133 s 的 95 %。）
  - 门不在范围上证明（2026-11-13 起）：第一个模型什么都不保留；哪个单元保留只由先导/侦察状态上实测的误差与 §5.2 的保留规则决定（QuTiP 式的实测误差控制）。折叠在原子所到之处不成立时，它在那里实测的误差就是它自己的小参数（S ≥ ½ 时至少是它的态布居的四分之一），没有一个输出放得下，按 §5.2 保留。门的陈述只在一个点上求值（准备与报告的阱、退化拉曼对的连簇，§1.4），不再在格子上证明。
  - 每种单元只提供三样东西：自己的 size、distance、rate，在一个点上（原子所在处）求值。
- 驱动：size = |Σ_l a_l X_l[e,g]|。它的失谐在一个格子上是中心值 Δ_c 加减 moved：两个能级在格子内的移动余量、消去所取的能级与能级本身之差（§1.4：载波自身偏振单元之间的干涉在分母里被平均掉的那些光束对）、别的载波的缀饰、多普勒移 k·v、激发态之间耦合的 Gershgorin 半径、自能的界。rate = v·L + k·a_max。
  - 按原子处能级折叠：原子处的能级持有静止的原子——它的能级、缀饰、自能都在分母 D 里；运动原子吸收第 l 束光的光子有多普勒移与反冲 w_l = (ħ/m)(k_l·κ + k_l²/2)，响应只取到一阶 T − wT2，即 (D + w)⁻¹ 按 ε = w/D 展开的前两项。这是两个展开，各有自己的小参数：|V| 跨过运动原子的实际分母 |max(|Δ_c| − moved, 0) − iΓ/2| 的折叠（它的份额，多普勒移作为失谐的区间，进尾和），与围绕静止原子的 ε 级数。各自在一个门说成立的地方成立——尾和低于 ½；级数自己的门，|w|（≤ k v_max + (ħ/m)k²/2）跨过静止时的分母 D = |max(|Δ_c| − moved_静止, 0) − iΓ/2|（moved 去掉多普勒移那一项）的门低于 ½，即 |ε| < ½，与裸能级的级数同一个余量——驱动的门取两者中较大的。份额不是级数的门：|V| < Γ/4 的驱动在任何速率下份额都低于 ½（实际距离不小于 Γ/2），而 |w/D| > 1 时级数发散：v23 的失控就是共振探测光的循环跃迁按原子处能级折叠、被推出去的原子上 |w/D| ≈ 85。（裸能级的构造——|V| + |w| 跨过 D 的一个门——两者都说，但比每一个都严：(|V| + |w|)/D 比实际距离上的 |V| 大约 (|w|/D)(1 − |V|/D)，比 |ε| 大 |V|/D；S2 的回泵光在原子处、30 µK 的范围上读成 0.4998（份额 0.47），范围的证明是一个阈值落在它的量的最大值上，内存用尽。单元测试 `units::tests::a_drive_at_the_atom_fails_where_its_doppler_series_diverges`。）实测（2026-11-12，d0f18611 对 709856c8）：PGC3D、四面体 MOT、GMD1C 1 ms，R3_DOPPLER 种子 0–3，R4_LIN_2，R6_RAMAN_CO/COUNTER，R9_PUSH，S1、S2、S2Q 的结果逐位相同——这些场景里没有一个模型改变。
  - 按裸能级折叠：裸响应 V/(Δ₀ − iΓ/2) 是按 ε = δΔ/(Δ₀ − iΓ/2) 展开的级数的首项，δΔ 是它的两个能级在原子处被别的光移动的量加多普勒移与反冲。裸能级是围绕 H0 的微扰论：它跨过裸距离 |Δ₀ − iΓ/2| 折叠掉的，是两态之间 H0 没有的一切，即耦合与能级的移动。所以它自己的门取 size = |V| + |δΔ|（能级往哪边移都算）、distance = 裸距离。门内折叠存在（|V| 对剩下的距离 |Δ₀ − iΓ/2| − |δΔ|），级数收敛且 |ε| < ½；门内它的误差是级数的一阶，在原子处实测。
- 折叠到显式激发态上的驱动是拉曼对的一条腿（两级都一样）：驱动 U（e ← g）与 e 的每个保留驱动 V_a（e ← a）构成一对，除了自己的门还有这一对的门——同一个门，size = |U||V_a| 除以两个单光子距离中较近的一个（两态之一含另一态的振幅就是它除以双光子距离），distance = 双光子距离 |E_g + ν − E_a − ν_a| 在格子上的界（中心值，加减 E_g − E_a 这个差在格子上移动的量：常数形式的对角之差，与两个态的耦合取距离的方式相同——两个能级一起移动的光移不移动距离；原来取两个能级各自移动量之和，光镊的共同光移被算了两次），减去双光子的多普勒移、两个基态被按原子处能级折叠的驱动移动的量、被保留驱动移动的量（耦合 v、距离 d 的保留驱动至多移动 min(v, v²/d)），rate = v|∇(E_g − E_a)| + |q − k′|·a_max。这一对的耦合 U V_a* 在空间里按 e^{i(q − k′)·r} 转（q 是折叠驱动的光子 k_l，反旋分量取 −k_l；k′ 是保留驱动的），运动原子的双光子失谐移动 (q − k′)·v，至多 |q − k′|·v（两个分量各束光之间取最大）：同一束光的两个光子为零，对射的为 2kv。（原来取 |q| + |k′|：同一束回泵光在 F=1 m=1 与 m=0 之间的一对（相距 2.1 MHz），在 0.53 µm/µs 的原子上连同能级移动，界读到零，门对 |U V|/d = 1e-18 rad/µs 的双光子耦合读成 ∞。）拉曼对是两个慢态之间的二阶耦合（g 与 e 所在簇的态 a），与两个态之间的耦合是同一种东西，不是 g 的某个激发态振幅：它是自己的陈述，单独判定，不进尾和（见下一条）；不成立就保留这个驱动，与别的驱动一样。按裸能级折叠时，e 被保留驱动移动的量（自能 |V_a|²/d_R）另外进入它的 δΔ：门里取界，误差里实测。
- 尾和规则：同一个基态的各个折叠驱动分享它的布居，一组折叠存在的条件是它们的份额 2m² 之和 < ½，每个份额按该驱动的实际距离算，不论它取哪一级。
  - 尾和加的是 g 的折叠在它的折叠驱动所到的激发态上的一阶振幅 R[e, g] = V_e/D_e：这一列的模界住 g 这一组折叠是否存在（Stewart，一个基态对它的折叠激发态）。拉曼对的混合不是其中之一：它是另一个慢态在 g 里的二阶振幅 |U V_a|/(d d_R)，d_R → 0 时相对于该驱动自己的份额 |U|²/d² 没有上界，所以在按驱动自己份额排的次序里没有位置。驱动的门值因此取它所在位的尾和与该位各驱动的拉曼对（取最大，与扫过相同）中较大的一个。（原来加在该驱动的位上：一对不成立就让 g 的每个更强的驱动跟着不成立——保留它们治不了，这一对要到它自己的驱动被保留才消失——一直到只能折叠的反旋转项：π 探测光 lin⊥lin 加回泵光的请求因回泵光 F=1 m=1 → F′=2 m=−1 的 1.7e-9 rad/µs 耦合（H0 本征态的混合给的）与 F=1 m=0 的 1.1e-8 rad/µs 耦合构成的一对被拒绝，实测。）
  - 一个驱动的门值 = 该基态的折叠驱动中份额不大于它的那些之和。于是最强的先不成立、先被保留；份额相等的一起；远处的线不会因为近处的线而被保留。
  - 按裸能级折叠的驱动，把它自己那一项换成它自己的门值：裸折叠存不存在是它自己的事，不连累别的驱动；按原子处能级折叠的驱动的多普勒级数也是它自己的事，它的门在尾和旁边取较大者。
  - 次序是每个基态一个固定的次序：每束光取峰值、裸能级下的份额，从大到小。若在每个格子上各自排序，和对格子不单调，可证的界做不出来；谁先被保留只是代价的选择，每个门都是对一个固定集合的陈述。
  - 两个份额之差在各自算术的舍入之内，就算同一位（由对称性相等的驱动只在末位上不同），否则对称的一组会被噪声拆开；同一位、同一级的驱动取其中最大的扫过。
  - 一个格子上、一个点上，和里的每一项都是这个格子、这个点自己的份额：点上的门值就是那里的值。不拿别处的界顶替较弱的位——那不是任何一点的值（实测：两个相等的驱动，一个取全空间的界 0.49，另一个的门在阱心被读成“达到 0.52”，而那里两者各只有 0.03；失谐 20 个线宽的光因此被改成显式）。
- 折叠的驱动对它的能级做的事，按它自己的门来界：耦合 v 跨过距离 d 折叠，基态能级至多移动 v²/d = m·v（折叠存在处小于 v/2）。按原子处能级折叠的各驱动对一个基态能级的移动，逐个驱动取它自己的门在该处读到的距离；这个移动的斜率取其中最近一个的 1/d 作响应的范数。不用共振驱动的距离 Γ/2：那个界是失谐 Δ 的光的真实光移的 2|Δ|/Γ 倍，随光强增长，80 mW/cm²、失谐 20 个线宽时就超过了冷却光子与回泵光子之间的 137 MHz，耦合的距离读成零、门读成 ∞，F=1 与 F=2 被并成一簇。
- 两个态之间的耦合：一个精确拍频 β 上 a ← b 的全部二阶项是一个单元——常数形式的矩阵元（§1.2；β = 0 时连同所有光都关时两态自己的耦合），加上按原子处能级折叠的那一部分。
  - size = 这个矩阵元的界；distance = |β + E_a − E_b| 在格子上的界，减去它的光束对最大波矢的多普勒移和两态各自被按原子处能级折叠的驱动移动的量（上一条的界）；rate = v|∇(E_a − E_b)| + q·a_max（同一个态的拍动，两项都不随它动）。
  - 不超过所在形式求和舍入的矩阵元不是耦合（场的零分量以它所在矢量的末位出现）。
- 两源光子相干：size 是两类光子的跳跃算符大小之积 Σ_a ‖L_a‖‖L′_a‖ 在区域上的界——每个成员的场分量取相干的界，载波在原子处的那部分逐个驱动除以它自己分母的界（与两个态的耦合用同一个界），常数部分照原样；distance = 两个频率之差减去能级移动的界与两个光子的多普勒移；同一个门。沿轨迹实测时 size 取该点的跳跃算符本身。
- 缀饰单元（§1.4 的 T̄）不是消去：它是别的分母里偏振单元之间干涉的平均，自己没有能量分母，所以没有存在门，只有实测误差。
- 首项误差（供 §5.2 映射到输出）：
  - 驱动的折叠（两级相同）：布居 s p_g，T (s + a) p_g，s = 2|R[e,g]|² 是它自己的份额；按原子处能级折叠的另加一阶多普勒的下一阶 (w/σ)²；
    - 二阶缺的只有一项，四阶光移：势深了 s/2，力大了 s，散射率大了 s（一条线上精确：力 ×(1 − s + 3/2 s²)，速率 ×1/(1 + s)）。T 跟着势的调制走：Sisyphus 图样上扩散 +0.6 s、摩擦 −0.2 s，合起来 0.8–0.9 s（实测 +8.8 ± 1.5 %，s = 0.12），是同一项的两个后果，不是两个要相加的误差；力的 s 是它的界，按它记账。原来的 √2 s 是真值的 1.8 倍。
    - 四阶（§1.4）：力 3/2 s²；簇内基态能级之差/驱动的距离 × s（W3 的一个分母）；速率 9/8 s²（连同落点的范数对阈值，§1.4；对二能级原子实测，s = 0.03、0.06、0.12：二阶 +s；四阶的跳跃单独在远失谐处 −s/2、共振处 +3s/2；加上落点，远失谐 −0.99 s²，共振处 +1.07 s²——范数 1 + 3s/2 对阈值多等 ln(1 + 3s/2)/γ，而精确的平均间隔多 (3s/2)/γ，相差 (3s/2)²/2 = 9/8 s²，这是各失谐下最大的）。与精确消去对照（冻结原子，⁸⁷Rb 的 F′ = 1, 2, 3，s = 0.03 / 0.06 / 0.12）：势 s/2 → 0.5 s²，力 0.7 s → 0.9 s²，慢态衰减率 1.5 s → 1.9 s²。
    - 上面的 s 是一条线的。同一基态、同一载波的几个驱动是一个折叠，不是几个：记 D_e 为驱动的分母、a_k = Σ_e |V_e|²/D_e^k，慢本征值是 λ = −a₁(1 − a₂ + a₂² + a₁a₃ − …)，四阶留下的每一项（λ 的、跳跃速率的、落点范数的）都是两个数的乘积，这两个数只有两种：该基态的激发份额（a₂、X），至多 S_b/2 = Σ_e |R[e,b]|²；该能级自己的二阶项除以驱动的距离 a₁/D_e（响应的分母被折叠本身移动），模为 L_e/2 = |N_bb|/|D_e|，N_bb = Σ_e V*R。各驱动在同一距离时两者都是 S_b/2：激发态合成一个亮态，就是份额 S_b = Σ_e s_e 的二能级原子（速率精确为二阶的 1/(1 + S_b)），余项是 c·S_b²，不是 c·Σ_e s_e²。距离不同时近线读到远线的光移，L_e ≤ Σ_f s_f |D_f/D_e|，不受份额约束。所以四阶时驱动的这条线差 c·max(S_b, L_e)²（c 即上面一条线的 3/2 与 9/8），它的单元按它在该基态激发里占的 s_e/S_b 记：布居 9/8·s_e·max(S_b, L_e)²/S_b·p_b，T 上 3/2·s_e·max(S_b, L_e)²/S_b·p_b 加能级之差那一项；同一距离的各驱动合计 c·S_b²·p_b。势自己的余项 |a₂² + a₁a₃| ≤ Σ_e s_e(S_b + L_e)/4 在其内。实测（一个基态到 1–3 个激发态，对精确的平均等待时间）：同一失谐、每个驱动 0.03，余项在共振处 +0.98 至 +1.02 (Σs)²、6Γ 处 −0.99 (Σs)²，是 Σs² 的 2–3 倍（逐个驱动记 s² 时只记到 0.38–0.57）；份额 0.04 分别在 3Γ 与 30Γ：−7.2 (Σs)²，是所记的 0.42。
    - 二阶自己的误差由同样两个数构成，各出现一次：一条线的速率是 |R_e|²·|1 + λ/D_e + …|²/(1 + X + …)，二阶只取 |R_e|²，差的是 2Re(a₁/D_e)（能级自己的二阶项除以这条线的距离；远失谐时速率恰好高 ⟨L_e⟩）以及份额 X、a₂，在一条线上合起来就是 s。所以二阶时一个驱动记 s_e·max(S_b, L_e)/S_b·p_b（布居与 T 相同）：同一距离的各驱动合计 Σ s_e p_b（与原来相同），近线读到远线光移时更多。这里的远线指同样按原子处能级折叠的；按裸能级折叠的远线对近线分母的移动在原子处的能级 H(r) 里，不在此列。实测（同一测试，二阶）：同一失谐，速率高 1.000 Σs；份额 0.04 在 3Γ 与 30Γ：高 2.72 Σs（原来记 Σs，现在记 3.21 Σs）；0.01 在 1Γ 与 0.05 在 40Γ：3.10 Σs（现记 5.83）；0.06/0.006/0.002 在 20/64/90Γ：1.19 Σs（现记 1.26）。力的误差（势的两倍）在任何距离下都不超过 Σs（实测至多 0.94 Σs），在 T 的记账之内。L_e/S_b 按距离之比取：(|N_bb|/|D_e|)/Σ_f(|V_f R_f|/|D_f|)——响应为 V/D 时就是 2|N_bb|/|D_e| 比 S_b，同一距离时不超过 1，单独一条线上恒为 1，不论它的响应里还带着什么（若直接拿 2|N_bb|/|D_e| 比 S_b，响应的一阶多普勒项会让单独一条线读成 1/|1 − (w/D)²|，R3 的快原子上到 1.35：那是多普勒项自己的下一阶，已由它的单元记账）。两级（二阶与四阶）都用这个比。
    - 有四阶的簇里，这一项分给两个单元（§5.2）：簇的“二阶”单元带着四阶能去掉的部分（T 与布居：Σ s·max(S_b, L_e)/S_b·p），驱动自己的单元带着只有显式才能去掉的部分（四阶时的余项；两级都有的运动项 a 与多普勒下一阶）。
  - 裸折叠另有分母的一阶 |ε|。速率是响应的二次式，改变 2|ε| × 它在该状态各速率中的份额（记在布居与 T 上）；光移是一次式，改变 |ε| × 它在该状态光移中的份额（记在 T 上）。一个状态的全部驱动（折叠的与显式保留的）的份额加起来是 1，所以各单元的误差相加就是该状态的误差，不随驱动的个数膨胀；显式保留的谱线旁边，远处谱线的速率只是改变布居的总速率里很小的一份；
  - 拉曼对（折叠到显式激发态上的驱动）：3 m²，记在布居与 T 上。在 e 所在的簇里 m² = |U|² p_e/d_R²（d_R 取簇里各基态中最近的，并减去保留驱动对两个基态能级的移动）；在 g 所在的簇里 m² = |R[e,g]|²|V_a|²/d_a²，乘 p_g。系数 3 的来源：保留谱线读到的自能是 |U|²/(d_R + λ) 在 λ = 0 处的值，下一项使它的速率改变 m²(3ε² − Γ²/4)/(ε² + Γ²/4)、光移改变 m²(ε² − 3Γ²/4)/(ε² + Γ²/4)，任何 ε 下都不超过 3 m²。簇里某个基态离平均读数能量 off 时，另记保留谱线分母的相对误差 |U|² off/d_R²/|ε̃|（速率 2 倍、光移 1 倍，各乘它在该状态速率、光移中的份额）。
  - 两个态的耦合混入 m²(p_a + p_b)；两源光子相干 m²√(p_i p_j)。
- 折叠的更精确的一级依次是：二阶 → 四阶（有四阶的簇）→ 显式。

### 1.6 跳跃与光给的动量（定义：`model::photon`、`step`）
- 等待时间展开：阈值 θ ~ U(0,1]；跳跃发生在步内，就在这一步自己的传播到达 ln‖ψ‖² = ln θ 的时刻 u*（从步的中点起算）——带区间的反插值（过最近三点的抛物线，不行则割线，再不行取区间中点；到范数的舍入为止，不用 Newton：节点之间范数的导数不是态自己范数的斜率）。跳跃取这次传播在 u* 处的态，并且**在步自己路径上的那一点**做：位置 r_h + v_m u*，动量取生成元所用的 κ_m；光子类、踢、落点都是模型在这一点的。跳跃的时刻、态、所在的点出自同一次传播：给跳跃定时的衰减正是这一点上的 ΣJ†J，于是"率 × 踢"就是步的路径上一点的散射力，与步自己的力读在同一条路径上，剩下的是步自己的、对时间两个方向相同的误差。（原因，R10 持原子波腹 ω τ = 3、每步 10 次跳跃时实测：定时用名义步路径**起点一侧**的危险率、踢取在轨道另一处时，随位置变的平均踢 b(r)——这里是阱的差分光移带来的响应相位梯度——与速度相关的危险率相乘出一个沿速度的力：沿驻波方向 Σ(ħ/m)κ·δκ = −2.06 ± 0.13 µK，正好抵掉全部加热 +2.2 µK；与驻波垂直、同样硬的轴不受影响。原先"步末跳跃、定长不动点 L = s(L)"也是单侧读，差 (ωL)²/8，靠跳跃把步截短才小。）跳跃之后这一步接着走完：传播对态是线性的，步的分解（中点生成元、本征系、跟随、斜率）只认原子的位置和速度、不认内态，所以落点态在 u* 处重新发射到同一个绘景上（`spectral::Picture::launch`：一次 1 + X(u*) 的分解，剩余部分上两跳，三个停点的五次插值），每步只传播一次，不论步内几次跳跃。冲量的求积在跳跃处分段（态在那里不连续）；跳跃的踢 δκ 在参考流里就地精确进入（按参考流的每个主轴，u 时刻的踢等价于中点处的踢 δκ cos ωu 与位移 −(ħ/m)δκ sin(ωu)/ω）；落到别的簇时用那个簇在同一个中点的生成元接着走。每次跳跃留下的一次性误差（跳跃数由物理定，与 τ 无关，所以各自就是全程误差的阶；h = τ/2）：光子的多普勒权重取路径的 κ_m 而不是 κ_m + a u*——一阶，对 u* 是奇的，对跳跃在步内的位置平均为零；光场的振幅（包络及其梯度）整步取在中点 r_h，沿路径转的只有平面波的相位：态在跳跃后 1/Γ 内做的事（激发态振幅建立到它跟随的值、裸态的快部分消失）所得的那一小段冲量 K 取在 r_h 而不是 r_h + v_m u*，差 u*(v_m·∇)K——一阶，对 u* 是奇的，平均为零（它最大的样子出现在轨迹不会有的态上：GMD1C 8+5 簇内 13 个随机振幅，40 % 在激发态，步一开始的 1/Γ = 0.03 µs 内在阱光对激发态的力下衰减掉，冲量是动量的 1.5 %、与 τ 无关；τ = 0.5 µs 时一步对两个半步差 (τ/4)(v·∇)K = 动量的 9e-4，减半只降到 1/2.2、1/2.7，与速度成正比；原子静止、去掉衰减、让激发态受基态的力、或换成运行中的态（激发态占 3e-4，差 8e-5，降到 1/7.7–1/7.9）时都没有这一项）；步内态的误差 ∂_κH·a(u² − h²)/2 在跳跃两侧不再相消——二阶，有确定符号；力在跳跃处改变而仍作为中点的一踢——步末位置 (ħ/m)Δf(h² − u*²)/2，二阶（与光滑部分合起来是每步 (ħ/m)(τ³/12)(f′ + γΔf)）；散射光的力与扩散取中点那个态的——一阶、零均值；**踢要到步末才进入路径**——余下的半步（平均）里生成元仍按 κ_m 读，力对这一踢的响应从下一步才开始：一阶。发射方向没有均值；折叠光的吸收平均踢在单侧照射时有，量级 (γτ/2)(2ω_r/|Δ + iΓ/2|)；经由摩擦，每次跳跃的踢多保留半步不被阻尼，能量偏高"半步内跳跃的踢注入的能量"，折成温度是每步每次跳跃 E_r/(3k_B)（Rb：0.06 µK；PGC3D 每步 0.28 次、13 µK：0.13 %）。布朗部分本来就有同一项（κ_m 的预测不含路径增量）。这些都由试探的 τ 对 2τ 检查读到（§2.2）。同号、同抽数的单条轨迹实测（`step::tests::a_trajectory_with_jumps_inside_its_steps_is_of_the_second_order`）：持原子波腹（ω τ = 3 起逐次减半）跳跃时刻、r、κ 的阶 1.85–2.11；穿过失谐驻波、带反冲 1.85–2.5。
- 光子类 φ：同一频率的光子集合，折叠振幅与显式振幅相加。类的概率 ∝ Σ_a‖u_a‖²，u_a = J_{a,φ}ψ；方向密度 ∝ tr G − n·Re(G)·n（G_ab = ⟨u_a|u_b⟩），从均匀球面精确拒绝抽样；偏振在 n 的实正交基中按 ‖Σ_a ε_a u_a‖² 选；跳后 ψ ← f/‖f‖。
- 吸收的光给的动量，一条规则。单位时间里，光对动量的作用是方法自身展开（半经典的 Wigner 展开，Gordon–Ashkin、Dalibard–Cohen-Tannoudji）的一阶与二阶 Kramers–Moyal 系数，对各类 c、各发射偏振 a 求和：
  - 力 Σ_c Σ_a Im⟨u_a|∇u_a⟩（散射力；偶极力在 Ehrenfest 力里），二阶矩的率 Σ_c Σ_a Re⟨∇u_a|⊗|∇u_a⟩。两者都**不除以**跳跃率 W_c = Σ_a‖u_a‖²，在相消干涉处（驻波节点）有限、光滑。二阶矩有一半来自不跳的演化，它不是“每个光子的属性”。
  - 没有任何一次动量增量是除以跳跃率得到的：
    - 跳跃（类 c，方向 n）：κ += −k_φ n + s_c b_c。b_c = Σ_a Im⟨u_a|∇u_a⟩/W_c 是该类的条件均值，s_c = min(1, k_c/|b_c|)，k_c 是该类所吸收的光的波数：跳跃带走它的条件均值，至多一个被吸收光子的动量。b 是各束波矢的加权和，权重非负时在它们的凸包里（|b| ≤ k）；只有相消干涉使权重变号时才超出，那不是任何光子的动量。一次跳跃的踢至多 k_φ + k_c。
    - 每步在中点（态 x_m，点 r_h）：力 F_s = Σ_c (1 − s_c) Σ_a Im⟨u_a|∇u_a⟩/‖ψ‖² 乘 τ；扩散 2D = Σ_c [Σ_a Re⟨∇u_a|⊗|∇u_a⟩ + E_c − s_c² W_c b_c b_cᵀ]/‖ψ‖²（Cauchy–Schwarz 保证半正定），经它的因子 Λ（Λ Λᵀ = 2D）作用在该步的布朗路径上（§2.1、§2.4）。
    - 均值留在跳跃上是因为精确的一阶项把吸收的动量给“跳过去的那一支”：内态随跳跃改变时（光抽运），把均值全改成连续力会多出量级为 k² 的方差（一束行波抽运一次，真实恰为一个 k）。内态只有一个时两种放法是同一个 Fokker–Planck 方程。
  - 显式激发态：它的跳跃算符是常数，吸收的均值在 Ehrenfest 力里，跳跃只带发射反冲。它的二阶矩的率 E_c 取它的驱动按原子处能级折叠时会有的响应：每个载波 c 的响应 σ_c = Σ_b ψ_b Σ_l a_l X_l[e,b]/(δ_b + w_l − iΓ_e/2) 对该载波的各光束和簇内各基态振幅相干求和（与折叠的跳跃同样求和，绝不逐束），S = Σ_c|σ_c|²，T = Σ_c Re[∇σ_c*⊗∇σ_c]（不同载波彼此拍动，按 |σ_c|² 分享光子），E_c = Γ_{e→c} · min(p_e, S) · T/S。p_e 是该态的布居，在一步里取步内的平均（冲量自己的求积；跳后的裸态在 1/Γ 内充满激发态，步不必分辨它，步内散射的光子是衰变率的积分）。布居只算到线性响应的那一份：超出的激发不是在此处吸收的，T/S 不是它的矩；上界是折叠的式子 Γ T，处处有限，不除以为零的响应。
  - 检验：单束平面波 b = k，跳跃恰带走 ħk，步里不剩力也不剩扩散；驻波 f ∝ cos kz：b = 0，2D_zz = k²R₀ sin² kz——波腹处为零，波节处（没有跳跃）为 k²R₀（偶极力的涨落，Gordon–Ashkin）；两束不等的对射光 f ∝ cos kz + iε sin kz：b_z = kε/(cos² + ε² sin²)，波节处 k/ε，跳跃只带 k；同一个跃迁折叠与保留为显式给出同一个每光子的二阶矩。
  - 强饱和下显式态的力涨落（Gordon–Ashkin 的一般式）不是轨迹上的闭式：E_c 随实际散射率饱和，对行波是对的，驻波的振幅梯度项在精确结果里不饱和。这是模型在该处的适用范围，不是规则的一部分。
  - 发射反冲为 −k_φ n，|k_φ| = |ω_φ|/c。ω_φ 是该类光子自己的频率：激发态的帧频率减去该类的帧频率，再加上源簇首态与落点簇首态的裸能量之差（帧是从每个簇的首态算起的）。回到原态的光子是所吸收光的频率（Rayleigh），落到别的基态的差一个基态能量差（Raman），显式激发态发出的是谱线的频率；簇内各态与自己的帧只差残余失谐，是光频的 10⁻⁷。

### 1.7 读出与输出（定义：`model::readout`、`estimate`）
- 读出：ρ_g = ρ − ½{Y, ρ}，加折叠的激发布居；显示行 P_s(t) = E[A(t) ρ_s] = p(1−L)。
- 损失：τ = 首次"在区域外，且 E_s 高于远处的渐近值"（阱光全是聚焦光束，§9：这个值是 0）；在每步末、每次跳跃后和每个输出时刻（步内读出的状态，§2.2）判定。L(t) = P(τ ≤ t)，单调。
- T_a(t) = (ħ²/m k_B)·(E[A·⟨κ_a²⟩_w]/E[A] − (E[A·⟨κ_a⟩_w]/E[A])²)：⟨·⟩_w 是以 t 为中心、一个 a 轴阱周期的窗口均值（t 不到半个周期时截到 t = 0 以保持居中），与输出间隔无关：输出比周期密时相邻输出的窗口重叠，按每条轨迹从 t = 0 起的累积积分在各窗口两端之差求（`solve::Windows`），运行在最后一个输出之后再走半个周期——窗口截在 t = 0，所以至多与运行本身一样长；平方项用无偏估计；n̄ 同理。为什么不按输出间隔截短（v2026.11.12 之前的规则）：一个原子的 κ_a² 以 2ω 振荡，宽 W 的窗口均值留下 sinc(ωW) 倍的振荡，N 个原子的相位不相消，于是 T 以 2ω、约 |sinc ωW|/√N 的均方根在均值附近“呼吸”——统计噪声，看上去却像运动；它在单个原子读数的方差里占 sinc²(ωW)，W → 0 时是能量本身方差的两倍（实测 R1 光镊、1 µs 输出：200 个原子各轴 7.9–8.7 %、3200 个 1.9–2.4 %，整周期窗口 0.3 %；四个种子的平均曲线上没有共同的部分。按 10 µs 输出的整次求解、四个种子：R1 的 T_x 去掉 9 点滑动平均后的残差 6.1 % → 0.9 %，轨迹 228 → 146 条；PGC3D 1 ms 的 T_z 4.2 % → 1.4 %，轨迹不变；同一批轨迹上 T_z 只差那一部分噪声，均值差 −0.05 %）。代价是运行多走半个周期：1 ms 的光镊场景 2–4 %，10 ms 的 0.2 %，短于一个周期的运行至多加倍（R6 的 20 µs 到 40 µs）。窗口切到步内时，κ 与 κ² 取在"冲量摊在整步上"的路径上（§2.2 步内读数），任何一段都是格式的阶。
- t = 0：布居返回请求初态的对角；T(0) 为初始系综的精确矩。

### 1.8 原子能到的范围（定义：`model::reach`）
- 准备能量的子水平集 {(r, κ) : V_prep(r) + (ħ/m)κ²/2 − V_min ≤ L·k_BT_r}：势能与动能合在一起不超过这个水平。它是“装下系综里除份额 s 之外全部原子”的集合：s = z²/(N_max + z²)（§3 的函数在 N_max = 2¹⁴ 处的值，2.44e-4），T_r 为原子实际到达的温度（只增不减，由试探读出）。
- 水平 L 是初始系综（照它实际抽出来的样子，§2.5：热分布乘每个轴的谐振子 Wigner 因子）里一个原子的能量的 (1 − s) 分位数，按阱的谐振形式算。准备阱 Hessian 的每个把原子束缚住的主轴 i（阱频 ω_i > 0）是一个谐振子：经典时它的两个二次自由度共有 k_BT·E_i（E_i 是单位指数分布），Wigner 因子把两者都乘上 s_i² = x_i coth x_i，x_i = ħω_i/2k_BT（就是该振子自己的平均能量除以 k_BT：ħω_i ≪ k_BT 时为 1，冷的时候是零点能 ½ħω_i/k_BT）；阱不束缚的轴只有动量的一个自由度（Γ(½)）。所以能量除以 k_BT 是 X = Y + Σ_束缚 s_i²E_i（Y 服从 Γ(f/2)，f 是不束缚的轴数），L 由 P(X > L) = s 解出（对分到浮点分辨率，`quantile`）。一句话管所有温度，没有“冷”的分支：s_i 全为 1 时它就是 n = 6 − f 个二次自由度的 Q(n/2, L) = s，三个轴都束缚时 Q(3, L) = e^{−L}(1 + L + L²/2) = s，L = 12.89。（Boltzmann 因子等于 s 的水平 ln(1/s) = 8.32 只是一个振子的分位数，六个自由度下它留在外面 1.07 % 的原子；而 12.89 k_BT 的水平装不下零点能比它高的系综：ħω = 14、14、61 k_BT 时 s² = 7.2、7.2、30.6，分位数是 271 k_BT。）X 的尾概率是各项的卷积，一个指数接一个地做：P(Y + aE > L) = e^{−L/a} + (1/a)∫₀^L e^{−(L−u)/a}P(Y > u)du，每个积分用 Gauss–Legendre（变量 √u），节点逐级加倍到两级之差不再下降（`tail`）；不用指数之差的闭式，所以相等或几乎相等的尺度（圆阱）不是特例。系综沿主轴 i 的动能温度是 s_i²T_r（`Reach::kinetic_uk`）：伴随层的方均根速率取它们的平均（系综自己的方均根速率），可达范围的否证（试探的 T 是否超出了范围）拿各实验室轴读到的 T 与它们中最大的一个比——原子就是范围所对应的那个系综时，任何轴的 T 都不超过它（原先与 T_r 本身比：零点系综的 T(0) 是 0.4–0.49 µK，而 T_r = 0.03 µK）。分位数是谐振阱的；真实的阱多出来的部分（光镊势的非谐尾部、降低的等温分布的截断、Wigner 因子）从初始系综自己的密度上算、照实记账（§4；`Model::left_out`，`Ensemble::beyond`），不抽任何原子：范围在位置 r′ 处装得下的动能是 A(r′) = V_min + L·k_BT_r − V_prep(r′)；系综是经典抽样 (r, κ) 经 Wigner 因子映成 (r′, Sκ)（§2.5），在 r 处经典动量各向同性、动能 K（以 k_BT 计）的密度 ∝ (e^{y−K} − 1)K^{1/2}（0 ≤ K ≤ y），沿方向 n 的动量映射后的动能是 q(n)K，q = Σ_i s_i² n_i²，所以 K > k₀(n) = A(r′)/(k_BT·q(n)) 的部分在范围之外。原子份额 = ∫d³r ⟨kept(3/2, y, y) − kept(3/2, y, min(y, k₀))⟩_n / ∫d³r kept(3/2, y, y)，记在布居上；它们占的动能份额 = ∫d³r ⟨q·[kept(5/2, y, y) − kept(5/2, y, min(y, k₀))]⟩_n / (⟨q⟩∫d³r = 5/6，任何温度、阱底在哪里都一样；原先节点按光束的尺度围绕焦点放，冷原子纳米宽的云、偏离焦点的阱底里一个节点也没有），方向平均在球面的一个卦限上（q 对每个 n_i 是偶的）；节点数逐级加倍，一级至多用 N_max = 2¹⁴ 次势的求值，最后两级之差就是这个份额自己的误差，与份额一起记账。经典谐振阱里两者就是 Q(3, L) 与 Q(4, L)（每个坐标 32 个节点时与闭式、与带各向异性 Wigner 因子的亚指数分布闭式都在一成以内，阱深 30 与 30000 k_BT 给出同样的数：动量在水平处的截断是径向被积函数的折点，Gauss 求积对它代数收敛；节点跟不上的结构——比云自身尺度细得多的密度、与阱底同样深的其他格点——留在最后两级之差里照实记账；一个光镊上与 2¹⁴ 个抽样原子的计数在计数自己的误差内一致——抽样只在测试里做）。范围随 T_r 长大时留在外面的更少。（原先在 2¹⁴ 个抽出的初始原子上计数：超冷原子的一次抽样要 65 ms，计数要上千核秒；抽样不是免费的，有限次抽样也不是得到 2.4e-4 量级份额的办法。）
- 范围的否证（`solve::outgrown`，在试探上读）。模型是在范围上判定的，范围是为一个系综做的：温度 T_r 的热系综，范围装下它除份额 s 之外的全部原子。这句话对试探的原子说了两件事，两件都读，合成一族读数（对全部读数取 Šidák，每个读数单侧、置信度 z）；任何一件被推翻，范围就按读到的最大 T 长大，本次尝试结束：
  - 任何实验室轴、任何输出的 T 都不超过该系综沿主轴的最大动能温度（`Reach::kinetic_uk`）：某个 T − 区间 > 它即推翻（区间按组数取 Student t）。
  - 列出分布的各输出时刻（至多 21 个）被俘获的原子里，在范围之外的（`Model::holds`：准备能量超过水平）至多是份额为 s 的二项分布（s 取范围对它自己的系综留出的份额与对初始系综记账的份额 `Model::left_out` 中较大的）：某个时刻的计数的上尾概率（`estimate::at_least`，精确求和）低于这一族里一个读数的单侧尾（`estimate::tail_among`）即推翻。200 个输出、21 个列出时刻（621 个读数）时，试探的 88 个原子里有 3 个在外即是（2 个在外的偶然概率是 2.3e-4，一个读数的尾是 3.7e-5）。这个读数不估计任何离散。
  - 读到的 T 没有一个高于范围的温度时范围不变：离开了范围而并不更热的原子不是哪个更热的系综的（被推走的原子团的能量在平均速度里：R9_PUSH 全部原子在范围之外），这个否证给不出它的范围。
  - 为什么要计数（原来只比温度；实测 2026-11-11，R3_DOPPLER，T_r = 30 µK，原子在 4 ms 内升到 75 µK、T_z 94 µK）：600 个读数、11 组时区间是 6.41 个标准误差，而标准误差本身只在 11 组上估计。种子 0 最热的读数是 T − 区间 = 36.2 > 30.04，推翻；种子 3 在 1.4332 µs 上是 38.8 ± 1.79 µK，T − 区间 = 27.3，不推翻——整次运行留在 30 µK 的范围和 1.4332 µs 的起始档上（两层同样少加热、彼此一致，步长检查看不出），末端总温度比解析参照低 13.5 %。同一批 88 个原子里 4000 µs 时有 6 个在范围之外（种子 0：9 个；八个种子 6–18 个）：温度翻倍把范围外的份额从 2.4e-4 变成一成，计数不依赖哪个标准误差碰巧估得大。同样没被发现的还有 R4_LIN_2 的两个种子（T_r = 30 µK 而 T_z = 74 µK：试探 88 个里 4 个在外，产品 896 个里 50 个、696 个里 33 个）。
  - 为什么不在 scout 上读：范围长大要一个温度，scout 的 11 个原子把 T 读到 √(2/11) = 43 %，而且取的是 600 个这样的读数里最大的那个。实测（R3_DOPPLER，在 scout 上按计数长大的三个种子）：新的 T_r 是 136、197、228 µK（试探上读到的是 84–128 µK，T_z 实际约 95 µK）；起始档按 1/√T_r 变小，这三次运行的工作量比在试探上长大多 16 %（1350 万对 1164 万轨迹步），而省下的那个试探约占一成。
  - scout 已经推翻范围时（在 scout 的保留读数之前读，与试探上一样：单元的误差在一个成立的范围的状态上读——在被推翻的范围上读的是越过它的原子），试探先只跑运行自己那一层（其余成员，步长 τ），在它的 88 个原子（scout 的在内）上照常读这个否证：推翻则本次尝试结束，范围长到它们读到的温度——与跑完整个试探时同一个读数、同一个温度——，伴随层（2τ）不跑：那是在一个范围将被推翻、模型要在长大的范围上重新判定的尝试里检查步长，下一次尝试从这个步长起自己重新检查。不推翻时试探的检查从这一层接着做，只补跑伴随层（轨迹只是编号与步长的函数，与在哪次分发里跑无关）。实测（2026-11-12）：S3（1 mW）与 S3c 10 ms 的 scout 都推翻了 30 µK 的范围（11 个原子里 3 个、2 个在范围外），省下先导的伴随层。
  - 运行层按成员翻倍分批跑（与产品的批次同一规则：每批至多把已有的翻倍），每批之后在手头的原子上读否证：推翻即长大，剩下的先导不跑。scout 的推翻是选出这次尝试要结束的那个读数（被选中的读数偏高）；它的 11 个原子（每组一个）由接下来的 11 个一起确认，范围才长到它们读到的温度。否证需要的是显著，翻倍后仍成立就有了；更多原子只把长到的温度读得更准——读低了下一次先导的原子会再推翻，读高了多付它自己的证明——都由下一次尝试来说。实测 S3 30 µK：22 个原子长到 99.7 µK，44 个 95.7，88 个 113.0，下一次先导的 88 个原子都没有推翻；全程 957、949、1128 CPU-s，结果相同（只差账目的末位）。
  - 长大之后上一次尝试的先导什么也带不过去（solve.rs # An attempt's own）：保留了单元（S3 82 → 84、S3c 10 ms 69 → 75）时模型处处不同，轨迹、步长读数、单元读数、表、统计、初始系综都是旧模型的；没保留时表（在范围上加密）、布朗路径的格、起始档也变了（R3_DOPPLER 起始档 1.43 → 0.83 µs）。留下的只是关于原子的结论：范围被推翻、长到的温度、下一次的起始档。
- 阱的区域（`model::reach`，# The trap's region）。原子在区域内、或在区域外但被束缚（损失能量不高于远处值）时都被持有（§1.7）。所以水平达到或超过远处值时（原子获得了阱深但仍在阱光里），范围是区域内的子水平集；区域外是一个低于远处值的水平的子水平集（`Reach::outside`：起初没有；要持有区域外的原子时才加，`Model::outside_to`）。两个水平而不是一个：远处值以下的子水平集随水平趋近远处值无界地伸展（远离焦点的静止原子是束缚的），而只在远处值以上才截到区域的一族，长过远处值时会丢掉它在远处值以下时持有的区域外的束缚原子。两个水平都只增不减，长大的范围包含长大之前的。区域在阱光各束光的椭球 u_l ≤ 1/REGION_INTENSITY − 1 之内（|a_l|² ≤ 1/(1 + u_l)）：它们的外延界住区域，正如水平的椭球界住子水平集。区域外的水平达到远处值时（V_run 束缚而 V_prep 不束缚的被持有原子，或越过区域边界、在区域外的部分证明不了的路径）范围无界：全空间、全局的界。（原来水平达到远处值时范围就是全空间：默认光镊加探测光的场景长到 88 µK 以上即如此。）
- 一步向它的定义域只问两件便宜的事（`step::Domain`、`solve::Domain`；推导在 step.rs # The domain），都用这一步本来就有的量，不在路径上证明任何门：
  - 失控守卫：每段传播（每步，以及跳跃落到另一个簇之后）第一个状态的 hazard x̂†Γx̂（这一步铺好的衰减，显式激发态与折叠一样算）高于模型最快的激发态衰减率 Γ_max——原子任何状态都不可能散射得这么快（整个处在最快的激发态上也只有 Γ_max）——就是远离适用范围的折叠：v23 的失控（共振探测光按原子处能级折叠，多普勒级数发散，散射率按 (kv/Δ)² 增长，约 10⁵ 次/µs，对 Γ/2）。这一步不走（`step::Refused::Runaway`），原子停在那里，此后每个输出都按停下时的状态记为未分辨（整份记账，见下）。守卫不点名、不保留任何单元；停下的原子若是先导保留状态的一员，它的状态照常读单元误差，由 §5.2 的规则决定保留。
  - 光的分辨：结果层（运行的档及其下面的档）的步在该速率下不能分辨光时，这一步照走，轨迹从这一步起是未分辨的。
- 记账（模型误差 A 的一项，§4；产品每批之前重算，所以停止判据里有它）：
  - 未分辨的原子（包括守卫停下的）按全部：显示量上记它们占被俘获原子的份额（一个原子的每一行是一个概率，误差至多 1），T 上记它们占的动能份额。
  - 范围之外的原子按旧引擎的办法（`solve::beyond_reach`，decisions.md §3.9）：某个输出的 T（取最大的实验室轴，封顶在阱深/ln(1/s)，超过它的原子归损失）高于范围的 T_r 时，温度为 T 的热系综在范围水平之外、超出范围自己留在外面的份额 s 的部分 s^(T_r/T) − s，同时记在布居与 T 上；这些原子上的折叠不另行判定、不在它们的状态上读单元误差。
  - 范围长大（重做产品）只在这一项放不下的地方：产品停下时，某个量加上它之后没有统计的余地、去掉它则有，就按读到的温度长大；否则照记、在账本上标出。
- 范围上的极值只剩表的取值区间用可证的界（逐格、逐边算到二阶，§2.3），不用固定节点采样；折叠的门不在范围上证明（§1.5）。

## 2 数值方法

### 2.1 一步（定义：`step`）
一步 = A(τ/2) ∘ B(τ) ∘ A(τ/2)：
- A：参考哈密顿量 ħ²κ²/2m + V_ref 的精确流。V_ref 是固定参考态（初态里布居最大的基态分量；并列时取下标大的）的远光阱势在步中点 r_h 的二次展开（Hessian 解析；不定时为双曲流）。r_h 由"在 V_ref(r_h) 上的前半步流到达 r_h"这个不动点定义，所以一步是自身的逆（Hut–Makino–McMillan）。任何几何都是同一条规则，没有格点检测，没有区域换接。
- B：位置固定在 r_h。内态沿本步的直线路径 r_h + v_m(t − t_m) 演化，路径相位精确处理（多普勒参考系或拍）；冲量 = 在 r_h、对起点态的守恒力（剪切），加上态沿路径变化带来的部分，减去参考力；v_m = 步中点动量。
- 散射光在该步的部分（§1.6）也在中点：κ += τ F_s，加扩散。扩散是参考流里的精确形式：布朗路径在该步上的增量 ΔW = ∫dW 与关于中点的一阶矩 ΔZ = ∫(s − τ/2)dW 经 Λ 后，沿参考流的每个主轴（x = (ħ/m)λτ²）取“摊在整步上的力”在中点等效的踢 ∫cos(ωu)Λ dW 与位移 −(ħ/m)∫(sin ωu/ω)Λ dW 的方差：ΔW 乘 √((1 + c₁(x))/2)，ΔZ 乘 √(6 c₃(x))（Stumpff 函数；自由飞行时都是 1）。于是扩散注入的平均能量是 (ħ/m) tr(2D) τ/2，与 ωτ 无关；只用自由飞行的杠杆会在势能里多出 (ωτ)²/12。v_m 的预测不含随机部分：传播、范数、跳跃时刻与抽到的数无关。
- 性质：守恒部分辛、整步可逆、二阶。
- 内态传播（一条路径）：在步中点生成元的本征基里做相互作用绘景。生成元自己的频率（失谐、光移、衰减）对态和对冲量都精确积分，不论 Δτ 多大；沿路径的慢变化（k·v·τ）由步的中点和两端三个节点给出，D(u) = uA + u²B（`spectral`）。中点生成元的一对本征态按它在相邻两个节点之间转过多少（x = |ω|·τ/2）、对照这半步里变化量的大小分两种处理（分界见下）：慢对每步两跳（起点到中点、中点到终点），每一跳取第一项 Magnus、其振荡积分解析做完，节点之间取五次 Hermite 插值；快对（显式的远失谐态在任何步长下都是）不跳，态跟随变化——逐元素解 ωX − iẊ + D = 0 的多项式 X₀ + uX₁ + u²X₂，它留下的二阶残余再跟一次——，变化量自己的光移留在慢对的生成元里，精确。对慢变化的阶：慢对是四阶——三个节点就是 Simpson 规则，Magnus 第二项是步长的五阶；快对留下跟随的三阶，在跟随量的平方 (k·v·(τ/2)·V/ω)² 以内（V 是耦合，ω 是这一对的频率），随步长、随失谐一起下降。传播自己的工作量与 Δτ 无关。分界由两种处理各自在步末留下的首项误差相等来定（`spectral::followed`；在单独一对上推导，并对照精确传播逐项验证，`spectral::tests::a_pair_hopped_and_followed_against_its_flow`）：记半步内变化量的斜率与曲率的大小为 S_A = ‖A‖(τ/2)²、S_B = ‖B‖(τ/2)³（各对平方和的根，每对算一次），跳的一对留下 Magnus 第二项 x(S_A²/15 + S_B²/42)，跟随的一对留下二阶的四次项 (4/15)S_B²/x（三个节点的抛物线漏掉的、变化量自身光移的 u⁴ 项）和跟随的三阶 (2/3)(S_A/x)³；跟随留下的不超过跳留下的那些对才跟随。只有斜率时分界是 x⁴ = 10 S_A：半步变化量为 0.1 时是 1 弧度，0.01 时是 0.56 弧度——不是一个固定的数；一对随步长越过分界时，两种处理的首项误差相等。这条规则只管步末态的两个首项：跳的 [A, B] 项（符号不定）、曲率的三阶、步内的态与读在它上面的冲量不在其内。整步仍是二阶：那是分裂的阶（踢取在固定的 r_h，路径取直线，路径动量靠预测），不是传播的。实测（场景自己的模型，每簇 16 个热原子、簇内随机态，`step::tests::a_scene_s_step_error_by_the_split`）：传播在该步路径上自己的误差，PGC3D（F = 2，τ = 0.625 µs）内态 1.8e-4、路径冲量 6.7e-6（相对动量），是"一步对两个半步之差"（内态 1.4e-2、动量 6.5e-4）的约 1 %；τ 减半时它降到 1/14–1/17（四阶），那个差降到 1/7.5（分裂的二阶）。GMD1C（8+5，τ = 0.5 µs）：内态 7.3e-5 对 1.06e-2，降法相同。"一步对两个半步之差"读在运行会有的态上——随机态落在基态上的部分（跳跃落下的样子）和它一步之后的态；GMD1C 的动量差是 3.4e-4 与 2.8e-4，减半降到 1/8.4、1/6.6 与 1/8.3、1/8.2。不读在簇内随机态上：显式激发态上的随机振幅在步初 1/Γ 内衰减，其间的冲量按步中点的光场取，是每个瞬变的一阶项（§1.6），动量差减半只降到 1/2.2–1/2.7，不是格式的阶。分界固定在 1 弧度时，步长加倍处（PGC3D 1.25 µs、GMD1C 1 µs，半步变化量 0.3–0.5）减半的降幅是 29 与 22（冲量 40 与 35）——刚过 1 弧度的对被跟随，而跳留下的更少；按上面的分界是 14.7 与 14.2（冲量 17.6 与 13.9），该处误差减半。本征矢量病态处（例外点附近：经本征基的舍入超过直接指数的舍入时）不做分解，在求积节点之间逐段用 CF4（同一个 Ĥ₀ + uA + u²B，两个指数）。原因：显式的远失谐激发态（Δτ ≫ 1）下，原来在网格节点上"采样"以 Δ 振荡的力，冲量错 17–46 %，一步对两个半步完全看不出（R4_LIN_4：T_z 在 τ = 0.0625 读 62、在 0.0039 读 45；改后 47.6 ± 1.2 对 45.5 ± 1.0）。指数与级数算到舍入（代价对精度是对数的）。
- 跳跃：在步内、这一步自己的传播到达阈值处做，步从落点态接着走完（§1.6）；一步只传播一次。

### 2.2 步长：全程一个常数（定义：`adapt`；选取与记账：`solve`）
- 一次运行只有一个步长 τ，所有轨迹共用。每条轨迹以 τ 推进：
  - 步不认输出时刻：输出落在哪一步里，就在那一步里读（下面"步内读数"）；整次运行的最后一步取剩余时长；
  - 步内发生跳跃，就在步内做（§1.6），这一步照常走到它的末端：步始终落在轨迹的网格上；
  - 格式做不出的步（中点的不动点不收敛）取一半。
- 步内读数（定义：`step::Segment`、`step::Step::at`；`adapt::advance` 在每步里读落在该步的输出）。步长由格式要分辨的东西决定，与输出多密无关：输出间隔是步长的十分之一，也不让步长变小。一步在两端之间知道的东西：
  - 内态：传播本来就有步内任意时刻的态 x(u)（u 从中点起算，中点生成元本征基里的相互作用绘景，§2.1；跳跃的求根就是这样读的），ψ_s = e^{iK_s·v_m u} x_s。它是直线路径 r_h + v_m u 上的解，这条路径离原子的路径 ½au² + ½a_B h²（a 是总加速度，a_B 是冲量那一份，h = τ/2），速度是 v_m 而不是 v_m + au：u 处的误差是 ∫∇H·d = O(τ³)，再加生成元对所取动量 κ_m 的依赖带来的 ∂_κH·a(u² − h²)/2 = O(τ²)，在两端为零。
  - 位置与动量：分裂自己的路径（参考流、中点一踢、参考流）在两端是对的，在步内**一阶**地错——中点之前动量少了已经过去的那段时间的力，中点之后多了还没到的那段，是幅度为半个冲量的锯齿。整步上它从 ∫κ 里消掉（∫κ² 里到 τ²），步内一点上消不掉。所以把这一踢摊在整步上：参考流是仿射的，贯穿一步的力 f(u) 在步末的效果等于中点处的冲量 ∫cos(ωu) f du 与位移 −(ħ/m)∫(sin ωu/ω) f du（每个主轴；与扩散的"摊开"是同一个恒等式）。取对时间线性的力 α + βu，使这两个积分正是本步的冲量与位移：α = Δk/(τ c₁(x_h))，β = shift/(2h³(c₂ − c₃)(x_h))，x_h = (ħ/m)λh²。在这个力下的参考流从步的起点精确地走到步的终点，中间：
    - 冲量的确定部分 = 把力在一步内当作常数。u 处动量的误差 f′(h² − u²)/2（f′ 是力的变化率）：O(τ²)，两端为零；位置是它的积分，O(τ³)。
    - 布朗部分 = 给定本步所取的两个矩（ΔW、ΔZ）时路径的条件均值；自由飞行时 E[W(s)|ΔW, ΔZ] = sΔW/τ − 6s(τ − s)ΔZ/τ³ 正是这条流。两个矩没有说出的是布朗桥剩下的部分，方差 τσ(1 − 3σ)，σ = (s/τ)(1 − s/τ)（两端为零，至多 τ/12），经 Λ。在一个时刻读出的动量用一次抽样补上它（该时刻自己的流）；窗口的 ∫κ² 按均值补上它的积分（整步是 τ²/15），于是任何一段的 E∫κ² 都含扩散到该处为止的全部输入（核对：∫₀^τ [s²/τ + 3s²(τ − s)²/τ³] ds + τ²/15 = τ²/2）。余项取自由飞行的形式，参考流的转动改变它的 (ωτ)² 份，三阶。
  - 阶：步内读到的值 = 累积到步起点的格式误差（O(τ²)，对时间光滑）+ 所在这一步自己的一项。后一项不累积，所以 O(τ²) 就保住二阶；读在步末时它为零，读到的就是步末本身（到舍入）。两层（τ 与 2τ）在同一时刻读：τ → 0 时一致，差为 τ² 阶；Richardson 的系数对光滑的累积部分逐输出成立，对读数自己的那一项（系数 (h² − u²)/2 随输出在步内的位置变，对位置平均是 τ²/12）按输出平均成立——筛正是在输出上取平均。布朗路径在读数处的部分是每层自己的（如同跳跃那一步），两层之差零均值，方差是"两个矩没说出的"那一份，随 τ 降。
  - 比较过的做法：中点一踢的路径（不花代价，动量一阶）；把冲量的求积做到读数时刻（约三分之一步的代价，误差同样是 f′(h² − u²)/2：剪切取在固定的 r_h，驻波里被保持的态的力在格式里一步内是常数）；从步的起点另走一个缩短的步作旁支（三阶，但每个读数一整步：GMD1C 每条轨迹 556 + 1000 次步求值，只比现在的 2000 省 22 %）。取的是摊开的冲量：每个读数一个"某时刻的态"（n²）和一次流求值，约百分之一步。
  - 跳跃：要读的时刻是这一步传播的停点（与求积节点一样），各自取传播经过它时的态：在它之前的跳跃之后、在它之后的跳跃之前。步的路径按跳跃分段交出去（步起点到第一次跳跃，每次跳跃到下一次，最后到步末），跳跃的踢落在它发生的时刻；冲量仍摊在整步上，所以含跳跃的那一步里读到的 κ 差 Δf·τ/4 量级——一次性的，这样的步占 γτ，对输出平均是二阶。
  - 损失是首达时间，在轨迹的状态被做出来的每个地方判定：步末、跳跃后、以及每个读数处（§1.7）。不在读数处判，步内输出上的损失就是上一步末的，晚一个步长，一阶。读数处判定为损失的轨迹就在那个时刻损失，它的窗口只取这一步到该时刻为止的部分。
  - 实测（2026-11-11，658f53ff 之上；`step::tests::a_read_inside_a_step_is_of_the_second_order_and_the_step_s_end_at_its_end`，两个态各在自己的谐振阱里，闭式解）：一步内 0.3τ 处读动量，τ 逐次减半时误差 3.8e-2 / 1.0e-2 / 2.7e-3 / 6.9e-4（阶 1.86 / 1.94 / 1.97）；同一处用中点一踢的路径是 3.34 / 1.67 / 0.83 / 0.42（阶 1.00）；步末 5.2e-2 → 1.0e-4（阶 3.00）。跑四个轨道周期，在步内读的 r、κ、两态相对相位都以 2 阶收敛（1.84–2.08），与步末处的 2.00 相同。读在步末等于步末（1e-13 内）。
  - 实测，场景：R6_RAMAN_CO（20 µs、401 个输出，布居振荡）步长 0.025 → 5.006 µs（每条轨迹 800 → 4 步），check.mjs 通过，max|d| 0.013；R5_PUMP 0.5 → 6.68 µs，通过；PGC3D 1 ms 0.8333 → 0.8910 µs，368 条，T 与 0.8333 的结果在统计内一致（全部输出上 z 的均值 0.29、均方根 1.00）。GMD1C 1 ms × 1001 个输出：新做法在原步长 0.5 µs 下（手设）472 条，T 与原结果一致（全程平均 −0.3 %，z 均方根 0.91）；在 0.91 µs 下（手设）536 条，仍一致（−0.6 %），轨迹步数 0.59 M 对 0.94 M。
  - **实测到的问题（步长的筛的事，不在步内读数的范围内）**：GMD1C 上只由可用性定出的起始档是 1.819 µs（伴随 3.638 µs），筛没有减半——两层在 88 对上对 T 的分辨率只有 ±15 %。在这个步长上 T_总 随时间越来越低（全程平均 −3.5 %，700 µs 之后 −7 %，T_z −16 %），并出现一个 0.35 m/s 的原子（可达范围的 v_max 是 0.2185 µm/µs），它把 T 的统计噪声放大到要 1696 条轨迹：轨迹步数 0.93 M，与 0.5 µs 的 0.94 M 相同，CPU 反而多一半。输出稀（101 个）时同一步长给出同样的 T，所以这是步长自己的误差，不是步内读数的。
- 为什么是常数：分裂的守恒部分辛、整步可逆，步长不变时阱中运动的能量误差有界（参照 R1：10³ 个周期不漂）；按上一步的误差选步长则会漂。实测：逐轨迹接受/拒绝的步长控制步数 ∝ 时长^1.4、一半的步被拒；常数步长的步数 = 时长/τ，与跳跃数无关（跳跃在步内做，§1.6；此前每次跳跃截断一步并重试：PGC3D 每个名义步 1.44 次传播，现在 1.00）。
- 梯子：档位是运行时长（最后一个输出的窗口末端，`Plan::end`）的偶数分之一，往下逐次减半。偶数的原因：伴随层的步长是两倍，运行于是恰好是伴随层的整数步，两层都没有被截短的末步（没有跳跃的轨迹正好走 end/τ 步）。输出间隔不进入步长（上面"步内读数"）。一档对某个速率的原子可用，条件是一句话：它的节点分辨得了这个格式沿该原子路径采样的东西（`solve::admissible`）。
  - 参考流与夹在它两半之间的踢：在势的极小附近，一步是线性映射 R(ωτ/2)·K·R(ωτ/2)（参考流转过 ωτ/2 两次，中间的踢从 κ 里取走 τ·w·y，w = ∂∂(⟨x|Ĥ_h|x⟩ − V_ref) 是踢的曲率），它的迹是 2cos ωτ − ω_k²τ²·sin(ωτ)/(ωτ)，ω_k² = (ħ/m)·w；迹在 ±2 之内运动有界。条件：ωτ < π 且 cos ωτ − (ω_k²τ²/2)·sin(ωτ)/(ωτ) > −1，ω 取准备阱最大的主轴频率，ω_k² 取模型给出的踢的最大曲率（`Model::kick_curvature`）。
    - 踢没有曲率（ω_k² = 0）或原子自己的阱比参考的软（ω_k² < 0）时，这就是原来的 ω τ < π（两个半步的参考流把运动转过 π，夹在中间的冲量被放大；实测：越过即错）。原子自己的阱更硬（ω_k² > 0：光场里的势阱，或内态的阱比参考态的深）时，边在 π 以下，(ωτ/2)·tan(ωτ/2) = ω²/ω_k²：ω_k²/ω² = 0.1、1、4 时在 0.91π、0.55π、0.31π；参考是平的（ω → 0）时是踢自己的 ω_k τ < 2。没有新的常数。
    - 三个轴、任意主轴的踢：映射有特征值 −1 当且仅当 det(D − τW) = 0，D 在参考的主轴上是 2ω_i·cot(ω_iτ/2)，W 是踢的 Hessian；(ħ/m)λ_max(W)τ² < 4·(ω_maxτ/2)·cot(ω_maxτ/2) 时没有，这就是上面的条件取在最大的 ω 与最大的曲率上。条件对 ω、对 ω_k² 都单调，所以两个最大值对每个轴、每个态都够。
    - 实测（`step::tests::a_step_about_a_minimum_is_stable_below_the_edge_of_its_reference_s_turn_and_its_kick_s_curvature`，两个态各在自己的谐振阱里）：crate 的单步矩阵的迹与公式一致到 2e-14；它自己的边在 0.909647π、0.547705π、0.468555π、0.305638π（ω_k²/ω² = 0.1、1、1.5、4），与公式一致到 1e-9；边以下 2000 步留在不变椭圆上，带内每步增长 e^μ（cosh μ = |迹|/2）。沿路径的求积不软化曲率：不变的态的踢取在固定的 r_h；跟随的态沿路径的力对位移线性的部分，在以 r_h 为中心的直线路径上积分为零。
    - 踢的曲率是内态所跟随的那条能级的曲率（`step::tests::a_following_state_s_kick_has_the_curvature_of_the_level_it_follows`，远失谐驻波里的二能级原子）：红失谐、阱在波腹时等于 ⟨∂∂Ĥ_h⟩；蓝失谐、阱在波节时全部来自态对耦合斜率的二阶响应 2|c′|²/Δ，"态被保持"的预测在那里没有边，而实测的边与能级曲率的公式一致（1e-3 内）。
    - 模型给的 ω_k²（`model/reach.rs`，# The kick's curvature）目前含两项：阱光对各个态比对参考态硬多少（阱心处两个势的 Hessian 之差的最大本征值，精确、带符号）；按裸能级折叠的光的条纹以及其余两个基态之间（或两个激发态之间）的常数项，各矩阵元的模乘它在簇的参考系里的残余波矢的平方，按 Gershgorin 的行和（一对光束、一个态时精确；多对光束时不认它们之间的相位，偏大）。**没有**含在内的：在原子处折叠的驱动的光移、簇里显式保留的态的耦合——用模型现有的界去界它们，实测偏大一到两个量级（PGC3D 的起始档会从 1.43 µs 降到 0.086 µs，GMD1C 到 0.39 µs，而检查在 0.72 µs 上就站住），所以这两类势阱的边仍由检查去发现：伴随层落在不稳定带里时，它的轨迹与运行的轨迹无界地分开，检查减半。
  - 生成元：传播在步的中点和两端三个节点上读生成元沿路径的变化（§2.1），节点相距 τ/2，并把它当作过这三点的抛物线。一个在簇的参考系里残余拍频为 Ω、残余波矢为 K 的矩阵元，沿速度为 v 的路径以 |Ω + K·v| ≤ |Ω| + |K| v 的速率转动，相邻节点之间转过这个速率乘 τ/2；到 π 时节点读到的只是它的混叠。所以对每个矩阵元 (|Ω| + |K| v)·τ/2 < π。K 与 Ω 取自模型自己的组装（每个拍频下它各矩阵元的最大残余波矢，`Model::sampled`：两个场分量各束光的波矢之和减去两态参考系之差），不按光的种类列表。
  - 为什么需要第二条：只有阱的共振时，R4_LIN_1 的顶档是 16 µs，5–10 cm/s 的原子一步跨过一到两个 lin⊥lin 图样的波长；8 与 16 µs 两层同样没有意义、彼此一致，两层比较在那里是瞎的。
- 起始档（`solve::first_rung`）：对运行可用、且它的两倍对伴随层（2τ，见下）可用的最大一档。两层的任务不同，条件各有其义，速率都取自模型判定所用的同一个可达范围（§1.8），范围长大时起始档跟着降：
  - 运行的步长是结果：它要对模型所判定的每一个原子可用——阱的共振以下，并且在可达范围的最大速率 v_max（`Reach::speed`）下分辨得了光。模型的折叠与步长用同一个有效域。范围之外的原子每一步都对它自己的路径检验（§1.8）：稳定性（参考流转角与踢的曲率的边，不随速率变；路径上某束光比范围上强时取路径上的曲率）是证明，不成立范围长大；在它的速率下分辨得了光是精度，不能分辨的一步照走，原子从那一步起按全部记账。两条边不是同一类（`solve::stable`、`solve::resolves`）。
  - 伴随层是探针，不是结果：它要稳定（上面那条边对每个原子都一样，运行与伴随层用同一个条件、同一个 ω 与 ω_k²），并且对典型原子分辨得了光，即取可达范围温度下的方均根速率 √(3k_BT_r/m)。两层里若有一层在多数原子上读到的是光的混叠，两层的一致或不一致就与步长无关；超出它上限的少数最快原子只按它们的份额进入差值。
  - 这条边起限制作用时，这就是"最大稳定档的下一档"。起始档至多是运行时长的一半：伴随层的步长自己也是一档，那时整次运行是它的一步。
  - 起始档是梯子上的一档，梯子的底是每条轨迹 2²⁴ 步的那个步长：一直数到底也没有可用的档（光或阱要求的步长比上限允许的还小；或者阱频、速率不是有限数，那时没有哪一档可用），就拒绝这个请求、返回错误（§9）。不可用的步长算出来的不是这个模型的解，不拿它当"到了下限照常返回"的结果。
- 步长的收敛是在试探上做的一次检查，不是每个输出上的误差界（定义：`estimate::between`、`solve::settle`、`solve::screen`、`solve::blind`、`solve::remedy`、`solve::checked`、`solve::Levels::told`）：
  - 两层：试探的轨迹跑步长 τ，同编号的轨迹在 2τ 下再跑一遍（伴随层）。同编号 = 同一个初始原子、同一组跳跃用数、同一条布朗路径（§2.4）。
  - 读的是误差在全程上的大小。一个量 Q 在第 k 个输出的步长误差 e_k = [Q_k(2τ) − Q_k(τ)]/(2^p − 1)（Richardson：e ∝ τ^p；p = 2 时是两层之差的 1/3）。检查读它在 t > 0 各输出上的均方 M = (1/K) Σ_k e_k²（方均根 √M）：损失、每个显示行（绝对）、总温度（相对 τ 层的总温度；两层都读得出的那些输出）各一个数。M = (平均误差)² + 误差随时间的方差：随时间变号的误差（振荡布居的相位误差）按它的大小计入，而带符号的平均在那里读到零。实测 R6_RAMAN_COUNTER（5 µs 对 10 µs，显示行）：带符号平均 0.43 %，方均根 2.2 %。
  - 估计不带噪声本底。估计值的平方里含有估计值自己的方差，没有误差也不为零。各组独立，两个不同组的值相乘就没有这一项：
    - M̂ = (1/K) Σ_k [(Σ_i x_ik)² − Σ_i x_ik²]/(G(G − 1))，x_ik 是第 i 组自己的 e_k，取 jackknife 的伪值 G·e_k(全体) − (G − 1)·e_k(去掉第 i 组)：对轨迹取平均的量（损失、显示行）它就是该组自己的差；T 是比值，它是 T 在两层合并值处的线性部分。一条规则适用于每个量。
    - E[M̂] = M，与噪声大小无关；没有误差时 M̂ 落在零的两侧。
    - 误差是 M̂ 自己的删一组 jackknife（每一组同时从两层、从所有输出里删掉，时间上的相关自然在内）。M̂ 的方差有两项：(4/G)⟨μ, Cμ⟩（有误差才有，随 1/G 降）与 (2/(G(G − 1))) tr C²（本底自己的涨落，随 1/G² 降）；jackknife 把第二项算成 2(G − 1)/(G − 2) 倍（Efron–Stein），所以没有误差时偏大，不会偏小。
  - 判定在平方上做，界是步长份额的平方 b = (s·ε)²（s = √(1/(1+2p))；均方按 τ^{2p} 变）。每一档、每加一批对之后都重读。一条原则：**只凭读数不留疑问的东西离开一档**。下一档的工作量是这一档的两倍，梯子不往回爬；而试探的对上读数是带噪声的（成对轨迹很早就分开，一个显示行的均方读数的误差与界同量级），被噪声抬高的读数换来的减半是白花的（实测见本节末）。
    - 超出：某个量的 M̂ − t·SE > b（t 取整族三十几个读数的区间），在本档自己的读数上或在保证本档的那个读数上（见"继承"）→ 减半：τ 那一层变成伴随层，只新跑 τ/2。降到 τ = 时长/2²⁴ 为止，到了仍超出就标记。
    - 阶检验过的档（它继承了上一档的读数，自己的读数没有推翻阶，见"阶的前提要检验"）：不超出就站住。不为把读数读得更窄而加对：读得更窄也不多记什么（见"记账"），读数分辨不出的大小写在结果里。
    - 阶没有检验过的档（一次尝试的起始档，没有继承的读数，只有两层）：那里 e = 差/(2^p − 1) 是假设，两层都太粗时它们可以彼此一致，远端不是误差的界（实测 R6_RAMAN_COUNTER 在 5 µs：显示行远端 2.9 %，对解析结果最大差 9.8 %）。所以它要读到"在内"才站住：每个量的 max(M̂, 0) + t·SE ≤ b（各用自己的区间）——份额给"阶没检验过的估计"留了均方上 1 + 2p 倍的余量。M̂ 为负时远端从零算起：大小不会为负，读到负值就是什么也没读到，排除不了比它自己的区间更小的误差。scout（11 对）不在内也站住，留给试探。试探上不在内时：
      - 上面一档是梯子上的档时（这次尝试是从上一次尝试站住的步长开始的，低于它自己的起始档；判据就是起始档的判据用在 2τ 上），在试探的轨迹上加读第三层：4τ，每条四分之一条轨迹的工作量。(2τ | 4τ) 的读数按阶降低后就是本档继承的读数：本档的阶与别的档一样被检验，代价是加对的伴随层的四分之一（88 条：22 条轨迹的量）。之后按"阶检验过的档"处理。
      - 在梯子的顶上（没有上面一档）：第三层是下面一档自己的试探（τ/2）；读它之前，加对省下的工作量有把握时才先加对。起始档凭第三层站住，要 (τ/2 | τ) 的读数换算到 τ 之后读到"在内"；否则取用下面一档。规则与两条路的工作量都在 §5.3（`solve::settle`、`solve::blind`、`solve::remedy`、`estimate::within_on`）。下面没有档可用时（已在梯子的最后一档，或读数什么也排除不了）没有可以比较的工作量，只剩这两条：
        - 那时加对按它**可能**做到的算：假设误差就是读数允许的最小值 L（近端 M̂ − t·SE，各量用自己的区间，从零算起），读数高出 L 的部分（值与区间）就是这些对的噪声，随 1/N 降：N 对上的远端 = L + (F − L)·N₀/N，N ≥ N₀·(F − L)/(b − L) 时在内；L ≥ b 时多少对都不够。一批至多把对数翻倍（§3 的批次规则），跑完重读。（原来把值按读到的算：N = N₀·t·SE/(b − M̂)，M̂ ≥ b 时"多少对都不够"——被噪声抬到 b 以上的读数于是直接离开这一档。）
        - 两者都没有时（§5.1 的"界用完"）：已在梯子的最后一档（再减半就超过每条轨迹 2²⁴ 步）而所需的对数超过轨迹上限，或者读数什么也排除不了（不是数，或离散读不出）。检查就以"看不见"结束：步长站住并标记，每个量的账目记检查没有排除的上限，即远端的方根 √(max(M̂, 0) + t·SE)（各用自己的区间；`solve::unexcluded`），不再记读清的部分。阶检验过的档读数什么也排除不了时同样处理。
  - 继承。减半得到的档继承上一档的读数，按阶降低（值和误差都除以 2^{2p}，`solve::carried`）；每个量由自己的读数和继承的读数中远端较小的那个保证（`solve::held`）。scout 减半留下的继承读数，在它让其站住的那一档上也给试探用（同一个模型、同样的步长）。
  - 阶的前提要检验。e = 差/(2^p − 1) 和继承都以"这几层之间 e ∝ τ^p"为前提；减半之后有三层，这个前提可以检验：本档自己的读数的近端高于继承读数的远端（都取整族的区间）就是前提被推翻（`solve::refuted`）——误差在这几档之间没有按阶下降，两个读数都不是步长误差——减半。逐个量检验，只检验两档都读得出的量：损失与各显示行总在其中；总温度只有两档都读出时才检验，只有一档读出时它没有可比的对象，不算在这一族里，也不妨碍别的量照常检验。
    - 实测 R6_RAMAN_COUNTER 显示行的 M̂：4.77e-4（5 | 10 µs）、2.71e-4（2.5 | 5）、3.10e-4（1.25 | 2.5）、3.7e-7（0.626 | 1.25）。到 1.25 µs 为止没有收敛：步长分辨不了多普勒相位。2.5 与 1.25 µs 上自己的读数是"在内"（方均根 1.7 % < 2.24 %），而解析参照在 2.5 µs 上最大差 0.147，比 5 µs 的 0.097 还大。只换统计量不够：没有这一条，它停在 2.5 µs，不通过；有了它停在 0.626 µs，通过（最大差 0.035）。
    - 限制：前提只有三层才能检验。梯子顶上的起始档自己读到"在内"时只有两层，那一档就凭 Richardson 站住。
    - 误差降得比阶更快时（上一档还不在渐近区；实测 R4_LIN_2 的总温度：0.72 µs 上读到 b 的 87 倍，0.36 µs 上读不出），继承的读数偏高，本档自己的读数远端更小，由它保证。
  - 记账：一个量在每个输出的账目里，步长这一项都是它的方均根里读清的部分 c = √max(M̂ − t·SE, 0)，t 取同一族的区间。没看到变化就是 0；步长凭自己的读数站住时它不超过份额。试探之后固定。读数取本档站住所凭的那一个（§5.3"写出与记账用哪个读数"，`solve::Levels::told`）：自己的（对 2τ）；梯子顶上凭下面一层站住的起始档，取 (τ/2 | τ) 的读数乘 2^{2p}。
  - 检查的分辨率照实写出、不记账：结果的方法说明里写明比较的是哪两个步长（本步长与它的两倍，或与它的一半）、多少对轨迹、方均根误差低于多少时分辨不出（同一个读数的 √(t·SE)：布居绝对、T 相对）。它不进任何总误差，本身也不触发标记。
  - 这是检查，不是界：只出现在运行中一小段时间里的误差会被整段运行的长度稀释；e 依赖格式的阶（上一条）。
  - 产品只跑 τ 一层，不再读步长。
  - 与带符号平均相比（原来的统计量；对随时间不变的误差它是最有力的）：设噪声在全程有 K′ 个独立的时段、单个输出上是 σ，平均能分辨 t·σ/√K′，均方的分辨率约为 (2/K′)^{1/4}·√t·σ——只有一个时段时相同，时段多时差 K′^{1/4} 倍；误差一旦被分辨出来，两者的区间一阶相同。实测（88 对，总温度的分辨率，均方 | 带符号平均）：PGC3D 0.716 µs 2.4 % | 2.9 %；四面体 MOT 0.716 µs 3.0 % | 4.0 %、0.358 µs 4.6 % | 3.7 %；GMD1C 1.458 µs 7.5 % | 10.6 %。带符号平均的噪声是全程最慢的那个模式（最大的一个），均方把它只当作 K′ 个模式之一，所以实测中没有吃亏。带符号的平均只能从下面界住 M，永远说不出"在内"，所以只用均方一个统计量，不加第二族读数。
  - 阈值取份额而不取目标（原来"检查必须看得见"取的是目标，且只会减半）：读不清就站住，等于让一个估计值在份额附近、真值更大的步长通过（R6_RAMAN_COUNTER 在 5 µs：远端 2.9 % < 5 %，站住，不通过）。这一条现在只对阶没有检验过的档成立——上面的规则。
  - 为什么"只凭不留疑问的读数离开一档"（实测，2026-11-11，8 个随机种子；此前每一档都要读到"在内"，读不清时按"值照读到的算"在加对与下一档之间选）：R4_LIN_2 停在 0.3577 µs 的 4 次、0.1788 µs 的 4 次（工作量 148 万到 452 万轨迹步），每一次从 0.3577 往下走，都是某一个显示行的 M̂ 被噪声抬到了 b 以上（1.4 ± 1.6 b："多少对都不够" → 下一档）。把停在两档的运行各自合起来比较：0.3577 µs 上没有一个显示行的步长误差读得出（最大的方均根 0.17 %，本底 0.3 %），总温度末端差 −1.0 ± 2.2 %——那些减半全是噪声决定的。同一批数据也说明账目记读清的部分（0）没有少记。
- 为什么只做检查（实测）：
  - 做成每个输出的界（产品两层都跑、每批重测，a60231dd）要多花一次运行的 30–240 %（同一条线上 CPU：R10_HELD_ANTINODE 120 对 95 s、R3_DOPPLER 472 对 205 s、R9_PUSH 58 对 17 s）。原因：成对轨迹在 PGC3D 上 100 µs 内就分开（两层之差的方差 / 单层方差：50 µs 处 0.35，100 µs 处 1.1，此后 1.5–2 即相互独立），关掉扩散也一样快——跳跃的时刻由步长定，光场波长尺度的结构把这点差别带到条纹的另一处；R3 上能保持 0.5 ms。之后 SE(e) 就是两个独立系综的，把 T 上 3 % 的误差分辨到 2σ 要约 870 对。
  - 把 e 在输出时刻上合并（Lepski 规则取窗口）降噪：e 不随时间变时 SE 降到 1/2–1/3 且无低估；e 随时间线性增长到 6 % 时，运行末尾记的界低于真值的占 16–54 %（允许 2.3 %）。改用窗口内直线则覆盖恢复而收益抵消。
  - 沿轨迹逐步读局部误差（每步对两个半步，再按动力学带到输出）：PGC3D 上 τ = 0.625 µs 读到 T_x +3.2 %（真值 −1 %）、1.25 µs 读到 +37 %（真值 −3 %）；读数用的"轴能量"在近共振光自己给力时不是运动守恒的量。三种局部形式都没有在三个轴上同时对。
  - e = C τ^p 要求 2τ 那一层也分辨得了决定误差的过程。PGC3D 1 ms：τ = 1.25（伴随 2.5 µs）读到 T 的 e = +11 到 +28 %，真值 −3 %：2.5 µs 分辨不了内态，差偏大一个量级；τ = 0.625（伴随 1.25 µs）读到的与真值同量级（1 % 上下）。偏大只会让步长更细。
- 实测（同一条线 e125aa2f 上各跑一次；上限与取到的步长；筛在这四个场景上都没有再减半）：

- 模型的决策（§5.2）里步长误差一律按份额 s·ε 取。定模型不用整套试探：scout（11 条的两层）筛过步长后，在它 τ 层的状态上测各被消去单元的误差；要显式跟踪某个单元、或原子超出了取值范围，就在这里换模型重来。范围长大而没有新的折叠在它上面不成立时，模型不变：只取决于模型的东西（模型本身连同它已经做出的部分、它的单元、参考态的准备阱、各初态分量的阱与初始系综、T(0) 的求积、报告用的阱、起始档要读的矩阵元）每个模型只做一次；取决于范围或步长的（范围、门、各单元怎样记账、范围留在外面的份额、踢的曲率、起始档、表、全部轨迹和在轨迹上读的一切）每次尝试重做（`solve::solve`、`solve::Setting`）。结果逐位不变；实测一个 P 核上长大后的那次尝试少做 4.9 ms（R3_DOPPLER，它的建立过程共 250–267 ms，其余是门 52 ms、范围留在外面的份额 54 ms、表 150 ms）与 26 ms（R4_LIN_2，共约 112 ms，其余主要是范围留在外面的份额 66–72 ms）。模型各单元的误差在每组第一条**仍被俘获的**轨迹的状态上测（每个输出 11 个状态）。
- 格式在任何长度上都做不出某一步（中点不动点不收敛到时间的舍入，或状态超出浮点范围）的轨迹：从做不出的时刻起不计入任何估计，单独计数并标记。它不是损失。
- 求积节点：一步内的时间积分（冲量、平均布居、范数的根）在 Gauss–Legendre 节点上读，节点数由被积二次型的带宽定，不调用模型；τ 减半节点随之减半。
- 每步内态只传播一次：沿直线路径，路径速度取预测的步中动量（起点态在步中点受的力算出的半步冲量）。原来的"预测再校正一遍"删掉了。无光时一步与反向一步仍回到舍入；有光时来回的偏差是"一步对两个半步"之差的 5e-5 到 2e-4（缀饰态出发），随 τ 下降快于 τ³，是步长误差的一部分。实测（PGC3D 100 µs，单线程）：一步 92 → 60 µs，结果在误差内一致。
- 路径速度 v_m：只预测（κ_h 加上起点态在 r_h 的剪切与参考力给出的半步冲量），不校正。预测差的是"态的变化带给冲量的那部分"的一半，O(τ²)；冲量对 v_m 的敏感度是 O(τ)，所以冲量差 O(τ³)，就是格式自己的局部阶。
- 损失：步长对损失的误差与显示行、T 同一个量（试探两层的损失之差的 1/(2^p − 1)）；没有损失能量的窗口。

### 2.3 表（定义：`table`、`model::tabulate`）
- 表化的对象：每个簇、每组光下，近光消去的非线性部分，即该簇的"近光形式"——光移与耦合 S 及其多普勒伴随项、跳跃 C_aT 与 C_aT2、显式激发态的 van Vleck 移、响应 T 与 T2（读出用）——都写在各载波的场基上，是若干复数。线性部分（场分量 e_k、多普勒移 w_l、平面波相位）在原子处精确计算，不进表。表化与不表化用的是同一个组装（§1.4），只是这些形式的来源不同。
- 坐标：消去通过分母里的能级和各载波的缀饰、自能依赖位置。不是载波的频率以它的相干矩阵进入能级，即该频率坐标图的函数（光强、偏振角、相对相位）；载波以它的缀饰进入：T̄ 下是它每个偏振单元的光强 I_u（它所在频率的静态形式也按 I_u 进入，§1.4），缀饰单元被保留时是它的坐标图。每个坐标取它的整个值域，所以原子走不到表的边上。
- 轴：一个坐标的先验权重 = 它在可达范围内把簇的谱线移动多少个半宽（响应是谱线失谐的极点，它的相对变化至多是这个数）。光强坐标的权重 = 单位光强的移动 × 可达范围内光强离焦点值的可证界（§1.8），所以平面波的光强处处相同、权重为零。表留在外面的东西只有一个判据，就是下面的"表的份额"，不论它是在一个轴的节点之间，还是在一个不作轴的坐标里：响应误差的两倍在份额内，势的误差在 T 的份额 × k_BT_r 内。
  - 先验：权重不超过份额之半（min(0.0078, 0.022)/2 = 0.0039，即加密对一个轴所要求的同一个响应误差）的坐标，固定在焦点值。
  - 权重是界：它所跨的谱线可能远离共振，这个坐标也可能根本不进入响应（唯一的载波自己的偏振单元：它的缀饰不在它自己响应的分母里）。所以更重的坐标要问表需不需要它，问法是"看一眼"（`Model::look`）：把该坐标固定在焦点值的那张表，与把该坐标挪开后的消去本身，在表的可达范围内的节点上比较，用加密的同两个量度、同一份额。看两次：
    - 取作轴之前，从最重的坐标起：已取的各轴各在首个网格上的那张表，对该坐标在自己首个网格上可达范围内的各节点。超出份额就取作轴（直到一次插值不比它替代的消去便宜、或首个网格超出工作量界、或已有 6 个轴（`table::MOST_AXES`，查表时各轴模板的容量，不是推导出的数）为止）；在份额内就固定。什么也不带的坐标只花这几个节点，不会把表乘大。
    - 加密之后：每个这样固定下来的坐标，取第一次看时读数最坏的那个值，对加密后的表在可达范围内的每个节点再看一次。在那里超出份额，它终究是轴，带上它重新建表。
  - 两次看说明什么、不说明什么。第一次只看到别的轴的首批节点：响应因谱线移动 δ 而改变 δ/|D|，在某个轴把谱线带过共振处最大，而该轴首批节点之间的这一部分看不到。第二次在留下的表的每个节点上（加密本身也只在节点上读），但只看该坐标的一个值：对按挪动量成比例地移动谱线的坐标（一切光强），误差 |δ|/|D + δ| 在小于 1 时随 |δ| 单调上升，所以可达范围内最远的那个值（即第一次看到的最坏值）在每个节点上都是最坏的；对角度与相位，第一次看到的次序在别的节点上不一定成立。两次都不看节点之间，与加密一样。固定的坐标留下的误差由下面的整体读数在原子处读出、记账：读数是量度，"看"只决定取哪些轴。一个都不需要时，表就是焦点处的一组值。
  - 原来以布居目标 0.05 为取轴的阈值：固定在焦点的坐标可以让响应差到 0.05，而已有的轴被加密到 0.004。实测（构造的例子：R2 的探测光在焦点共振，光镊在整个光强范围内只把谱线移动 0.04 个半宽）：可达范围 120 µK 时，不作轴的表在范围边缘读到 2.1e-2、平均 8.2e-3，超过份额 7.8e-3 而没有轴可减半；现在光镊光强是轴（13 个节点），读数 1.8e-6。参照场景里没有这种情形（表的记账误差 1e-6–3e-5）：R3、R10 里冷却光自己的单元按权重（0.045、0.0066）被问到，第一次看读到份额的 6e-7，固定；最后的表与原来逐位相同。代价按建表时消去的节点数：PGC3D 40 → 52，R3 970 → 1430，R10 634 → 799，R4_LIN_1 28 → 40。
- 插值：每轴三次 Hermite（Catmull–Rom 斜率，C¹）；周期相位轴用周期插值。力取插值自身沿各轴的导数乘坐标的梯度。于是表化的生成元的力就是它自己厄米部分的梯度。衰减取表里另存的乘积 Σ J†J 的插值，跳跃取 J 的插值（§1.4）：两者差一个插值误差，在节点上严格相等，所以表化的生成元只在节点上严格是 Lindblad 的，节点之间到表的误差为止（这个差含在整体读数里）。表代表的是"近光形式为插值"的那个模型。表只在各轴的值域内取值，不外推；越界是调用方的错误，直接拒绝。
- 加密，在使用之前做完。响应是失谐的极点，轴把谱线带过共振是阱中近共振光的常态，首个网格分辨不了它。把一个轴的间距减半，新节点正好落在原来各区间的中点。那里并不是插值误差最大的地方：三次插值的首项误差 (h³f‴/6)·u(1 − u)(1 − 2u) 在中点为零，最大在 u ≈ 0.21 与 0.79（`table`），所以这个检查读到的是下一阶 h⁴f⁗，不是减半之前那张表的误差的界；保留下来的表到底差多少，由原子处的整体读数读出。在这些节点上，把减半之前的表与消去本身比较（消去的值就是新节点的值，所以这个检查不另花消去），范围是可达范围碰到的所有区间：光强轴取焦点值 ± 光强变化的可证界，角与相位取整个值域。量度有两个，各取这些节点上的最大值：
  - 响应的相对误差 (‖ΔT‖ + w‖ΔT2‖)/‖T‖，w 是该载波各光束在可达速度下最大的多普勒移；速率是响应的二次式，所以取它的两倍；
  - 势的误差的界：‖H̃_h − H_h‖ 按行的界，每项按两个场分量的峰值。
  一直减半到"减半之前的表"落在份额之内，保留更细的那张，它自己的误差比验证过的再小插值的阶（值三阶、梯度二阶）。下一个网格超出工作量界就停，误差按整体读数记账。不是数的误差（节点落在实分母的极点上）算作读不出，记 +∞，永远不在份额内。
- 表的份额。表的误差要低于任何一次运行读得出的量，所以取最大系综的分辨率，N_max = 2¹⁴ 条轨迹、置信度 z：
  - 显示量，绝对：z/(2√N_max) = 0.0078（一个份额 p 的标准误差至多 1/(2√N)）；
  - T，相对：z√(2/N_max) = 0.022（方差的标准误差，正态理论）；势的误差按 T 的份额乘 k_BT_r。
  误差在这两个数以内，就没有哪次运行会受表的限制。
- 表的误差在账本里的形式（整体读数）：在试探状态上把表给出的近光形式与精确消去比较，按它对该状态的生成元造成的误差记。δ = ‖(Ñ − N)ψ‖/‖Nψ‖，N 是近光在生成元里的部分（多普勒伴随项取原子的动量）。布居（绝对）记 δ·P_g，P_g 是该状态的基态布居；T（相对）记 δ·P_g 与 |ΔV|/k_BT_r 中较大的，ΔV = ⟨ψ|H̃_h − H_h|ψ⟩ 是势的改变（保守的改变，动能至多跟着变这么多）。力的误差不另记：它是小量 ΔV 的梯度。每个轴另有自己的插值误差读数（同一点上粗、细两套插值之差），用来指出是哪个轴。

### 2.4 随机数（定义：`random`）
- Philox4x32-10。键为（种子, 用途），计数器为（轨迹, 事件）。
- 第 j 次跳跃用第 j 个流：只差步长或模型的两次运行，在同一跳跃序号上抽到同样的数（共同随机数）。抽取顺序固定。
- 每条轨迹有自己的布朗路径（三个独立的标准布朗运动，§1.6 的扩散），它是时间的函数，与步长无关（定义：`adapt::Path`；只有这一种实现）：
  - 时间按输出间隔分成格子。每个格子上路径的那一段（增量 ΔW 与关于中点的一阶矩 ΔZ）取自该格子自己的流（用途 Diffusion）；格子的两半是两端之间的布朗桥（`step::Brownian::split`），取自那个节点的流，逐层往下：任何一档的任何一个区间上的那一段都是（种子，轨迹号，区间）的函数，并且等于它两半之和——2τ 的一步取的正是它跨过的两个 τ 步之和。
  - 不落在网格上的步（被格式拒绝后取半的步，以及它之后的那些 τ；跳跃不切）把所在区间在该时刻再切一次（同一个布朗桥，取自以该时刻为键的流，用途 Bridge），剩下的部分留给下一步。
  - 每一段的分布都严格是布朗路径在该段上的分布，不相交的段相互独立。产品只用到这个分布；试探的两层用到"同一条路径"。
  - 读树是增量的：记住上一个区间从格子到它的那条枝，下一个区间只从两条枝分开的那一层往下算（相邻区间平均只差两个节点），结果逐位相同。
  - 实测（`adapt::tests`）：τ = 1、2、4 µs 三档，每个 2τ 步与它的两个 τ 步之和相差 ≤ 1e-13；乱序读各区间与各自从头读逐位相同；切出的一段的方差为 s 与 s³/12、协方差为零。

### 2.5 初始系综（定义：`ensemble`）
- 每个初态分量在自己的准备阱里：降低的等温分布乘每轴谐振子的 Wigner 因子；精确拒绝抽样，包络用证明的上界。
- 拉丁超立方分组：每组 8 条轨迹，组间独立。

## 3 统计（定义：`estimate`）

- 所有轨迹都跑到最后一个输出时刻。每个输出的估计是全部轨迹的样本均值，按组 jackknife，区间用 Student t_{g−1}。
- 计入（`estimate`，# What is counted）：一条轨迹在某个输出时刻有结果（被俘获，或此前已丢失）才计入。在那之前没有结果地结束的轨迹（格式在所有步长上都拒绝一步、跳跃无光子可发；或者某一步未经证明——这一轮的模型不是它路径上的模型，这一轮随后扩大范围重来，所以它们只出现在这一轮运行中发出的结果里）从结束起不计入。估计取计入的轨迹；不计入的份额 u 上的结果未知，概率最多差它的份额：|P − P_c| = u|P_u − P_c| ≤ u，按全部计入显示量（损失和各显示行）的模型误差 A；T 上它们的那部分没有任何界，所以有轨迹不计入的时刻 T 没有账目。一条都不计入的时刻（u = 1）什么也不估：损失沿用前一时刻的，显示量按 100 % 计，结果里写明。实测（79cb5075 上的 S2Q）：试探先头的 11 个原子在第二轮的范围里全部在 1.1 ms 前未经证明，用它们做的检查点有 79 个时刻一条都不计入——原来给出损失 NaN、统计 ∞，worker 因此拒绝整个结果。
- 显示行直接对 A·ρ_s 做 jackknife；T 的 plug-in 方差补上 s²/n 项。
- N 次抽样里出现 n 次的份额只有一个函数：Wilson 远端（`wilson`）；n = 0 时是 z²/(N + z²)（`unseen`）。
- 批次：每批之后，对每个计入目标的量（每个输出的显示量；每个输出的总温度）算总误差 E² = A² + c² + S²：A 是模型误差、c 是步长检查读清的部分（§2.2），两者都由试探固定，A 另加本次运行里到了可达范围之外的原子所带的那一项（§1.8，每批之前重读）；S 是统计区间。全部在目标内就停——这就是账本标记一个输出所用的同一个判据（§4）。停止只依赖本次的标准误差与范围之外原子的读数，不依赖估计值本身。
- 统计的余地：R² = ε² − A² − c²。所需轨迹数按 S ∝ N^{−1/2} 预测（显示量不少于"零计数的 Wilson 远端不超过余地"所要的条数）。没有余地的量（A² + c² ≥ ε²，模型的决策已经保留了能保留的）不追：由账本标记。
  - 总温度的统计读不出的时刻（被俘获的原子不足两组）没有可以外推的区间：所需轨迹数按一个轴的方差的正态理论预测，相对区间 z√(2/(N h))（N h 是被俘获的原子数；三个轴的平均不会比它大）。这是同一个量的第二条预测规则，只用在这种时刻。
- 试探的大小（`solve::pilot_size`）：试探是运行的头一批轨迹，任何运行都不会停在比它更少的轨迹上。显示量的统计不小于零计数的 Wilson 远端（§4），所以在步长份额旁、模型没有误差时，N 至少要使 z²/(N + z²) ≤ √(1 − s²)·ε：N ≥ z²(1/(√(1 − s²) ε) − 1) = 85.4（z = 2，s² = 1/5，ε = 0.05），取整组是 11 组、88 条。
- 一批至多把轨迹数翻倍：所需轨迹数是由已有各组的方差预测的（起初只有试探的 11 组），一批至多跑到这次预测所依据的轨迹数的 2 倍。各批累加，运行停在第一个满足目标的总数上；所以最后的总数不超过刚好够用的 2 倍。
- T 的目标在总温度上：用户的 10 %（相对，置信度 z）说的是三个实验室轴的 T 的平均（总温度），它的统计误差是这个平均值自己的刀切误差。t > 0 的每个输出、只要读得出，就计入目标。
  - 为什么不逐轴：用户（2026-11-11）："不用每个轴，我要的 10 % 是总的温度 10 % 相对；两倍标准差还是要保证。" 逐轴时，能量占比很小的一个轴（例如冷到几 µK 的弱束缚轴）决定了整次计算的轨迹数。
  - 跟着总温度走的：步长的筛（§2.2，两层之差取总温度的）、记账的步长项、停止与所需轨迹数、账本里 T 的总误差与标记（§4）。各轴的 T 照常给出，只带它自己的统计误差，不计入任何目标。
  - 经典区 k_BT_a ≥ 4ħω_a 只作报告（逐时刻、逐轴的 `classical`），不参与求解的任何决定。
- 轨迹数上限 2¹⁴：到了照常返回，状态为 partial。

## 4 账本（定义：`ledger`）

- 每个输出的总误差 E² = A² + b² + S²：
  - A：模型误差，即各单元的实测误差，加模型的可达范围（§1.8）留在外面的那部分初始系综：范围的水平按谐振阱的分位数留出份额 s，真实的阱留在外面多少由初始系综密度的求积给出（§1.8，不抽样）——布居上是范围之外的原子份额，T 上是它们占的动能份额，各自加上求积最后两级之差；与本次实际跑了多少条无关。账本里各列一条。再加运行中到了范围之外的原子所带的那一项（§1.8；它们的每一步都在自己的状态上被证明）：按它们的份额乘以在它们的状态上读到的模型误差超出已记部分的量；它是产品自己读出的，布居与 T 各列一条；
  - b：步长项，即试探的两层之差在全程上的方均根里读清的部分 c（§2.2；没看到变化时为 0）；对显示量取各显示行与损失中最大的；试探读完之前（scout、试探途中的结果）按步长份额 s·ε 记；检查以"看不见"结束时（§2.2）记它没有排除的上限，并标记。它是检查的结果，不是界：检查的分辨率写在方法说明里，不进总误差；
  - S：统计误差，jackknife 的区间 t·SE（§3）。对显示量（各显示行与损失）它不小于零计数的 Wilson 远端 z²/(N + z²)，N 是本次已跑的轨迹数：N 条轨迹都没有出现的事件（一次损失、一个没到过的态），jackknife 读不出它的离散。它也不大于 1：显示量是概率，误差不会超过它的范围（读不出的区间也只说到这里）。
  - 不计入的轨迹的份额（§3）按全部记在显示量的 A 里；它不是任何单元的误差，保留单元的决定不看它。
  - 显示量误差的每一个上限都是同一个（`solve::probability_error`）：至多 1；不是数的误差就是整个范围 1——不让 `min` 把 NaN 变成一个界。凡是"计数/份额/权重可能为零"的比值，都在分母为零处给出明确的"读不出/无界/没有这个量"，而不是 NaN（审计表见 leak.status.md；类测试 `every_estimator_and_account_is_a_number_or_says_why_on_every_kind_of_output`）。没有原子被俘获的时刻没有 T，也就没有 T 的看法（`looks`）。
  - A 里范围之外的份额与 S 的这个下限是两笔不同的误差，不重复：前者是模型判定范围之外的系综份额（求积），后者是有限样本对零计数的统计（本次的 N，§3 的 Wilson 远端）。
- t = 0：布居是请求的初态，没有误差。T(0) 是初始系综的精确矩，由求积算出；它的账目只有 b 一项，取求积最后两级之差（相对）。b 是把离散加密就会消失的那一项：t > 0 时是时间步长的，t = 0 时是求积节点的。
- t > 0：总温度有一份账目（步长项是它自己读数里读清的部分，统计是它自己的区间），只在统计、模型误差、步长误差三者都读得出的时刻才有；三项都按持有份额 1 − L 计权（§0）。
- totals 是先验部分 √(A² + b²) 在各输出上的最大值：布居取所有输出；T 取所有有账目的输出（总温度）——totals 说的是所显示的 T 被近似留下多少误差。flagged 对 T 标的是总温度，只标它有账目的时刻；统计读得出而模型或步长对温度的误差读不出的时刻另标一条。
- 条目逐条列出（label, estimate, action）。action 写明这个数是怎么得到的：单元的误差沿试探轨迹实测，或按可达范围上的界记账（§5.4）；表的误差在试探状态上对照消去本身实测；范围之外的份额按初始系综的密度求积；运行中到了范围之外的原子在产品里逐输出读出（§1.8）；步长项是两层配对比较里读清的部分。flagged 是总误差超出目标的时刻段；没有原子的时刻不参与显示的最大值。
- 没有"只记说明"的精度结论。

## 5 决策（一条规则；定义：`decide`）

### 5.1 形式
- 每个决策都由四样东西构成：当前一级、更精确的一级、比较的输出、代价。
- 读 = 同一批轨迹（共同随机数）或同一批采样态上的差 d 及其误差。
- 三种结果：
  - 在内：|d| + z·SE ≤ 份额 → 保留；
  - 超出：|d| − z·SE > 份额 → 细化到下一级（步长减半，表的一个轴减半），到了再读；不按实测比值算细化的倍数；
  - 读不清：在工作量界内细化；界用完就标记，把可读的界 |d| + z·SE 计入总误差。
- 一个决策同时看许多个读数时：判"超出"用整族的区间（Šidák：最大的那个噪声读数不该触发细化），判"在内"每个读数各用自己的区间（每一个都得自己落在份额内）。
- 否证是另一种决策：当前一级已经按某个界记账，读数只能推翻它；在内与读不清都让记账的界保持不变。可达范围（§1.8）对试探的 T 与对试探在范围之外的原子数也是这样一个否证。产品里到了范围之外的原子不是否证而是读数：它们带的误差照实进模型账目，范围只在这一项放不下时长大（§1.8）。一步在它的路径上没有被证明（§1.8）既不是读数也不是否证：模型不是那一步的模型，那次尝试就此结束，范围长大到装下它。
- 花费：pays = 预计节省 − z·SE(节省) > 花费。
- 工作量 = 引擎按算法计数的乘加数（推导，不标定）。

### 5.2 模型单元
- 单元（没有按光分类的单元：没有“远分量”“远拍频”）：
  - 每个驱动一个。按裸能级折叠的：保留 → 按原子处的能级折叠；按原子处能级折叠的：保留 → 显式。它的激发态已被别的驱动变成显式时（两级都一样），它是拉曼对的一条腿：折叠的值（激发态块取双光子距离，§1.2；响应里的自能，§1.4）、门与记账的误差（§1.5）都按这一对，仍是同一个单元；
  - 两个态在一个精确拍频上的耦合（两个基态，或一个显式激发态与另一个激发态）：保留 → 进入生成元，两态并成一个簇，帧差等于拍频；
  - 一个簇按原子处能级的折叠的阶（有四阶的簇，§1.4）：保留 → 该簇的折叠取到四阶。它没有存在门：折叠存在处，它的下一阶也存在；折叠不存在的驱动仍由它自己的单元保留为显式。
  - 载波的缀饰（§1.4）；每对两源光子相干。
- 单元是相对于当前模型的：保留一个单元会重新闭包，簇和帧随之改变，候选单元要在新模型上重新列出（例如光子相干只在两个不同帧频率落到同一簇时才是单元）。保留的单元按值携带到下一个模型。簇内残余拍频恰为零的耦合，保留没有代价，误差为零。
- 没有事先的存在门（§1.5）：第一个模型什么都不保留，折叠在原子处不成立就表现为它在那里实测的误差，按下面的规则保留。
- 一个单元在某个状态上的误差没有界或不是数（距离为零的耦合、远离适用范围的折叠、失控守卫停下的原子）：记为该状态的全部——原子的每一行（概率的全程）和它在 T 里的全部份额，不算流（`solve::Booking::of`），与未分辨的原子同样记账。
- 侦察的保留先于范围的否证：单元误差让某个量没有统计余地的模型不是这些原子的模型，它们读到的 T 也是那个模型的（什么都不保留时，PGC3D、TET 的侦察把原子加热到 153、198 µK，为它们长大的范围一直留着：CPU 是发布线的 1.7、4.2 倍）。
- 单元的输出误差 = 沿试探轨迹、在误差产生处实测的小参数，经 §1.5 的推导关系映射到各输出。记账的模型误差是合并的一个数（`solve::Measured::combined`）：每个状态上所有折叠单元的误差合成该状态自己的误差（各单元在一个状态上的份额加起来是该状态的，§1.5），再对状态取平均；逐单元的误差只用于选择保留哪些。
- 保留是一次比较：读到的记账误差对保留的代价，在读数给出的整个集合上做一次，保留的集合只增不减、从不撤销；每次保留重新闭包、重新试探（`solve::keep`）：
  - 某个输出时刻已经没有统计的余地（模型误差加步长份额占满目标）：按这些时刻上的误差权重（持有份额 ×（布居误差/0.05 + T 误差/0.10）；只算有试探状态被读到、且还有原子被俘获的时刻——没读到状态的时刻每个单元都取同一个界，分不出哪个）除以保留后模型每 µs 的工作量（它自己的平均速率，见下面的计价），从大到小取单元（保留被拒绝的不取），直到每个读数都重新有余地；然后从最贵的起逐个检查，去掉它后每个仍没有余地的读数不变就去掉——这一组里没有可以省下的单元；一次保留（`solve::needed`）。保留后模型的速率要建它自己的表（每个节点一次消去，还有网格的内存），所以只在这一组的选择问到时才算、每个只算一次：先用它"只算步本身"的工作量（不带表，不含中点组装与跳跃的光子——这些正是表让它变便宜的部分；步的计数是簇的计划与生成元图像的，表只在它的误差以内改变）给出价值的上界，按上界的顺序问，已算出的最好价值不小于下一个的上界就停——取到的单元与每个都算出时相同。（原来一次只保留一个、每次一个新尝试：S3 的探测光在 14 次尝试里保留了 14 个裸驱动，每次一个模型、它的门和一次 scout；只按权重一次取，会连载波的缀饰一起保留，每步贵 3–4 倍，而只保留裸驱动就已有余地。R4_LIN_2 在 76.5 µK 的先导上有 733 个单元有权重，每个都建表时 8 GB 内存不够；按上界只建了 3 个。S3 的先导在 113 µK 上按价值第三个取了载波的缀饰——它的模型每 µs 是裸驱动的两倍——而取完六个后裸驱动单独就有余地。）
  - 否则按 pays：自己单独保留就"预计总工作量下降的份额，扣掉它的 z·SE，仍大于 0"的单元是候选；按单独的节省从大到小，取前几个一起保留时节省（扣掉它的 z·SE）最大的那一组——它们的误差一起离开读数，保留后的模型只建一次、计价一次（`Pricing::joint`）。
    - 只给这样的单元建保留后的模型并计价：假设保留后每 µs 不比现在更贵，单是去掉它的误差就付得起重做试探。
    - 不去找"保留比折叠更便宜"的单元：折叠就是为了更便宜；哪里不是，是那个折叠的缺陷，不由这里的选择来补。
    - 实测（PGC3D，100 µs）：原先对 528 个单元逐个建模型计价要 7.4 s，而产品轨迹只要 1 s；计价选中的一个拉曼耦合（预计更便宜）保留后每步实际贵 7.5 倍。
    - 每 µs 的工作量按运行自己的计数（`solve::rate`）：一步（积分器）加上它的中点组装与散射，除以 τ，再加上轨迹自己的跳跃率乘每次跳跃的光子；全部用该模型自己的近场表计数（`Run::tabulated`）——当前模型用本次尝试的表，保留后的模型用它下一次尝试会建的表（同一范围、同一节点上限）。保留带来的表的坐标就是表的轴，插值的工作量随轴数按 4 的幂增长。跳跃率是光的散射率，保留不改变它。（原来按不带表的精确消去计价：R4 上当前模型 1.78e7 对带表 1.29e5，差 138 倍；保留缀饰在不带表时比当前还"便宜"（S3：缀饰的模型不带表与当前相近），带表是 2.0 倍，实测每步 210 → 510 CPU-µs。R4 上保留四阶的模型带表预计 ×1.64，实测每步 37 → 60 CPU-µs，×1.63。）
    - scout（每个输出 11 个状态）上，余地与计价都按它的读数不留疑问的模型误差：每个模型的误差都减去当前模型误差在 scout 各组上的 jackknife 区间（整族读数），不低于 0（`solve::doubt`、`solve::clear`）；先导按它全部的状态读。单元的误差在状态上是重尾的，把余地读高的那几个读数同样把当前模型要的工作量读高：need 是统计区间除以余地，点估计几乎占满目标时 need 可以是任何数，刀切的每一份都在那里——节省读成接近 1、散布接近 0。（实测 R4_LIN_2：余地按近端、计价按点估计时，76.5 µK 的 scout 先按计价保留了一侧镜像的裸驱动，下一个 scout 在 need 168421 处保留了载波的缀饰，而它的近端余地是满的；产品 1352 条。两条路都按近端后 scout 不保留，先导只保留余地需要的一个四阶，704 条，轨迹步 5.22 M → 3.42 M，通过解析参照。）
    - 计价读的每 µs 工作量、表的整体读数（§5.4）都是"全程上被俘获状态的平均"：Σ_i Σ_{k∈H_i} f_ik / Σ_i |H_i|，H_i 是第 i 条轨迹在 t > 0 仍被俘获的那些输出（一条轨迹的工作量是它被俘获期间的速率之和；误差记在被俘获的原子上）。轨迹是系综里独立的那一份，它沿时间的各个状态不是，所以每条试探轨迹只读一个状态，代表它自己的整个和（一点求积，权重 |H_i|）：平均 = Σ_i |H_i| f_i / Σ_i |H_i|（`solve::one_each`、`solve::over_the_run`）。读的位置在全程上均匀铺开：第 i 条取 H_i 里位于 u_i = (ρ_i + ½)/n 处的那个输出（n 是轨迹数，即把全程分成 n 等份的各个中点）；G 组里第 g 组的第 m 条的序号是 ρ = m·G + g，所以每一组自己的各条就相隔 1/(组内条数) 铺满全程，各组之间错开 1/n——删一组的 jackknife 不会把运行的某一段整个删掉。位置只由轨迹的编号决定，对每个模型都是同一批状态。t > 0 没有任何输出被俘获的轨迹不给状态。（原来的规则取"各组第一条轨迹、在 1 + 编号 mod (输出数 − 1) 那个输出"：编号相差 8，11 个状态落在相连的 80 个输出里，t > 0 的输出数能整除 8 时落在同一个输出上。）
    - 不撤销。计价知道的是保留后的模型在当前步长上每步的工作量；保留后的模型自己的步长检查可能取更短的一档，那是它的精度所需，与任何模型的步长一样读出，不再拿来交换。原来的撤销（步长检查要走到的那一档若使保留后的模型比保留前更贵就撤销，撤销过的不再计价）是在同样的读数上重做同一个决定，结果来回反复：PGC3D 在一批记账过高的裸驱动上保留/撤销约 20 次，每次一个模型、它的门和一次先导（bounds3.status.md）。
- 试探在某个时刻没有被俘获的原子时，单元在该时刻的误差取它的界：布居 1，T 未知。
- 不做"再多保留一个单元"的配对否证。实测（88 对，PGC3D、R2、R3、R5、R1 五个）：配对差的区间是该单元记账误差的 3–30 倍，从未推翻过什么；它只检验记账最大的那个单元，被低估的单元（如 R6 的远失谐拉曼对）它测不到；而它占一次运行的 10–40 %（要另建模型和表）。单元的误差由 §1.5 的推导与试探上的实测负责，被低估的情形由解析参照（§6）来查。

### 5.3 步长
- 按 §2.2：一个全局常数 τ。四样东西（§5.1）：当前一级是 τ；比较的一级是更粗的 2τ（只花一半的步数），按阶 p 推出 τ 自己的误差；比较的输出是全部显示的输出；代价是试探的伴随层（88 条），起始档读不到"在内"时再加它的第三层——上面一档是梯子上的档时是 4τ（各四分之一条），在梯子顶上是下面一档的试探 τ/2（各两条）——以及梯子顶上在第三层之前加的对（省下的工作量有把握时才加；各半条）。
- 梯子的起始档由"节点分辨得了格式所采样的东西"定（运行的步长与伴随层各有条件，§2.2）；只有一处定步长：scout 与试探上的检查（§2.2：两层之差在全程上的均方，对步长份额的平方）。一条原则管每一档：只凭不留疑问的读数离开一档——明显超出，或阶被推翻，才减半；阶检验过的档否则站住。
  - 阶要三层才能检验。减半得到的档有三层（它继承上一档的读数）。一次尝试的起始档只有两层：读到"在内"就凭两层站住；读不到时取它的第三层，之后与别的档一样处理：
    - 上面一档是梯子上的档时（本次尝试从上一次站住的步长开始，低于它自己的起始档），第三层是 4τ：(2τ | 4τ) 的读数按阶降低后就是本档继承的读数。
    - 在梯子的顶上（上面没有档），第三层是下面一档自己的试探：同一批轨迹在 τ/2 下跑一遍（两倍的步数）。(τ/2 | τ) 的读数与本档读数按阶降低后的值比较（`solve::refuted`，与任何一档检验自己继承的阶是同一个检验）。本档照原样站住（下面一档只是被读过，没有被取用，花掉的是它的试探）要三条都成立：没有推翻阶；没有读数明显超出；这个读数换算到本档之后读到"在内"（`solve::certifies`）——本档的误差是 (τ/2 | τ) 之差的 2^p/(2^p − 1)，均方是读数的 2^{2p} 倍（见下"写出与记账用哪个读数"），它的远端 max(M̂, 0) + t·SE（各量用自己的区间）不超过份额的平方 b，与本档自己的读数要满足的是同一个判据（`solve::blind`）。**起始档只凭一个关于它自己误差、并且读到"在内"的读数站住**：两层的读数对它的粗层说的比对细层说的少 2^p 倍（方均根），一个在 τ 上分辨不出份额大小误差的读数，什么也没看到并不说明 τ 没有误差。否则本档被离开，已经跑的那个试探就是下面一档自己的：它自己的读数就是这同一个读数，阶由它检验过，之后与任何一档一样处理（没有推翻、没有超出就站住；否则接着减半）。
    - 读第三层之前，加对省下的工作量有把握时先加对（`solve::remedy`、`estimate::within_on`）。工作量以 τ 下的一条轨迹为单位，从此刻算到运行结束；N 是产品预计要跑的轨迹数，N₀ 是已有的对数：
      - 现在就往下走：下面一档的试探（同一批轨迹在 τ/2）加它的产品，W_d = 2·max(N, 试探)。这个试探就是本档的第三层，读数换算之后读到"在内"时本档仍然站住；但定价按"取用下面一档"算：阶成立时，这个读数换算到 τ 就是本档自己读数的那个数，噪声不会更小（成对轨迹不分开时相同，分开时是 2^p 到 2^{2p} 倍），它读到"在内"的机会不比本档自己的读数大，而后者没有读到。它确实让本档站住的情形（2τ 那一层不在渐近区、本档自己的读数偏高：默认场景）里，往下走比定的价便宜。
      - 加到 P 对，读不到"在内"再往下走。π(P) 是读数在 P 对上读到"在内"的概率（下一条）。读到了，本档站住：多花的是这些对的伴随层（各半条）和它们细层里超出 N 的部分，到运行结束共 W_s(P) = ½(P − N₀) + max(N, P) − N₀。没读到，这些对的两层都白跑，(3/2)(P − N₀)，往下走的全部工作量照旧。
      - 所以加对相对"现在就往下走"省下的工作量是一次抽签：以概率 π 省 S = W_d − W_s(P)，以概率 1 − π 亏 (3/2)(P − N₀)。它的期望就是两条路期望工作量之差 πS − (1 − π)(3/2)(P − N₀)，离散是这次抽签自己的 √(π(1 − π))·(S + (3/2)(P − N₀))。期望超过 z 倍离散才加对（§5.1 的花费判据 pays：预计节省 − z·SE(节省) > 0，与每一笔"为预计的节省先花工作量"的决定同一条）：取有把握的节省最大的 P，跑一批（至多翻倍，§3），重读，按新读数重新决定——已经花掉的不再计入，每次只比较此后的工作量。否则往下走。即使加对不花工作量，也要 π > z²/(1 + z²) = 0.8：加对只用在"差一点就在内"的读数上，不用在"有可能在内"的读数上。
      - π(P) 由读数自己的值与误差算出（`estimate::within_on`），不设常数。M̂ 是 U 统计量，G 组上它的方差是 V(G) = 4ζ₁/G + 2ζ₂/(G(G − 1))（§2.2：ζ₁ = ⟨μ, Cμ⟩ 有误差才有，ζ₂ = tr C² 是本底自己的涨落），jackknife 读到的是 J(G) = 4ζ₁/G + 4ζ₂/(G(G − 2))（本底那一项多算 2(G − 1)/(G − 2) 倍）。
        - 估计值的变化：G₀ 组上的 M̂ 等于 G 组上的 M̂ 加上后者不含的一部分，所以 M̂(G) − M̂(G₀) 的均值为零、方差是 V(G₀) − V(G)，与 M 是多少无关。以读到的大小 max(M̂, 0) 为中心（大小不会为负），按 Student t（自由度与读数的区间相同）。
        - 两部分各占多少：一次读数只给出 J(G₀) 一个数。带误差的那部分受本底约束：⟨μ, Cμ⟩ ≤ λ_max(C)·⟨μ, μ⟩ ≤ √(tr C²)·M，即 ζ₁ ≤ M√ζ₂，误差沿着噪声在全程上唯一的模式时取等号。这部分按 1/G 降，本底按 1/G² 降，它占得越多读数的误差降得越慢；取等号就是这个读数允许的最慢的下降：ζ₁ = M√ζ₂，M = max(M̂, 0)，√ζ₂ 由 J(G₀) 解出。读到零或负值的读数全是本底。
        - "在内"的概率：P 对上的区间 t·√J(G) 单独就超过 b 时为零；否则是"变化不超过 b − t·√J(G) − max(M̂, 0)"的概率。各个量里取最小的那个（任何联合概率都不超过它）。
        - 它把现在读到的误差当作噪声本身的大小：11 组上读低或读高了的误差不作修正（Student 的宽尾之外）。成对差的分布尾部重时它偏乐观（下面的实测），这也是只凭期望不够的原因。
        - 检验（`estimate::tests::a_read_on_more_pairs_changes_and_spreads_by_its_two_parts`，合成的两层，11 组读一次、22 组再读一次，4000 次）：只有一个输出时（误差沿噪声唯一的模式，上面取等号）J(22) 与变化的方差都与实测在 4 % 内一致（统计误差之内）（无误差与误差占主要部分两种情形）；8 个独立输出、带误差时它给出的两个方差是实测的 1.3 与 1.2 倍（界的那一侧）。GMD1C 1.4585 µs 的总温度读数（以 b 计）：四个种子 88 对上的标准误差 0.32–0.75，1024 对上 0.14–0.24（均方 0.44）；由 88 对上的平均值推 1024 对，这条规则给 0.15，只按本底的 1/G 给 0.05。
      - 没有再设"加对总共至多花多少"的上限：有把握的节省要求每批至少加约三分之一的对、并且 S 远大于亏的部分，已有的对数超过 N 之后这两条不能同时成立。
    - 两者都没有（已在每条轨迹 2²⁴ 步的最后一档，或读数什么也排除不了）：检查以"看不见"结束，记检查没有排除的上限并标记（§5.1）。
  - 写出与记账用哪个读数（`solve::Levels::told`；方法说明里的分辨率与账目里读清的部分，§2.2）：本档站住所凭的那一个——含 τ 这一层的读数里最细的一对。记一个量在某个输出上的误差 e(τ) = Q(τ) − Q(0)。两层给出的是差，要知道另一层的误差才得到误差：
    - 对 2τ（本档自己的读数）：d₂ = Q(2τ) − Q(τ) = e(2τ) − e(τ)。阶在这两层之间成立（e(2τ) = 2^p e(τ)）时 e(τ) = d₂/(2^p − 1)，即 `between` 读的量。这个数全靠伴随层：d₂ 里有 2^p/(2^p − 1) 是伴随层自己的误差。阶不成立时它对 e(τ) 什么也没说：两层都太粗时可以彼此一致（d₂ 小而 e(τ) 不小）；2τ 不在渐近区时把 e(τ) 读高，倍数没有上限。
    - 对 τ/2（下面一层的读数）：d₁ = Q(τ) − Q(τ/2) = e(τ) − e(τ/2)。差里就是 τ 自己的误差，阶只用来补余项 e(τ/2) = 2^{−p} e(τ)：e(τ) = d₁/(1 − 2^{−p}) = 2^p d₁/(2^p − 1)（p = 2：差的 4/3）。`between` 读的是细层的误差 d₁/(2^p − 1)，所以 τ 的均方是 (τ/2 | τ) 读数的 2^{2p} 倍（`solve::carried`：继承时按阶降低的同一个因子，反过来用）。阶不成立时，只要误差是收敛的（0 ≤ e(τ/2) ≤ e(τ)），就有 e(τ) ≥ d₁：误差降得比阶快时这个数至多偏高到 2^p/(2^p − 1) 倍；只有在 τ 与 τ/2 之间降得比阶慢时才偏低。
    - 三层之间阶都成立时 2^p d₁ = d₂，两个读数是同一个数。不一致时取 (τ/2 | τ)，按"读了哪几层"取，不按读到的值取：
      - 它是本档站住所凭的读数。自己的读数没有读到"在内"；本档站住是因为这个读数换算到本档之后读到了"在内"（`solve::certifies`）。自己读数的分辨率以 τ 与 2τ 之间阶成立为前提，读第三层正是为了检验这个前提。
      - 不取两个读数里较小或较窄的那个：只有阶在三层之间都成立时它们才估计同一个均方；从两个带噪声的读数里挑较小的，记下的"读清的部分"偏低，何况这里自己的读数是因为读得高才走到这一步的。
    - 同一个读数对两层说的不一样多。成对轨迹很早就分开时（§2.2），两层之差的噪声在哪两层之间都一样，而 τ 的误差是 (τ/2 | τ) 之差的 2^p/(2^p − 1)、τ/2 的误差是它的 1/(2^p − 1)：读数对 τ 的分辨率（方均根）比对 τ/2 的差 2^p 倍。成对轨迹不分开时（短的运行），差随步长一起变小，换算之后仍然读得到"在内"。所以起始档凭它站住要它换算之后读到"在内"；那时写出的分辨率也就在份额之内。
    - 实测（2026-11-11；(τ/2 | τ) 在试探的 88 对上的读数换算到 τ，远端以份额的平方 b 为单位，显示的量 | 总温度；要 ≤ 1 才站住）：

### 5.4 表
- 四样东西（§5.1）：当前一级是表；更精确的一级是把一个轴的间距减半，极限是该点的消去本身；比较的输出是整体读数映射到的布居与 T（§2.3）；代价是新节点的消去。
- 建表时就按 §2.3 加密到份额内，份额是最大系综的分辨率，所以表不是任何一次运行的限制，它不参与统计与步长之间的分配。
- 不必在状态上读的单元：耦合单元与相干单元的误差被它自己的门在可达范围上界住（`Gate::error_bound`）。把这些界从小到大累加，只要总和不超过一次求解在显示量上可能记的最小统计份额 2.44e-4（`unseen(MOST_TRAJECTORIES)`），这些单元就按界记账、不在状态上读；其余单元照常在侦察与试探的状态上读。依据：读一个单元的代价与它的大小无关，而账本感受不到比这个份额更小的总和。实测：D1 灰色黏团 2130 个单元里 927 个耦合合计只值 1.7e-11，却占读数时间的 96 %；改后侦察加试探的判断从一次计算的 41 % 降到 5 %（PGC3D 25 % → 6 %），模型、步长、轨迹数、账本前五项都不变。按时间抽稀输出不采用：取相邻两次读数的较大者，在灰色黏团上会把 3.3e-3 的误差少记到 2e-3。
- 试探之后，在试探状态上读整体误差，记入模型误差 A（§4），与单元的实测误差并列。读数超出份额的表（固定在焦点的坐标在动，或加密停在了工作量界上）：先把读数最大的轴减半；到工作量界仍超出，就标记并按读数记账。

## 6 验证参照
- 少而物理上不同，用解析或近似解析解，每个几秒到一两分钟。R0–R9 的公式、条件和场景见 contract.md §6：
  - R0 静止极限对种群核心；
  - R1 保守阱；
  - R2 二能级辐射压与反冲；
  - R3 一维多普勒极限；
  - R4 西西弗斯（含 TW1/TW2）；
  - R5 光泵；
  - R6 拉曼 Λ；
  - R7 共振壳穿越；
  - R8 QRT 扩散（只作表征）；
  - R9 损失与逃逸。
- 通过条件（定义与推导：`refs/check.mjs` 文件头；常数都由 z = 2 得出）：
  - 有用户目标的量（布居、组、损失 0.05；总温度 10 %）：|d| − 2σ ≤ 目标（不放宽），σ² = SE² + u²；2σ 超过目标而又没有失败的输出不判（噪声带比目标宽，分辨不了目标大小的误差）。
  - 自报误差盖住实际偏差，按它报告时的置信度比：|d| ≤ B，B² = E² + (2u)²（布居与损失的 E 是 `sampleErrors`；T 的 E 是 2·SE ⊕ 账本总量 × T）。两个检验：(a) 超出 B 的输出数，在有效独立输出数 n/(1 + 2Σ_k (1 − k/n)κ(ρ_k)) 下的二项检验不拒绝 2Φ(−2) = 4.55 % 的超出率。κ(ρ) 是相关为 ρ 的两个输出各自"双侧超出"这两个事件之间的相关（精确式见文件头；是 ρ 的偶函数，不超过 ρ²：振荡的残差与漂移的残差一样算）。ρ_k 是标准化残差对零（零假设的均值）的自相关，不是对本次运行自己平均值的：整次运行共有的偏移在零假设下是相关时间不短于运行的噪声，是一次抽样；减掉它，剩下的小涨落很快失去相关，这一次偏移造成的越界就被数成许多次独立的越界。(a) 管的是运行之内变化的部分（误差在多次抽样上被低估）；整次运行只是一次或几次抽样的残差，越界多少个输出都只是一个事件，(a) 看不到；(b) 平均偏差不超过平均界 √((模型⊕步长的平均)² + (2·u 的平均)² + (统计区间的平均)²)：所有输出共有的偏差平均不掉，由 (b) 负责（残差为常数时 (a) 的有效数是 1，一次 4.55 % 的事件不算证据）。误差诚实而整次运行只是一次抽样的序列，被 (b) 拒绝的概率至多是每个序列 4.55 %（账本与参照的 u 进了界就更小），这是诚实误差该有的失败率，也是单次运行能分辨的上限：这样的序列误差被低估 f 倍，单次运行只以 2Φ(−2/f) 的概率看得出。
  - 没有用户目标的量（阱频、平均位置与速度、单轴 T——引擎不对单轴 T 作任何保证）：只对参照自己的 u 与结果的统计误差，用同样两个检验；单个确定量（阱频）即 |d| ≤ 2u。没有借来的目标，也没有零目标。
  - R4 标度律 T(4I) − 3T(2I) + 2T(I) = 0 只检验稳态 T 对光强是带正斜率的仿射函数（|D| ≤ 2√(SE² + u²)，且 T(4I) − T(I) 分辨得出），不检验斜率、截距与 T 本身。点粒子模型在这些场景里 T 偏低（Ehrenfest 平均力丢掉一阶的无迹部分），由工具参照 R4D_TW2 报告（只报告）；同一分解下系综平均力是精确的，由 R4D_FORCE 判定（`refs/r4d.mjs`）。
- 旧真值表只作回归。锚点：RETRO、F5、R5051、R5031、SHALLOW、F10、CONTROL、R5038；布居与损失另有 R5033、R5066、R5040、R5004。k_BT < 4ħω 的 T 不作物理参照。

## 8 已知限制（照实写给用户）
- **点粒子（Ehrenfest）假设：亚多普勒冷却的温度偏低。这是模型自身的缺陷，不是数值误差，不进误差预算（用户 2026-11-11 定）。**
  - 是什么：一条轨迹是一个点（r, κ）带一个内态 ψ，质心按当前内态上的平均力 ⟨F̂⟩ 运动。精确的半经典理论里内态的各分量各受各的力，在动量上彼此分开，再经光泵与飞行反过来影响受力；点粒子带不了这个关联（缺的一项是 ½(|χ⟩⟨ψ| + |ψ⟩⟨χ|)，χ = (F̂ − ⟨F̂⟩)ψ）。平均力不受影响——摩擦是精确的（参考 R4D_FORCE）；受影响的是力的慢关联，也就是温度。
  - 何时为零：跳跃后的态是力的本征态时（多普勒冷却、反冲、驻波中的闭合跃迁：R2、R3、R10）。偏振梯度里基态带相干的冷却（F = 2 → 3 的 lin⊥lin、σ⁺σ⁻、灰色黏团）都有。
  - 多大（实测，同一模型的全量子参考对真实引擎）：
    - 光镊紧束缚轴上的 lin⊥lin，一维：−2 %（100 µs）、−9 %（500 µs）、−15 %（1 ms）（参考 R4D_TW2）；R4_LIN 场景一维 −18 % 至 −27 %。
    - 一维自由空间，−6Γ：lin⊥lin 每束 3–12 mW/cm² 时低 11–21 %，48 mW/cm² 时只有真值的 0.44；σ⁺σ⁻ 在 6–12 mW/cm² 时只有真值的 1/4 到 1/3，48 mW/cm² 时 0.42；3 mW/cm² 时真值是两群原子（核心 10.8 µK，一成很热），引擎的核心是 2.5 µK。σ⁺σ⁻ 的差距里混着半经典理论自身收敛慢的部分，没有分开。
    - 三维六束光：没有可用的量子参考，偏差未知；只能由实验数据判定。
  - 为什么不修：点粒子轨迹带不了这项关联；带上一阶矩的闭合（M、M+N）线性不稳定；既精确又为正的做法是在紧束缚轴上给每条轨迹一个波函数（一维代价 ×7.5，三维每量子化一个轴再 ×64–128），超出这个引擎的定位。推导与数值在 `motion3d_status/rewrite/diffusion.status.md`、`mscheme.status.md`。
  - 三维光镊里两个简并的紧束缚轴经阱的非谐势交换能量是模型内真实的物理（引擎与经典二维运动一致），拿三维结果去比一维参考不是有效的检验。
  - 经典区 k_BT_a ≥ 4ħω_a 只作报告，不参与任何决定；同一模型的精确半经典解在 4ħω 处与全量子只差 1.4 %，阱的量子化不是这里的主要限制。
- 傍轴近似，不含纵向场；所有光束共焦于原点。
- 同频光束相干，相位取请求的值。
- 原子冷到被局域在近共振光的晶格格点里时，经典区判据只反映光镊尺度的量子化，不反映格点的。

## 9 接口契约（详见 contract.md）
- 请求：native JSONL 一行（options、model、motion 块）。只收有限轨迹请求；`device` 照收，一律在 CPU 上算，结果报 `device:"cpu"`，并附 deviceNote"GPU 计算尚未提供：本次在 CPU 上计算"。
- 请求的字段：
  - motion 块的每个字段都必需（契约的 `MotionModel`）。引擎不读的字段只检查存在、不解析内容：`fieldVectorG`、每束光的 `intensityMWcm2` 与 `outsideShift`（它们已经在 H0、耦合与外层形式里）；
  - 初始密度矩阵 `initialReal`/`initialImag` 必需，不读 `initialIndex`；
  - 模型基里基态排在最前：第 s 个态是基态，当且仅当 s < 8。请求校验一次，此后一律按下标。
- 拒绝（返回错误，界面显示"运动计算失败：…"）。contract.md §2.4 列出的之外，引擎还拒绝下面四种；消息是中文，界面原样显示：
  - 初态在激发态上有布居（超出密度矩阵自身的舍入 γ₃₂）：初始系综是各基态分量在自己的准备阱里的原子（§2.5），激发态的运动没有准备阱可言；
  - 阱光（与光镊同频的全部光束，§1.3）里有平面波：平面波的势在远处不降为零，被俘获原子的初始系综无从定义；
  - 阱光对某个初态分量的势的包络界不为正：这个分量没有被俘获的原子（"光镊不约束原子"）。
  - 每条轨迹至多 2²⁴ 步之内没有可用的步长（§2.2 起始档）。
- native 没有 `gpu` 操作：界面启动时不为 GPU 做任何事。
- 结果：
  - 键集合固定；第 0 行等于初态；`requestedTolerance` = 0.05；`estimatedMaximumError` = max(`sampleErrors`)；
  - 部分结果不扣留；每批一个检查点，第一个在试探之后。
- 公开面：`Request`、`solve(&Request, &mut checkpoint) -> Result<Solution, String>`、`Solution`、账本类型、`POPULATION_TARGET`。

| `model` | 各频率的常数形式（按裸能级的折叠）、势 V_L、阱心与解析 Hessian、reach；单元、驱动的三级、存在门（一条规则）、簇、帧、按原子处能级的消去（RS、缀饰、一阶多普勒）、唯一的生成元组装（H、G、跳跃算符）、消去的表（坐标、轴、加密、整体读数）、读出、危险率、光子、吸收的光每单位时间给动量的两个矩 |
| `table` | 每轴三次表（通用插值、轴的误差读、间距减半） |
| `spectral` | 步中点生成元的相互作用绘景：本征分解、快对的跟随、慢对的两跳、步内任意时刻的态；病态处的 CF4 |
| `step` | 一步（A、B、参考、冲量）、内态传播的求积、步内路径、跳跃根与跳跃 |
| `adapt` | 常数步长的推进（步、步内读数、跳跃时刻、布朗路径） |
| `ensemble` | 初始系综 |
| `estimate` | 输出、估计量、jackknife、Student t、Wilson；步长误差：两层系综的成对差（`between`） |
| `decide` | 读、三种结果、pays、工作量计数 |
| `ledger` | 账本 |
| `solve` | 流水线：请求 → 范围与模型 → 试探（两层） → 决策 → 两层的批次（停、续、减半步长） → 检查点 → 结果 |
