# atom-motion：3D 半经典运动求解器（CPU 版）规格

本文件是新求解器的唯一规格。代码里的每个量、每个决策都要能对应到这里的一条；对应不上的，要么删，要么先改本文件。
推导和证据在提炼稿里（`C:\Users\eadri\WorkCode\motion3d_status\rewrite\`：field、internal、propagation、decisions、contract），本文件只写结论和规则。

## 0 范围与原则

- 取代 `atom-motion-3d`（冻结于 62d4d206，只读参考，不再修改）。与界面的契约不变（§9）。只做 CPU；GPU 等 CPU 版完整、正确、优化之后再议。
- 硬约束：没有特判，没有 magic number，没有多套实现，没有冗余。
- 每个量只有一个定义（下文标出定义处）；每类决策只有一条规则（§5）；决策只有三种结果：在内、细化、标记。
- 允许的常数只有这几类，每个写明来源：
  - 用户的目标：布居与损失 0.05（绝对），T 0.10（相对）。只描述被俘获原子的量（T、模型误差）按持有份额 1 − L 计权，损失按自身：这是用户对目标的定义，不是推导；
  - 格式的阶 p = 2（对称分裂）；统计置信度 z = 2；
  - 物理常数；浮点格式（ε）；
  - 由以上推导出的值（写出推导）；
  - 经典区边界 k_BT ≥ 4ħω：方法的验证范围，与界面镜像（文字、灰带）。它只用于报告，不参与求解的任何决定（T 的目标在总温度上，§3）。
  - 契约定义的量：区域的光强判据 1/20（界面文字里的损失定义，REGION_INTENSITY）；资源上限：轨迹 2¹⁴；步长的下限是时长/2²⁴（到了照常返回并标记）；时长上限 10 s、输出点数上限 2000；直方图的 21 个时刻；检查点间隔 60 s（界面 120 s 规则的一半）。
  - 已发表算法自带的常数（Philox 的乘子与轮数、QR 迭代的例外位移）。
  - 结构量：拉丁超立方的组大小 8（§2.5），它也是 jackknife 每次删去的块。组内每条轨迹的分布与独立抽样相同，各组相互独立，所以组大小取多少，估计所用的各个均值的期望都是系综的，jackknife 的方差都是各组均值的方差。在同样的轨迹数下，组大小只是拿每个变量的分层数（等于组内条数）和每个输出保存的和（每组一份）去换读离散用的组数（Student 的自由度是组数减一）。
- 单位：长度 µm，时间 µs，能量与频率 rad/µs，κ = p/ħ（1/µm），温度 µK，场 V/m，波数 rad/µm。

## 1 物理模型

### 1.1 原子
- 32 态：8 个基态（5S½ F=1、2），D1 8 个、D2 16 个激发态。H0 由请求给出，必须在模型基里对角。
- 发射算符 C_a（a = x, y, z，基 ← 激发），D = Σ_a C_a†C_a。

### 1.2 光场（定义：`field`）
- 光束振幅 a_l(r)：焦点在原点的傍轴高斯光束（含 Gouy 相位与波前曲率），或平面波；∇a_l 解析。
- 每束光的焦点场 E_l（球分量 q = −1, 0, +1，含偏振与初相）由请求给出，**必需**。
- 每个频率一个相干场：E_ω(r) = Σ_{l∈ω} a_l(r) E_l；耦合对场线性：V_ω(r) = Σ_q E_{ω,q}(r) D_q。同频光束彼此相干，相位取请求的值（前提：相对相位的漂移比原子动力学慢得多）。
- 相干矩阵 T_ω = E_ω E_ω†（每个频率至多 9 个实数坐标 x_{ω,i}）。
- 光不分“远光”与“近光”。每个频率的光有同旋、反旋两个分量；一个分量把一个基态 g 耦合到一个激发态 e 的那个矩阵元叫一个**驱动**。每个驱动各自取三级之一（§1.4），由它自己的分母决定（§1.5、§5.2）：不看频率，不看谱线（D1/D2），不看是哪束光，也不看是不是阱光。
- 按裸能级折叠的驱动：响应取在裸能级上，R = (K₀ − E_b − ν)⁻¹V，K₀ = H0_ee − (i/2)D，分母里没有光，所以 R 对场线性、各项是常数，在原子处精确计算，不进表。
  它与 §1.4 的折叠是同一个二阶消去，只是响应取的能级不同：基态块就是 §1.4 的那个缩并 −½(V′†R + R′†V)，散射是同一个响应的跳跃算符 C_a R（散射不丢）；激发态块是经基态的 van Vleck 式（基态不衰减，实分母）。
  激发态块的分母取在“读它的态”的能量上：消去折叠驱动 U（e ← b，频率 ν）的基态 b，激发态得到自能 |U|²/(z − E_b − ν)，z 是读它的那个态的能量。自己也被折叠的激发态在自己的能量上读（z = E_e，分母是单光子距离 β = E_e − E_b − ν）；被另一个保留驱动 V（e ← a，频率 ν_V，失谐 ε）变成显式的激发态由它所在的簇读：它的振幅跟着簇的基态转，z = E_a + ν_V，分母是拉曼对 (a, b) 的双光子距离 d_R = E_a + ν_V − E_b − ν = β − ε（簇有几个基态时取它们在簇的帧里的平均，`Model::read`；按原子处能级折叠的驱动同样，取原子处的能级）。不用单光子的实分母 1/β（β = 0 处有极点而那里什么都不共振），也不用单光子的复分母 1/(β − iΓ/2)（那是寿命 1/Γ 的瞬态的读法）。三能级精确对照（V = 0.5Γ，ε = Γ，U = 0.2Γ）：保留谱线的速率用 1/β 在 β = 0.5/0.1/0.02 Γ 处低 14/38/82 %，用复分母低 16–18 %，用 1/d_R 在 0.1–3.8 % 内（拉曼对自己的下一阶）。1/d_R 的极点是拉曼共振，那里这个折叠不存在，由拉曼对的门拒绝（§1.5）。|β| ≫ |ε| 时两个距离相同。
  基态块含线宽：失谐 Δ 的一条线上它是色散型的 −|V|²Δ/(Δ² + Γ²/4)，比实分母的 −|V|²/Δ 小 (Γ/2Δ)²（失谐几十 THz：约 1e-14；20 GHz：约 2e-8）。光移与散射出自同一个响应。
- 常数形式：两个频率 ω′、ω 的场在拍频 δ_ω′ − δ_ω 上给出同一种形式 Σ e′_k′* e_k C_k′k，由三项组成：外层形式的交叉项（取两个频率外层形式的平均）、同旋的二阶项（发射 ω′、吸收 ω）、反旋的二阶项（发射 ω、吸收 ω′）。
  - ω′ = ω（拍频为零）就是该频率的静态形式：Σ_i x_{ω,i}(r) O_{ω,i}（请求给出的外层形式）+ 它按裸能级折叠的驱动的二阶移。
  - 它的每个矩阵元 a ← b 是一个耦合单元（§5.2），不静默丢弃：在簇的帧里残余拍频恰为零，或该单元被保留，它才进入生成元；否则折叠，误差记账。
- 同旋与反旋的交叉项以两倍光频拍动，不在模型里（请求的外层形式里也没有这一项）；两个折叠都存在时它的混入是两者之积，四阶。反旋驱动只按裸能级折叠：这是模型的适用范围，它的折叠不存在（同一个门，每束光取峰值）的请求被拒绝。
- 坐标图：每个频率的场用有界坐标（光强 I ∈ [0,1]，偏振超球角，相对相位）；表只用于近光消去的非线性部分（§2.3）。

### 1.3 势（定义：`model::potential`，全程只此一个）
V_L(r; p) = Σ_b p_b [h_L(r) − h_{L∖阱光}(r)]_bb
- h = 消去后生成元的静态厄米部分（与动力学用的是同一个）；p = 基态布居（只在基态上归一）；L = 当时开着的光；阱光 = 光镊所在频率的整个场。
- 派生量全部由它给出：
  - 损失能量 E_s = ħ²κ²/2m + V_run(r; p(ψ))。p(ψ) 是 ψ 衰变回基态之后的基态布居：p_b = (|ψ_b|² + Σ_e β_{b←e}|ψ_e|²)/‖ψ‖²，e 取簇里的显式激发态，β_{b←e} = Σ_a|C_a[b,e]|²/D_ee 是它的分支比。显式激发态只存在 1/Γ，远短于任何运动的时间，原子之后感受的是它落到的基态的势。这个定义对布居线性、和为 1，对任何 ψ ≠ 0 都有值：没有显式激发布居时就是 ψ 的基态布居；全部在显式激发态上时（没有基态布居）是它将落到的基态的布居；
  - 准备势 V_prep(r; ref)（t = 0 之前只开阱光）；
  - 阱心 = V_prep 从焦点下降到的局部极小；不存在极小 → 拒绝（"光镊不约束原子"），不退回焦点；
  - 阱频与主轴：准备阱（V_prep 在其极小处的 Hessian）给初始系综的 Wigner 因子；运行阱给报告的 `trapFrequencyKHz`、n̄、经典区判据与 T 的窗口周期——它们描述把原子困住的阱：阱光的势（保留阱光自身的干涉，所以反射光镊按格点报），加上其他光的平滑光移（每束光只取自身光强，光束之间的相位全部平均，所以没有波长尺度的条纹；近共振光的条纹属于冷却动力学，不是阱），参考态，在其极小处的 Hessian。其他光的平滑光移就是它的驱动按原子处能级折叠时的光移，只要这个折叠在阱心处存在（同一个门，取在准备阱的阱心、原子静止；把这些驱动都放到原子处，同一基态的驱动按尾和规则，门不成立的驱动改为显式，直到都成立；两个基态之间的耦合照模型已保留的那些，它们决定读光移的簇），就按它读，不论动力学把该驱动放在哪一级：这种光移在阱内的变化全部来自阱光对它的谱线的移动，按裸能级折叠的驱动只有常数、不含这一项（它是那个级数的首项，误差在动力学里记账），显式保留的驱动在模型里是簇内的动力学；报告量属于场景，不能随求解把哪个驱动留在哪一级而变。在阱心处折叠不存在的驱动（例如在阱心共振的推出光）没有光移可言，仍是动力学，不进这个势。经典区判据 k_BT ≥ 4ħω 正是在光镊加冷却光的一维量子参照上、以这个 ω 验证的；V_run 没有极小时（运行的势不束缚原子），这些量按准备阱报告并标记“运行中的势没有极小”；
  - 区域：每束聚焦光在原子处的强度都低于焦点处的 1/20 即为区域外（与界面文字一致）。

### 1.4 内态生成元（定义：`model`）
- 簇：被保留的耦合连通的态集合（基态加显式激发态）。哪些耦合保留由 §5.2 决定。
- 一个驱动的三级。每一级是前一级更精确的一级；一个驱动恰好取一级，即它被保留的单元给出的最高一级；簇内两态之间残余拍频恰为零的驱动不需要单元就是显式的：
  - 按裸能级折叠（§1.2）：常数；
  - 按原子处的能级折叠（下面的缀饰消去，进表）；
  - 显式：V 直接进入生成元。
  “载波”是有驱动不取裸能级的同旋分量：由各驱动的级推出，不列出。
- 按原子处能级的折叠（二阶 Reiter–Sørensen，按构造是 Lindblad 形式）：
  R_c = (K + Σ_b(z) − z)⁻¹ V_c^a，K = H_ee − (i/2)D，z = E_b + δ_c + 缀饰移；V_c^a 是载波 c 取这一级的那些驱动。
  自能 Σ_b(z) 是激发态通往别的基态的通道：通往簇外基态、按原子处能级折叠的通道，以及保留（显式）驱动的通道——后者只要与 b 这条通道不是同一个 Floquet 态（a 在别的簇，或在同一簇的帧里两者的残余拍频不恰为零）。被保留驱动 V 缀饰的显式激发态因此在 b 的响应里是 U/(β̃ − |V|²/d_R)，不是未缀饰的 U/β̃（后者的光移差 |V|²/(β d_R)、速率差两倍；三能级 V = 2Γ、β = 27.4Γ、共振：−0.53 % 与 −1.06 %，带上这一项 1.6e-4）。
  有效项 X_ab = −½(V′^f†R + R′†V^f)：两个频率各出一条腿，耦合 V^f 取该频率全部折叠驱动（裸的也在内），响应 R 取原子处的。折叠项对耦合与响应是双线性的，所以裸折叠的常数（§1.2：同一个 V^f 配裸响应）加上这一项就是全部，没有“混合对”的特例。衰减是跳跃自己的乘积 −(i/2)Σ J†J，J = C_a R；读出度规 Y = Σ R′†R。
- 折叠的下一阶（四阶，按需，§5.2）：簇里只有基态、按原子处能级折叠的驱动同属一个频率时，该簇的折叠可以取到四阶。
  - 无跳生成元的慢不变子空间 Ψ = (x, Wx)，W = −R + W3，W3 = −R2 N；在正交坐标 y = (1 + X)^{1/2} x 下，用二阶自己在簇上的三个矩阵——N = −V†R（厄米部分是光移 S，反厄米部分是模型的衰减 −½ΣJ†J）、Y = V†R2（多普勒伙伴 D 的两倍）、X = R†R（读出度规）：
    H⁽⁴⁾ = Herm[−Y N + ½[X, N]]，跳跃 L̃_a = J_a(1 − ½X) + J2_a N，衰减仍是跳跃自己的乘积 −(i/2)ΣL̃†L̃。
  - 三个矩阵在该点各算一次（连同梯度；同一线程上一步的中点与它的散射共用这一次）：S、D 之外，这样的簇里每个光束对的形式还带度规 X 与损耗 L = T′†D T，与 S 一样进表。由它们：
    - 中点的 H⁽⁴⁾ 及其梯度是 n × n 矩阵的几次乘积；衰减的改变量 Σ L̃†L̃ − Σ J†J 由生成元自己在该点的衰减（按多普勒标志分开读出）与 B = 1 − ½X、N 算出。按标志读出的每一个都是生成元自己各项的反厄米部分：Λ = i(P − P†)（不带多普勒的项之和 P）；带一阶多普勒时响应是 R − wR2、跳跃是 J − wJ2，“吸收分量取多普勒移”的各项之和 G_R = ½V^f†R2 + (i/2)ΣJ†J2，“发射分量取”的各项之和 G_L = ½R2†V^f + (i/2)ΣJ2†J，厄米耦合的多普勒伙伴 ½V^f†R2 在两者里都有，所以 Λ_R = ΣJ†J2 = −i(G_R − G_L†)，不论 V^f 里有哪些频率的腿。（不能用 G_R 减去本频率自己的 Y：簇里保留了两个频率的静态耦合对时，V^f 含另一个频率按裸能级折叠的那条腿而 Y 不含，它的厄米多普勒伙伴会被读成衰减——R6_RAMAN_CO 保留拉曼对并取四阶时，生成元的衰减与光子速率相差 ±6e-3，符号随哪条腿在原子处而变；改后 1e-12–2e-11，与没有这种对时相同。）两者在步内与该点的形式一样取在中点（在簇的多普勒参考系里）：节点上加 n² 个数，力每个轴加 n² 个数。力仍是生成元厄米部分的梯度。
    - 光子：跳跃的矩阵作用在 (1 − ½X)ψ 上，伙伴的矩阵再作用在 Nψ 上；簇的每一个跳跃（裸折叠的、远光的也在内）都作用在弯过的态上，因为基态振幅就是 (1 − ½X) y。
    - 跳到一个四阶簇的裸基态 f 之后（`Model::landed`）：慢态是 Π f，Π = 1 + ½X − Y，轨迹带着它的范数继续，不归一。裸态 = 慢态 + 在 1/Γ 内消失的快部分；此后 ‖ψ(t)‖² → ‖Π f‖² e^{−γt}，所以 ‖Π f‖²/‖f‖² = 1 − p 是裸态的存活概率外推回跳跃时刻的值。一条线上 p = 2Re Y − X = (s/2)(Δ² − 3Γ²/4)/(Δ² + Γ²/4)，两种符号都有：远离谱线 p > 0（s/2）——快部分立刻再发一个光子；|Δ| < 0.866Γ 时 p < 0（共振处 −3s/2）——发完光子原子在基态，激发振幅要 1/Γ 才建立起来，下一个光子来得晚（反聚束）。两种情形是同一句话：范数与下一次跳跃的阈值 θ 比（`step` 的 `jump`），等待时间的分布是 P(T > t) = min(1, (1 − p)e^{−γt})。范数高于阈值就等：等于 1 时与二阶一样（二阶的运行不变）；低于 1 时按阈值分布剩下的部分等；高于 1 时多等衰减到 1 所需的 ln(1 − p)/γ。范数已经不高于阈值（只有范数低于 1 时才会，概率 p）就由裸态立刻再发一个光子（类、偏振、方向、反冲与有界的踢都与任何光子一样），重抽阈值，再落一次。没有按符号的分支，也不把 p 钳在 0（钳位时 p < 0 被丢掉，共振处速率高 1.52 s，比二阶的 +s 还差，而记账的是 s²）。平均间隔：p ≥ 0 时 (1 − p)/γ，p < 0 时 (1 + ln(1 − p))/γ，两者都与精确值差 s² 量级（二能级对精确稳态速率 1/(1+s)：共振处 +1.07 s²，远失谐 −0.99 s²，任何失谐下不超过 9/8 s²）。与精确消去的谱投影对照，p 差 0.6 s²。
  - W3 每列只用一个分母：簇内基态能级之差远小于驱动的距离时精确，其余记在该级的误差里（§1.5）。
  - 不含：按裸能级折叠的驱动的四阶、四阶项的一阶多普勒（都是再下一阶；后者使危险率与光子速率相差 (w/Δ)·s 量级，静止时 7e-7）；在簇的帧里拍动的项保持二阶。势里有 H⁽⁴⁾ 的对角（值与梯度：损失能量 E_s 读的就是它）；它的二阶导数不做，问到二阶的势（阱心、Hessian、阱频、步的参考）整个取二阶折叠的，连值也是（`model::potential`）。
  - 有显式激发态的簇、两个频率都有原子处折叠的簇没有这一级（那里的下一阶含显式耦合、含拍频，这个展开不是它的）：它们的下一级仍是显式。
  - 推导、与精确消去的对照数字：`motion3d_status/rewrite/fourth.status.md`。
- 缀饰：其他载波 d 移动基态能量 ΔE_b^d = −Re tr(T_d M_b^d)（T_d 的线性函数）。消去里用对载波内各偏振单元相对相位平均后的 T̄_d；单元间干涉的误差在原子处实测（§5.2）。这个平均也进入载波自己的折叠通道（通往簇外基态的自能，以及那些基态的缀饰能量），所以缀饰单元的误差同样量该载波自己的响应。
  载波所在频率的静态形式（它按裸能级折叠的驱动的移、外层形式）进入这些分母时也取同一个 T̄（只留同一偏振单元内的光束对）：一个载波的光对分母做的一切是同一个缀饰，它的条纹是缀饰单元的误差。近共振晶格光里按裸能级折叠的线因此不把波长尺度的条纹带进表的坐标（§2.3）。
  只要模型里有按原子处能级折叠的驱动（有消去），偏振单元多于一个的载波的缀饰单元就列出。
- 一阶多普勒（只对折叠部分）：响应在 w = k·v 处的一阶 R − wR2；误差 (w/σ)²（σ 为到最近激发极点的距离）沿轨迹实测。超出它的份额，就把该驱动保留为显式（§5.2）。不钳位，不半切换。
- 帧：簇内各态的帧取能量与载波失谐的整数组合（精确）；多普勒参考系 K_s 在簇内每对态只有一个波矢差、且沿每个回路相加为零时精确，生成元在步内为常数；回路不闭合时，K_s 取使各矩阵元的平面波残余波矢平方和最小的那一组（每个平面波计一次，图 Laplace 方程 L K = b，`model::cluster`），其余的路径相位作为拍。任何 K_s 都是精确的变量替换：它只决定步的节点要分辨多少（§2.2），不改变模型。
- 力算符 G = ∇H_h 与生成元在同一次组装中得到：**唯一的组装函数**，动力学、力、读出、危险率、势都用它。

  - 有表时：步里用的衰减矩阵是表里另存的乘积 Σ J†J 的插值（每步省一万多次复数乘法，单步里原先最贵的一项）；跳跃仍用 J 的插值。两者差一个插值误差——"先插值再乘"对"先乘再插值"——实测对衰减率是 3e-5 量级（PGC3D、R2、R3），远在表的份额（7.8e-3 / 2.2e-2）之内，并且已经含在表的误差读数里记账。无表（逐点精确消去）时两者严格相等。

### 1.5 消去的存在与误差（推导见 internal.md 1B）
- 一条规则，对每一种单元都是同一句话：把大小为 size 的耦合跨过距离 distance 折叠，m = size/distance。
  - 静态：S = 2m² < ½ 时折叠存在（Stewart 1973：m < ½ 时不变子空间存在）。
  - 运动：a = rate/distance² < ½，rate = |dΔE/dt| = v·∇ΔE + q·v̇（q 是该项的波矢，v̇ 取原子所在簇里力的界）。这是与静态边界同一相对误差（约 0.7）的门，不是存在性定理。
  - 两个条件互不蕴含，都要满足；不满足就必须保留（数学门，不是取舍）。½ 是唯一的阈值。
  - 每种单元只提供三样东西：自己的 size、可达范围（§1.8）上自己最小的 distance、rate。三者都是可证的界：同一频率内的光束按请求的相位相干叠加（就是原子在该点真实感受到的耦合）；界 = 格子中心的真实值加它在格子内能移动的量，逐边算到二阶（平面波只沿自己的波矢转相位，条纹只沿两束光的波矢差变化，聚焦光的包络垂直于光束按束腰、沿光束按瑞利长度变化；不用“格子半径乘一个 Lipschitz 常数”），逐格细分到判定为止；每个证明把格子沿“单独这条边就把它的界抬得最高”的那条边对分（驻波的条纹因此用薄片分辨，不用条纹尺度的立方体填满整个阱）；不用光图样的平均值，不用采样最大值。先在全空间上算一次界（每束光取峰值）：两个数在那里都低于 ½ 的单元就此判定，其余的才在可达范围的格子上证明。
- 驱动：size = |Σ_l a_l X_l[e,g]|。它的失谐在一个格子上是中心值 Δ_c 加减 moved：两个能级在格子内的移动余量、消去所取的能级与能级本身之差（§1.4：载波自身偏振单元之间的干涉在分母里被平均掉的那些光束对）、别的载波的缀饰、多普勒移 k·v、激发态之间耦合的 Gershgorin 半径、自能的界。rate = v·L + k·a_max。
  - 按原子处能级折叠：distance = |max(|Δ_c| − moved, 0) − iΓ/2|，即它的实际分母。
  - 按裸能级折叠：裸响应 V/(Δ₀ − iΓ/2) 是按 ε = δΔ/(Δ₀ − iΓ/2) 展开的级数的首项，δΔ 是它的两个能级在原子处被别的光移动的量加多普勒移与反冲。裸能级是围绕 H0 的微扰论：它跨过裸距离 |Δ₀ − iΓ/2| 折叠掉的，是两态之间 H0 没有的一切，即耦合与能级的移动。所以它自己的门取 size = |V| + |δΔ|（能级往哪边移都算）、distance = 裸距离。门内折叠存在（|V| 对剩下的距离 |Δ₀ − iΓ/2| − |δΔ|），级数收敛且 |ε| < ½；门内它的误差是级数的一阶，在原子处实测。
- 折叠到显式激发态上的驱动是拉曼对的一条腿（两级都一样）：驱动 U（e ← g）与 e 的每个保留驱动 V_a（e ← a）构成一对，除了自己的门还有这一对的门——同一个门，size = |U||V_a| 除以两个单光子距离中较近的一个（两态之一含另一态的振幅就是它除以双光子距离），distance = 双光子距离 |E_g + ν − E_a − ν_a| 在格子上的界，减去两个光子的多普勒移、两个基态被按原子处能级折叠的驱动移动的量、被保留驱动移动的量（耦合 v、距离 d 的保留驱动至多移动 min(v, v²/d)），rate = v|∇(E_g − E_a)| + (k + k_a)·a_max。各对的份额加进该驱动在尾和里的份额；不成立就保留这个驱动，与别的驱动一样。按裸能级折叠时，e 被保留驱动移动的量（自能 |V_a|²/d_R）另外进入它的 δΔ：门里取界，误差里实测。
- 尾和规则：同一个基态的各个折叠驱动分享它的布居，一组折叠存在的条件是它们的份额 2m² 之和 < ½，每个份额按该驱动的实际距离算，不论它取哪一级。
  - 一个驱动的门值 = 该基态的折叠驱动中份额不大于它的那些之和。于是最强的先不成立、先被保留；份额相等的一起；远处的线不会因为近处的线而被保留。
  - 按裸能级折叠的驱动，把它自己那一项换成它自己的门值：裸折叠存不存在是它自己的事，不连累别的驱动。
  - 次序是每个基态一个固定的次序：每束光取峰值、裸能级下的份额，从大到小。若在每个格子上各自排序，和对格子不单调，可证的界做不出来；谁先被保留只是代价的选择，每个门都是对一个固定集合的陈述。
  - 两个份额之差在各自算术的舍入之内，就算同一位（由对称性相等的驱动只在末位上不同），否则对称的一组会被噪声拆开；同一位、同一级的驱动取其中最大的扫过。
  - 一个格子上、一个点上，和里的每一项都是这个格子、这个点自己的份额：点上的门值就是那里的值。不拿别处的界顶替较弱的位——那不是任何一点的值（实测：两个相等的驱动，一个取全空间的界 0.49，另一个的门在阱心被读成“达到 0.52”，而那里两者各只有 0.03；失谐 20 个线宽的光因此被改成显式）。
- 折叠的驱动对它的能级做的事，按它自己的门来界：耦合 v 跨过距离 d 折叠，基态能级至多移动 v²/d = m·v（折叠存在处小于 v/2）。按原子处能级折叠的各驱动对一个基态能级的移动，逐个驱动取它自己的门在该处读到的距离；这个移动的斜率取其中最近一个的 1/d 作响应的范数。不用共振驱动的距离 Γ/2：那个界是失谐 Δ 的光的真实光移的 2|Δ|/Γ 倍，随光强增长，80 mW/cm²、失谐 20 个线宽时就超过了冷却光子与回泵光子之间的 137 MHz，耦合的距离读成零、门读成 ∞，F=1 与 F=2 被并成一簇。
- 两个态之间的耦合：一个精确拍频 β 上 a ← b 的全部二阶项是一个单元——常数形式的矩阵元（§1.2；β = 0 时连同所有光都关时两态自己的耦合），加上按原子处能级折叠的那一部分。
  - size = 这个矩阵元的界；distance = |β + E_a − E_b| 在格子上的界，减去它的光束对最大波矢的多普勒移和两态各自被按原子处能级折叠的驱动移动的量（上一条的界）；rate = v|∇(E_a − E_b)| + q·a_max（同一个态的拍动，两项都不随它动）。
  - 不超过所在形式求和舍入的矩阵元不是耦合（场的零分量以它所在矢量的末位出现）。
- 两源光子相干：size 是两类光子的跳跃算符大小之积 Σ_a ‖L_a‖‖L′_a‖ 在区域上的界——每个成员的场分量取相干的界，载波在原子处的那部分逐个驱动除以它自己分母的界（与两个态的耦合用同一个界），常数部分照原样；distance = 两个频率之差减去能级移动的界与两个光子的多普勒移；同一个门。沿轨迹实测时 size 取该点的跳跃算符本身。
- 缀饰单元（§1.4 的 T̄）不是消去：它是别的分母里偏振单元之间干涉的平均，自己没有能量分母，所以没有存在门，只有实测误差。
- 首项误差（供 §5.2 映射到输出）：
  - 驱动的折叠（两级相同）：布居 s p_g，T (s + a) p_g，s = 2|R[e,g]|² 是它自己的份额；按原子处能级折叠的另加一阶多普勒的下一阶 (w/σ)²；
    - 二阶缺的只有一项，四阶光移：势深了 s/2，力大了 s，散射率大了 s（一条线上精确：力 ×(1 − s + 3/2 s²)，速率 ×1/(1 + s)）。T 跟着势的调制走：Sisyphus 图样上扩散 +0.6 s、摩擦 −0.2 s，合起来 0.8–0.9 s（实测 +8.8 ± 1.5 %，s = 0.12），是同一项的两个后果，不是两个要相加的误差；力的 s 是它的界，按它记账。原来的 √2 s 是真值的 1.8 倍。
    - 四阶（§1.4）：力 3/2 s²；簇内基态能级之差/驱动的距离 × s（W3 的一个分母）；速率 9/8 s²（连同落点的范数对阈值，§1.4；对二能级原子实测，s = 0.03、0.06、0.12：二阶 +s；四阶的跳跃单独在远失谐处 −s/2、共振处 +3s/2；加上落点，远失谐 −0.99 s²，共振处 +1.07 s²——范数 1 + 3s/2 对阈值多等 ln(1 + 3s/2)/γ，而精确的平均间隔多 (3s/2)/γ，相差 (3s/2)²/2 = 9/8 s²，这是各失谐下最大的）。与精确消去对照（冻结原子，⁸⁷Rb 的 F′ = 1, 2, 3，s = 0.03 / 0.06 / 0.12）：势 s/2 → 0.5 s²，力 0.7 s → 0.9 s²，慢态衰减率 1.5 s → 1.9 s²。
    - 上面的 s 是一条线的。同一基态、同一载波的几个驱动是一个折叠，不是几个：记 D_e 为驱动的分母、a_k = Σ_e |V_e|²/D_e^k，慢本征值是 λ = −a₁(1 − a₂ + a₂² + a₁a₃ − …)，四阶留下的每一项（λ 的、跳跃速率的、落点范数的）都是两个数的乘积，这两个数只有两种：该基态的激发份额（a₂、X），至多 S_b/2 = Σ_e |R[e,b]|²；该能级自己的二阶项除以驱动的距离 a₁/D_e（响应的分母被折叠本身移动），模为 L_e/2 = |N_bb|/|D_e|，N_bb = Σ_e V*R。各驱动在同一距离时两者都是 S_b/2：激发态合成一个亮态，就是份额 S_b = Σ_e s_e 的二能级原子（速率精确为二阶的 1/(1 + S_b)），余项是 c·S_b²，不是 c·Σ_e s_e²。距离不同时近线读到远线的光移，L_e ≤ Σ_f s_f |D_f/D_e|，不受份额约束。所以四阶时驱动的这条线差 c·max(S_b, L_e)²（c 即上面一条线的 3/2 与 9/8），它的单元按它在该基态激发里占的 s_e/S_b 记：布居 9/8·s_e·max(S_b, L_e)²/S_b·p_b，T 上 3/2·s_e·max(S_b, L_e)²/S_b·p_b 加能级之差那一项；同一距离的各驱动合计 c·S_b²·p_b。势自己的余项 |a₂² + a₁a₃| ≤ Σ_e s_e(S_b + L_e)/4 在其内。实测（一个基态到 1–3 个激发态，对精确的平均等待时间）：同一失谐、每个驱动 0.03，余项在共振处 +0.98 至 +1.02 (Σs)²、6Γ 处 −0.99 (Σs)²，是 Σs² 的 2–3 倍（逐个驱动记 s² 时只记到 0.38–0.57）；份额 0.04 分别在 3Γ 与 30Γ：−7.2 (Σs)²，是所记的 0.42。
    - 有四阶的簇里，这一项分给两个单元（§5.2）：簇的“二阶”单元带着四阶能去掉的部分（T 与布居：Σ s p），驱动自己的单元带着只有显式才能去掉的部分（四阶时的余项；两级都有的运动项 a 与多普勒下一阶）。
  - 裸折叠另有分母的一阶 |ε|。速率是响应的二次式，改变 2|ε| × 它在该状态各速率中的份额（记在布居与 T 上）；光移是一次式，改变 |ε| × 它在该状态光移中的份额（记在 T 上）。一个状态的全部驱动（折叠的与显式保留的）的份额加起来是 1，所以各单元的误差相加就是该状态的误差，不随驱动的个数膨胀；显式保留的谱线旁边，远处谱线的速率只是改变布居的总速率里很小的一份；
  - 拉曼对（折叠到显式激发态上的驱动）：3 m²，记在布居与 T 上。在 e 所在的簇里 m² = |U|² p_e/d_R²（d_R 取簇里各基态中最近的，并减去保留驱动对两个基态能级的移动）；在 g 所在的簇里 m² = |R[e,g]|²|V_a|²/d_a²，乘 p_g。系数 3 的来源：保留谱线读到的自能是 |U|²/(d_R + λ) 在 λ = 0 处的值，下一项使它的速率改变 m²(3ε² − Γ²/4)/(ε² + Γ²/4)、光移改变 m²(ε² − 3Γ²/4)/(ε² + Γ²/4)，任何 ε 下都不超过 3 m²。簇里某个基态离平均读数能量 off 时，另记保留谱线分母的相对误差 |U|² off/d_R²/|ε̃|（速率 2 倍、光移 1 倍，各乘它在该状态速率、光移中的份额）。
  - 两个态的耦合混入 m²(p_a + p_b)；两源光子相干 m²√(p_i p_j)。
- 折叠的更精确的一级依次是：二阶 → 四阶（有四阶的簇）→ 显式。

### 1.6 跳跃与光给的动量（定义：`model::photon`、`step`）
- 等待时间展开：阈值 θ ~ U(0,1]；跳跃发生在这样一步的末尾：这一步自己的传播恰在步末到达阈值。被尝试的一步给出它自己的传播到达 ln‖ψ‖² = ln θ 的时刻 s——带区间的反插值（过最近三点的抛物线，不行则割线，再不行取区间中点；到范数的舍入为止，不用 Newton：节点之间范数的导数不是态自己范数的斜率），在步内，或步末之后沿同一条路径再跟至多一个步长。s 不在步末时，这一步只是提出长度 s：生成元取在步的中点，换一个长度就是另一条范数曲线，所以按长度 s 重新走一步，直到 L = s(L)，容差 |s − L| ≤ (s_τ·ε)²·L（`units::JUMP_TIMING`，s_τ 是步长份额，ε 取两个目标里紧的那个；指数 2 是选定的，不是推出来的：任何高于一阶的幂都满足同一个论证）。在步末跳，余下部分另作一步。
- 光子类 φ：同一频率的光子集合，折叠振幅与显式振幅相加。类的概率 ∝ Σ_a‖u_a‖²，u_a = J_{a,φ}ψ；方向密度 ∝ tr G − n·Re(G)·n（G_ab = ⟨u_a|u_b⟩），从均匀球面精确拒绝抽样；偏振在 n 的实正交基中按 ‖Σ_a ε_a u_a‖² 选；跳后 ψ ← f/‖f‖。
- 吸收的光给的动量，一条规则。单位时间里，光对动量的作用是方法自身展开（半经典的 Wigner 展开，Gordon–Ashkin、Dalibard–Cohen-Tannoudji）的一阶与二阶 Kramers–Moyal 系数，对各类 c、各发射偏振 a 求和：
  - 力 Σ_c Σ_a Im⟨u_a|∇u_a⟩（散射力；偶极力在 Ehrenfest 力里），二阶矩的率 Σ_c Σ_a Re⟨∇u_a|⊗|∇u_a⟩。两者都**不除以**跳跃率 W_c = Σ_a‖u_a‖²，在相消干涉处（驻波节点）有限、光滑。二阶矩有一半来自不跳的演化，它不是“每个光子的属性”。
  - 没有任何一次动量增量是除以跳跃率得到的：
    - 跳跃（类 c，方向 n）：κ += −k_φ n + s_c b_c。b_c = Σ_a Im⟨u_a|∇u_a⟩/W_c 是该类的条件均值，s_c = min(1, k_c/|b_c|)，k_c 是该类所吸收的光的波数：跳跃带走它的条件均值，至多一个被吸收光子的动量。b 是各束波矢的加权和，权重非负时在它们的凸包里（|b| ≤ k）；只有相消干涉使权重变号时才超出，那不是任何光子的动量。一次跳跃的踢至多 k_φ + k_c。
    - 每步在中点（态 x_m，点 r_h）：力 F_s = Σ_c (1 − s_c) Σ_a Im⟨u_a|∇u_a⟩/‖ψ‖² 乘 τ；扩散 2D = Σ_c [Σ_a Re⟨∇u_a|⊗|∇u_a⟩ + E_c − s_c² W_c b_c b_cᵀ]/‖ψ‖²（Cauchy–Schwarz 保证半正定），经它的因子 Λ（Λ Λᵀ = 2D）作用在该步的布朗路径上（§2.1、§2.4）。
    - 均值留在跳跃上是因为精确的一阶项把吸收的动量给“跳过去的那一支”：内态随跳跃改变时（光抽运），把均值全改成连续力会多出量级为 k² 的方差（一束行波抽运一次，真实恰为一个 k）。内态只有一个时两种放法是同一个 Fokker–Planck 方程。
  - 显式激发态：它的跳跃算符是常数，吸收的均值在 Ehrenfest 力里，跳跃只带发射反冲。它的二阶矩的率 E_c 取它的驱动按原子处能级折叠时会有的响应：每个载波 c 的响应 σ_c = Σ_b ψ_b Σ_l a_l X_l[e,b]/(δ_b + w_l − iΓ_e/2) 对该载波的各光束和簇内各基态振幅相干求和（与折叠的跳跃同样求和，绝不逐束），S = Σ_c|σ_c|²，T = Σ_c Re[∇σ_c*⊗∇σ_c]（不同载波彼此拍动，按 |σ_c|² 分享光子），E_c = Γ_{e→c} · min(p_e, S) · T/S。p_e 是该态的布居，在一步里取步内的平均（冲量自己的求积；跳后的裸态在 1/Γ 内充满激发态，步不必分辨它，步内散射的光子是衰变率的积分）。布居只算到线性响应的那一份：超出的激发不是在此处吸收的，T/S 不是它的矩；上界是折叠的式子 Γ T，处处有限，不除以为零的响应。
  - 检验：单束平面波 b = k，跳跃恰带走 ħk，步里不剩力也不剩扩散；驻波 f ∝ cos kz：b = 0，2D_zz = k²R₀ sin² kz——波腹处为零，波节处（没有跳跃）为 k²R₀（偶极力的涨落，Gordon–Ashkin）；两束不等的对射光 f ∝ cos kz + iε sin kz：b_z = kε/(cos² + ε² sin²)，波节处 k/ε，跳跃只带 k；同一个跃迁折叠与保留为显式给出同一个每光子的二阶矩。
  - 强饱和下显式态的力涨落（Gordon–Ashkin 的一般式）不是轨迹上的闭式：E_c 随实际散射率饱和，对行波是对的，驻波的振幅梯度项在精确结果里不饱和。这是模型在该处的适用范围，不是规则的一部分。
  - 发射反冲为 −k_φ n，|k_φ| = |ω_φ|/c。ω_φ 是该类光子自己的频率：激发态的帧频率减去该类的帧频率，再加上源簇首态与落点簇首态的裸能量之差（帧是从每个簇的首态算起的）。回到原态的光子是所吸收光的频率（Rayleigh），落到别的基态的差一个基态能量差（Raman），显式激发态发出的是谱线的频率；簇内各态与自己的帧只差残余失谐，是光频的 10⁻⁷。

### 1.7 读出与输出（定义：`model::readout`、`estimate`）
- 读出：ρ_g = ρ − ½{Y, ρ}，加折叠的激发布居；显示行 P_s(t) = E[A(t) ρ_s] = p(1−L)。
- 损失：τ = 首次"在区域外，且 E_s 高于远处的渐近值"（阱光全是聚焦光束，§9：这个值是 0）；在每步末、每次跳跃后和每个输出时刻（步内读出的状态，§2.2）判定。L(t) = P(τ ≤ t)，单调。
- T_a(t) = (ħ²/m k_B)·(E[A·⟨κ_a²⟩_w]/E[A] − (E[A·⟨κ_a⟩_w]/E[A])²)：⟨·⟩_w 是以 t 为中心、一个 a 轴阱周期的窗口均值（窗口长度不超过一个输出间隔），平方项用无偏估计；n̄ 同理。窗口切到步内时，κ 与 κ² 取在"冲量摊在整步上"的路径上（§2.2 步内读数），任何一段都是格式的阶。
- t = 0：布居返回请求初态的对角；T(0) 为初始系综的精确矩。

### 1.8 原子能到的范围（定义：`model::reach`）
- 准备能量的子水平集 {(r, κ) : V_prep(r) + (ħ/m)κ²/2 − V_min ≤ L·k_BT_r}：势能与动能合在一起不超过这个水平。它是“装下系综里除份额 s 之外全部原子”的集合：s = z²/(N_max + z²)（§3 的函数在 N_max = 2¹⁴ 处的值，2.44e-4），T_r 为原子实际到达的温度（只增不减，由试探读出）。
- 水平 L 是初始系综（照它实际抽出来的样子，§2.5：热分布乘每个轴的谐振子 Wigner 因子）里一个原子的能量的 (1 − s) 分位数，按阱的谐振形式算。准备阱 Hessian 的每个把原子束缚住的主轴 i（阱频 ω_i > 0）是一个谐振子：经典时它的两个二次自由度共有 k_BT·E_i（E_i 是单位指数分布），Wigner 因子把两者都乘上 s_i² = x_i coth x_i，x_i = ħω_i/2k_BT（就是该振子自己的平均能量除以 k_BT：ħω_i ≪ k_BT 时为 1，冷的时候是零点能 ½ħω_i/k_BT）；阱不束缚的轴只有动量的一个自由度（Γ(½)）。所以能量除以 k_BT 是 X = Y + Σ_束缚 s_i²E_i（Y 服从 Γ(f/2)，f 是不束缚的轴数），L 由 P(X > L) = s 解出（对分到浮点分辨率，`quantile`）。一句话管所有温度，没有“冷”的分支：s_i 全为 1 时它就是 n = 6 − f 个二次自由度的 Q(n/2, L) = s，三个轴都束缚时 Q(3, L) = e^{−L}(1 + L + L²/2) = s，L = 12.89。（Boltzmann 因子等于 s 的水平 ln(1/s) = 8.32 只是一个振子的分位数，六个自由度下它留在外面 ## 2 数值方法

### 2.1 一步（定义：`step`）
一步 = A(τ/2) ∘ B(τ) ∘ A(τ/2)：
- A：参考哈密顿量 ħ²κ²/2m + V_ref 的精确流。V_ref 是固定参考态（初态里布居最大的基态分量；并列时取下标大的）的远光阱势在步中点 r_h 的二次展开（Hessian 解析；不定时为双曲流）。r_h 由"在 V_ref(r_h) 上的前半步流到达 r_h"这个不动点定义，所以一步是自身的逆（Hut–Makino–McMillan）。任何几何都是同一条规则，没有格点检测，没有区域换接。
- B：位置固定在 r_h。内态沿本步的直线路径 r_h + v_m(t − t_m) 演化，路径相位精确处理（多普勒参考系或拍）；冲量 = 在 r_h、对起点态的守恒力（剪切），加上态沿路径变化带来的部分，减去参考力；v_m = 步中点动量。
- 散射光在该步的部分（§1.6）也在中点：κ += τ F_s，加扩散。扩散是参考流里的精确形式：布朗路径在该步上的增量 ΔW = ∫dW 与关于中点的一阶矩 ΔZ = ∫(s − τ/2)dW 经 Λ 后，沿参考流的每个主轴（x = (ħ/m)λτ²）取“摊在整步上的力”在中点等效的踢 ∫cos(ωu)Λ dW 与位移 −(ħ/m)∫(sin ωu/ω)Λ dW 的方差：ΔW 乘 √((1 + c₁(x))/2)，ΔZ 乘 √(6 c₃(x))（Stumpff 函数；自由飞行时都是 1）。于是扩散注入的平均能量是 (ħ/m) tr(2D) τ/2，与 ωτ 无关；只用自由飞行的杠杆会在势能里多出 (ωτ)²/12。v_m 的预测不含随机部分：传播、范数、跳跃时刻与抽到的数无关。
- 性质：守恒部分辛、整步可逆、二阶。
- 内态传播（一条路径）：在步中点生成元的本征基里做相互作用绘景。生成元自己的频率（失谐、光移、衰减）对态和对冲量都精确积分，不论 Δτ 多大；沿路径的慢变化（k·v·τ）由步的中点和两端三个节点给出，D(u) = uA + u²B（`spectral`）。中点生成元的一对本征态按它在相邻两个节点之间转过多少分两种处理：转不到 1 弧度的慢对（|ω|·τ/2 < 1）每步两跳（起点到中点、中点到终点），每一跳取第一项 Magnus、其振荡积分解析做完，节点之间取五次 Hermite 插值；转过 1 弧度及以上的快对（显式的远失谐态）不跳，态跟随变化——逐元素解 ωX − iẊ + D = 0 的多项式 X₀ + uX₁ + u²X₂，它留下的二阶残余再跟一次——，变化量自己的光移留在慢对的生成元里，精确。对慢变化的阶：慢对是四阶——三个节点就是 Simpson 规则，Magnus 第二项是步长的五阶；快对留下跟随的三阶，在跟随量的平方 (k·v·(τ/2)·V/ω)² 以内（V 是耦合，ω 是这一对的频率），随步长、随失谐一起下降。传播自己的工作量与 Δτ 无关。1 弧度这条分界没有推导：它是两种处理的大小相当处（慢对的矩级数在 |z| < 1 内无相消），不是两者误差相等处。整步仍是二阶：那是分裂的阶（踢取在固定的 r_h，路径取直线，路径动量靠预测），不是传播的。实测（PGC3D，F = 2，25 µK，τ = 0.625 µs，k·v τ = 0.25）：传播在该步路径上自己的误差，冲量上只占"一步对两个半步之差"的 8 %，内态上约三成；τ 减半时它降到 1/70 与 1/50，而那个差只降到 1/14 与 1/8。本征矢量病态处（例外点附近：经本征基的舍入超过直接指数的舍入时）不做分解，在求积节点之间逐段用 CF4（同一个 Ĥ₀ + uA + u²B，两个指数）。原因：显式的远失谐激发态（Δτ ≫ 1）下，原来在网格节点上"采样"以 Δ 振荡的力，冲量错 17–46 %，一步对两个半步完全看不出（R4_LIN_4：T_z 在 τ = 0.0625 读 62、在 0.0039 读 45；改后 47.6 ± 1.2 对 45.5 ± 1.0）。指数与级数算到舍入（代价对精度是对数的）。
- 跳跃：一步自己的传播不在步末到达阈值时，按它到达的长度重新走一步，直到到达点落在步末（§1.6）。

### 2.2 步长：全程一个常数（定义：`adapt`；选取与记账：`solve`）
- 一次运行只有一个步长 τ，所有轨迹共用。每条轨迹以 τ 推进：
  - 步不认输出时刻：输出落在哪一步里，就在那一步里读（下面"步内读数"）；整次运行的最后一步取剩余时长；
  - 步内发生跳跃，就把这一步重做到根，在根处跳跃，下一步从那里起仍是 τ；
  - 格式做不出的步（中点的不动点不收敛）取一半。
- 步内读数（定义：`step::Segment`、`step::Step::at`；`adapt::advance` 在每步里读落在该步的输出）。步长由格式要分辨的东西决定，与输出多密无关：输出间隔是步长的十分之一，也不让步长变小。一步在两端之间知道的东西：
  - 内态：传播本来就有步内任意时刻的态 x(u)（u 从中点起算，中点生成元本征基里的相互作用绘景，§2.1；跳跃的求根就是这样读的），ψ_s = e^{iK_s·v_m u} x_s。它是直线路径 r_h + v_m u 上的解，这条路径离原子的路径 ½au² + ½a_B h²（a 是总加速度，a_B 是冲量那一份，h = τ/2），速度是 v_m 而不是 v_m + au：u 处的误差是 ∫∇H·d = O(τ³)，再加生成元对所取动量 κ_m 的依赖带来的 ∂_κH·a(u² − h²)/2 = O(τ²)，在两端为零。
  - 位置与动量：分裂自己的路径（参考流、中点一踢、参考流）在两端是对的，在步内**一阶**地错——中点之前动量少了已经过去的那段时间的力，中点之后多了还没到的那段，是幅度为半个冲量的锯齿。整步上它从 ∫κ 里消掉（∫κ² 里到 τ²），步内一点上消不掉。所以把这一踢摊在整步上：参考流是仿射的，贯穿一步的力 f(u) 在步末的效果等于中点处的冲量 ∫cos(ωu) f du 与位移 −(ħ/m)∫(sin ωu/ω) f du（每个主轴；与扩散的"摊开"是同一个恒等式）。取对时间线性的力 α + βu，使这两个积分正是本步的冲量与位移：α = Δk/(τ c₁(x_h))，β = shift/(2h³(c₂ − c₃)(x_h))，x_h = (ħ/m)λh²。在这个力下的参考流从步的起点精确地走到步的终点，中间：
    - 冲量的确定部分 = 把力在一步内当作常数。u 处动量的误差 f′(h² − u²)/2（f′ 是力的变化率）：O(τ²)，两端为零；位置是它的积分，O(τ³)。
    - 布朗部分 = 给定本步所取的两个矩（ΔW、ΔZ）时路径的条件均值；自由飞行时 E[W(s)|ΔW, ΔZ] = sΔW/τ − 6s(τ − s)ΔZ/τ³ 正是这条流。两个矩没有说出的是布朗桥剩下的部分，方差 τσ(1 − 3σ)，σ = (s/τ)(1 − s/τ)（两端为零，至多 τ/12），经 Λ。在一个时刻读出的动量用一次抽样补上它（该时刻自己的流）；窗口的 ∫κ² 按均值补上它的积分（整步是 τ²/15），于是任何一段的 E∫κ² 都含扩散到该处为止的全部输入（核对：∫₀^τ [s²/τ + 3s²(τ − s)²/τ³] ds + τ²/15 = τ²/2）。余项取自由飞行的形式，参考流的转动改变它的 (ωτ)² 份，三阶。
  - 阶：步内读到的值 = 累积到步起点的格式误差（O(τ²)，对时间光滑）+ 所在这一步自己的一项。后一项不累积，所以 O(τ²) 就保住二阶；读在步末时它为零，读到的就是步末本身（到舍入）。两层（τ 与 2τ）在同一时刻读：τ → 0 时一致，差为 τ² 阶；Richardson 的系数对光滑的累积部分逐输出成立，对读数自己的那一项（系数 (h² − u²)/2 随输出在步内的位置变，对位置平均是 τ²/12）按输出平均成立——筛正是在输出上取平均。布朗路径在读数处的部分是每层自己的（如同跳跃那一步），两层之差零均值，方差是"两个矩没说出的"那一份，随 τ 降。
  - 比较过的做法：中点一踢的路径（不花代价，动量一阶）；把冲量的求积做到读数时刻（约三分之一步的代价，误差同样是 f′(h² − u²)/2：剪切取在固定的 r_h，驻波里被保持的态的力在格式里一步内是常数）；从步的起点另走一个缩短的步作旁支（三阶，但每个读数一整步：GMD1C 每条轨迹 556 + 1000 次步求值，只比现在的 2000 省 22 %）。取的是摊开的冲量：每个读数一个"某时刻的态"（n²）和一次流求值，约百分之一步。
  - 跳跃：跳跃所在的步在跳跃处结束，之前的输出从到跳跃的那一步读，之后的从下一步读。跳跃之后不再在下一个输出处对齐（原来那里的步被截到输出）。
  - 损失是首达时间，在轨迹的状态被做出来的每个地方判定：步末、跳跃后、以及每个读数处（§1.7）。不在读数处判，步内输出上的损失就是上一步末的，晚一个步长，一阶。读数处判定为损失的轨迹就在那个时刻损失，它的窗口只取这一步到该时刻为止的部分。
  - 实测（2026-11-11，658f53ff 之上；`step::tests::a_read_inside_a_step_is_of_the_second_order_and_the_step_s_end_at_its_end`，两个态各在自己的谐振阱里，闭式解）：一步内 0.3τ 处读动量，τ 逐次减半时误差 3.8e-2 / 1.0e-2 / 2.7e-3 / 6.9e-4（阶 1.86 / 1.94 / 1.97）；同一处用中点一踢的路径是 3.34 / 1.67 / 0.83 / 0.42（阶 1.00）；步末 5.2e-2 → 1.0e-4（阶 3.00）。跑四个轨道周期，在步内读的 r、κ、两态相对相位都以 2 阶收敛（1.84–2.08），与步末处的 2.00 相同。读在步末等于步末（1e-13 内）。
  - 实测，场景：R6_RAMAN_CO（20 µs、401 个输出，布居振荡）步长 0.025 → 5.006 µs（每条轨迹 800 → 4 步），check.mjs 通过，max|d| 0.013；R5_PUMP 0.5 → 6.68 µs，通过；PGC3D 1 ms 0.8333 → 0.8910 µs，368 条，T 与 0.8333 的结果在统计内一致（全部输出上 z 的均值 0.29、均方根 1.00）。GMD1C 1 ms × 1001 个输出：新做法在原步长 0.5 µs 下（手设）472 条，T 与原结果一致（全程平均 −0.3 %，z 均方根 0.91）；在 0.91 µs 下（手设）536 条，仍一致（−0.6 %），轨迹步数 0.59 M 对 0.94 M。
  - **实测到的问题（步长的筛的事，不在步内读数的范围内）**：GMD1C 上只由可用性定出的起始档是 1.819 µs（伴随 3.638 µs），筛没有减半——两层在 88 对上对 T 的分辨率只有 ±15 %。在这个步长上 T_总 随时间越来越低（全程平均 −3.5 %，700 µs 之后 −7 %，T_z −16 %），并出现一个 0.35 m/s 的原子（可达范围的 v_max 是 0.2185 µm/µs），它把 T 的统计噪声放大到要 1696 条轨迹：轨迹步数 0.93 M，与 0.5 µs 的 0.94 M 相同，CPU 反而多一半。输出稀（101 个）时同一步长给出同样的 T，所以这是步长自己的误差，不是步内读数的。
- 为什么是常数：分裂的守恒部分辛、整步可逆，步长不变时阱中运动的能量误差有界（参照 R1：10³ 个周期不漂）；按上一步的误差选步长则会漂。实测：逐轨迹接受/拒绝的步长控制步数 ∝ 时长^1.4、一半的步被拒；常数步长的步数 = 时长/τ + 跳跃数。
- 梯子：档位是运行时长（最后一个输出的窗口末端，`Plan::end`）的偶数分之一，往下逐次减半。偶数的原因：伴随层的步长是两倍，运行于是恰好是伴随层的整数步，两层都没有被截短的末步（没有跳跃的轨迹正好走 end/τ 步）。输出间隔不进入步长（上面"步内读数"）。一档对某个速率的原子可用，条件是一句话：它的节点分辨得了这个格式沿该原子路径采样的东西（`solve::admissible`）。
  - 参考流：ω τ < π，ω 取准备阱最大的主轴频率（一步里两个半步的参考流把运动转过 π 时，夹在中间的冲量会被放大；实测：越过即错）。
  - 生成元：传播在步的中点和两端三个节点上读生成元沿路径的变化（§2.1），节点相距 τ/2，并把它当作过这三点的抛物线。一个在簇的参考系里残余拍频为 Ω、残余波矢为 K 的矩阵元，沿速度为 v 的路径以 |Ω + K·v| ≤ |Ω| + |K| v 的速率转动，相邻节点之间转过这个速率乘 τ/2；到 π 时节点读到的只是它的混叠。所以对每个矩阵元 (|Ω| + |K| v)·τ/2 < π。K 与 Ω 取自模型自己的组装（每个拍频下它各矩阵元的最大残余波矢，`Model::sampled`：两个场分量各束光的波矢之和减去两态参考系之差），不按光的种类列表。
  - 为什么需要第二条：只有阱的共振时，R4_LIN_1 的顶档是 16 µs，5–10 cm/s 的原子一步跨过一到两个 lin⊥lin 图样的波长；8 与 16 µs 两层同样没有意义、彼此一致，两层比较在那里是瞎的。
- 起始档（`solve::first_rung`）：对运行可用、且它的两倍对伴随层（2τ，见下）可用的最大一档。两层的任务不同，条件各有其义，速率都取自模型判定所用的同一个可达范围（§1.8），范围长大时起始档跟着降：
  - 运行的步长是结果：它要对模型所判定的每一个原子可用——阱的共振以下，并且在可达范围的最大速率 v_max（`Reach::speed`）下分辨得了光。模型的折叠与步长用同一个有效域。
  - 伴随层是探针，不是结果：它要稳定（阱的共振对每个原子都一样），并且对典型原子分辨得了光，即取可达范围温度下的方均根速率 √(3k_BT_r/m)。两层里若有一层在多数原子上读到的是光的混叠，两层的一致或不一致就与步长无关；超出它上限的少数最快原子只按它们的份额进入差值。
  - 阱的共振起限制作用时，这就是"最大稳定档的下一档"。起始档至多是运行时长的一半：伴随层的步长自己也是一档，那时整次运行是它的一步。
  - 起始档是梯子上的一档，梯子的底是每条轨迹 2²⁴ 步的那个步长：一直数到底也没有可用的档（光或阱要求的步长比上限允许的还小；或者阱频、速率不是有限数，那时没有哪一档可用），就拒绝这个请求、返回错误（§9）。不可用的步长算出来的不是这个模型的解，不拿它当"到了下限照常返回"的结果。
- 步长的收敛是在试探上做的一次检查，不是每个输出上的误差界（定义：`estimate::between`、`solve::screen`、`solve::blind`、`solve::remedy`、`solve::checked`）：
  - 两层：试探的轨迹跑步长 τ，同编号的轨迹在 2τ 下再跑一遍（伴随层）。同编号 = 同一个初始原子、同一组跳跃用数、同一条布朗路径（§2.4）。
  - 读的是误差在全程上的大小。一个量 Q 在第 k 个输出的步长误差 e_k = [Q_k(2τ) − Q_k(τ)]/(2^p − 1)（Richardson：e ∝ τ^p；p = 2 时是两层之差的 1/3）。检查读它在 t > 0 各输出上的均方 M = (1/K) Σ_k e_k²（方均根 √M）：损失、每个显示行（绝对）、总温度（相对 τ 层的总温度；两层都读得出的那些输出）各一个数。M = (平均误差)² + 误差随时间的方差：随时间变号的误差（振荡布居的相位误差）按它的大小计入，而带符号的平均在那里读到零。实测 R6_RAMAN_COUNTER（5 µs 对 10 µs，显示行）：带符号平均 0.43 %，方均根 2.2 %。
  - 估计不带噪声本底。估计值的平方里含有估计值自己的方差，没有误差也不为零。各组独立，两个不同组的值相乘就没有这一项：
    - M̂ = (1/K) Σ_k [(Σ_i x_ik)² − Σ_i x_ik²]/(G(G − 1))，x_ik 是第 i 组自己的 e_k，取 jackknife 的伪值 G·e_k(全体) − (G − 1)·e_k(去掉第 i 组)：对轨迹取平均的量（损失、显示行）它就是该组自己的差；T 是比值，它是 T 在两层合并值处的线性部分。一条规则适用于每个量。
    - E[M̂] = M，与噪声大小无关；没有误差时 M̂ 落在零的两侧。
    - 误差是 M̂ 自己的删一组 jackknife（每一组同时从两层、从所有输出里删掉，时间上的相关自然在内）。M̂ 的方差有两项：(4/G)⟨μ, Cμ⟩（有误差才有，随 1/G 降）与 (2/(G(G − 1))) tr C²（本底自己的涨落，随 1/G² 降）；jackknife 把第二项算成 2(G − 1)/(G − 2) 倍（Efron–Stein），所以没有误差时偏大，不会偏小。
  - 判定在平方上做，三种结果（§5.1），界是步长份额的平方 b = (s·ε)²（s = √(1/(1+2p))；均方按 τ^{2p} 变）。每一档、每加一批对之后都重读：
    - 超出：某个量的 M̂ − t·SE > b（t 取整族三十几个读数的区间）→ 减半：τ 那一层变成伴随层，只新跑 τ/2。降到 τ = 时长/2²⁴ 为止，到了仍超出就标记。
    - 在内：每个量的 max(M̂, 0) + t·SE ≤ b（各用自己的区间）→ 步长站住：它的方均根误差在份额之内。M̂ 为负时远端从零算起：大小不会为负，读到负值就是什么也没读到，排除不了比它自己的区间更小的误差。
    - 读不清（两者都不是）：这次检查看不见。scout（11 对）只筛明显超出的，读不清就让步长站住，留给试探。试探上取预计工作量较小的补救（工作量以 τ 下的一条轨迹为单位，轨迹的步数 ∝ 1/τ）：
      - 加对。没有误差时 SE 是本底的涨落，随 1/N 降，所以检查的分辨率 √(t·SE)（它分不清有无的方均根误差）随 N^{−1/2} 降，与任何统计区间一样。预计看得见所需的对数 N = N₀·t·SE/(b − max(M̂, 0))；M̂ ≥ b 时多少对都不够。工作量 ½(N − N₀)（伴随层，每对半条）+ max(N, N_产品) − N₀（τ 层：新加的对就是产品接下来要跑的那些组，不白跑）。一批至多把对数翻倍（§3 的批次规则），跑完重读、重新预计；预计所需的对数超过轨迹数上限 2¹⁴、或对数已到上限时不加对，走下一档；误差已被分辨出来时 SE 只随 N^{−1/2} 降，预计偏少，由重读逐次补足，不会超过实际所需。
      - 下一档。按格式的阶，τ/2^j 的均方至多是远端除以 2^{2pj}，j 取使它 ≤ b 的最小值；工作量 2^j·max(N_产品, 试探) + (2^j − 2)·试探（产品在新档上重跑，中间各档的试探）。只走一档，到了再读（新档的两层是现成的）。
      - N_产品 = 试探 τ 层的估计在步长份额旁预计的产品轨迹数（§3 的同一个预计）。
      - 两个工作量对读数都是连续的：刚好看不见时只需再加一组（8 对，伴随层 4 条轨迹的量）；选择翻转之处两者相等。落在阈值上的一个带噪声的数因此不会把一次运行的代价翻倍。
      - 停止加对：看得见了（站住）、读到超出（减半）、或者还需要的对预计比下一档更贵（下一档）。
      - 两种补救都没有余地时（§5.1 的"界用完"）：拿不到的补救工作量记作无穷——所需的对数超过轨迹上限、已在梯子的最后一档（再减半就超过每条轨迹 2²⁴ 步）、或者读数什么也排除不了（不是数，或离散读不出：按阶算不出要减半几次）。在最后一档上只剩加对一种补救，够得着就加；两者都是无穷，检查就以"看不见"结束：步长站住并标记，每个量的账目记检查没有排除的上限，即远端的方根 √(max(M̂, 0) + t·SE)（各用自己的区间，取本档由它保证的那个读数；`solve::unexcluded`），不再记读清的部分。
  - 继承。减半得到的档继承上一档的读数，按阶降低（值和误差都除以 2^{2p}，`solve::lowered`）；每个量由自己的读数和继承的读数中远端较小的那个保证（`solve::held`）。
  - 阶的前提要检验。e = 差/(2^p − 1) 和继承都以"这几层之间 e ∝ τ^p"为前提；减半之后有三层，这个前提可以检验：本档自己的读数的近端高于继承读数的远端（都取整族的区间）就是前提被推翻（`solve::refuted`）——误差在这几档之间没有按阶下降，两个读数都不是步长误差——减半。逐个量检验，只检验两档都读得出的量：损失与各显示行总在其中；总温度只有两档都读出时才检验，只有一档读出时它没有可比的对象，不算在这一族里，也不妨碍别的量照常检验。
    - 实测 R6_RAMAN_COUNTER 显示行的 M̂：4.77e-4（5 | 10 µs）、2.71e-4（2.5 | 5）、3.10e-4（1.25 | 2.5）、3.7e-7（0.626 | 1.25）。到 1.25 µs 为止没有收敛：步长分辨不了多普勒相位。2.5 与 1.25 µs 上自己的读数是"在内"（方均根 1.7 % < 2.24 %），而解析参照在 2.5 µs 上最大差 0.147，比 5 µs 的 0.097 还大。只换统计量不够：没有这一条，它停在 2.5 µs，不通过；有了它停在 0.626 µs，通过（最大差 0.035）。
    - 限制：前提只有三层才能检验。起始档自己直接读到"在内"时只有两层，那一档就凭 Richardson 站住。
  - 记账：一个量在每个输出的账目里，步长这一项都是它的方均根里读清的部分 c = √max(M̂ − t·SE, 0)，t 取同一族的区间。没看到变化就是 0；检查让步长站住时它不超过份额。试探之后固定。
  - 检查的分辨率照实写出、不记账：结果的方法说明里写明比较的是哪两个步长、多少对轨迹、方均根误差低于多少时分辨不出（√(t·SE)：布居绝对、T 相对）。它不进任何总误差，本身也不触发标记。
  - 这是检查，不是界：只出现在运行中一小段时间里的误差会被整段运行的长度稀释；e 依赖格式的阶（上一条）。
  - 产品只跑 τ 一层，不再读步长。
  - 与带符号平均相比（原来的统计量；对随时间不变的误差它是最有力的）：设噪声在全程有 K′ 个独立的时段、单个输出上是 σ，平均能分辨 t·σ/√K′，均方的分辨率约为 (2/K′)^{1/4}·√t·σ——只有一个时段时相同，时段多时差 K′^{1/4} 倍；误差一旦被分辨出来，两者的区间一阶相同。实测（88 对，总温度的分辨率，均方 | 带符号平均）：PGC3D 0.716 µs 2.4 % | 2.9 %；四面体 MOT 0.716 µs 3.0 % | 4.0 %、0.358 µs 4.6 % | 3.7 %；GMD1C 1.458 µs 7.5 % | 10.6 %。带符号平均的噪声是全程最慢的那个模式（最大的一个），均方把它只当作 K′ 个模式之一，所以实测中没有吃亏。带符号的平均只能从下面界住 M，永远说不出"在内"，所以只用均方一个统计量，不加第二族读数。
  - 阈值取份额而不取目标（原来"检查必须看得见"取的是目标，且只会减半）：读不清就站住，等于让一个估计值在份额附近、真值更大的步长通过（R6_RAMAN_COUNTER 在 5 µs：远端 2.9 % < 5 %，站住，不通过）；现在有了便宜的补救（加对），§5.1 的规则可以照原样执行。代价：显示行的步长误差确实在份额附近的场景要走到更细的步长（R4_LIN_4 在 0.356 µs、176 对上：显示行的步长误差带符号读到 3.3 % ± 0.8 %，份额是 2.24 %；这是布居上真实的差别，不是温度的噪声）。
- 为什么只做检查（实测）：
  - 做成每个输出的界（产品两层都跑、每批重测，a60231dd）要多花一次运行的 30–240 %（同一条线上 CPU：R10_HELD_ANTINODE 120 对 95 s、R3_DOPPLER 472 对 205 s、R9_PUSH 58 对 17 s）。原因：成对轨迹在 PGC3D 上 100 µs 内就分开（两层之差的方差 / 单层方差：50 µs 处 0.35，100 µs 处 1.1，此后 1.5–2 即相互独立），关掉扩散也一样快——跳跃的时刻由步长定，光场波长尺度的结构把这点差别带到条纹的另一处；R3 上能保持 0.5 ms。之后 SE(e) 就是两个独立系综的，把 T 上 3 % 的误差分辨到 2σ 要约 870 对。
  - 把 e 在输出时刻上合并（Lepski 规则取窗口）降噪：e 不随时间变时 SE 降到 1/2–1/3 且无低估；e 随时间线性增长到 6 % 时，运行末尾记的界低于真值的占 16–54 %（允许 2.3 %）。改用窗口内直线则覆盖恢复而收益抵消。
  - 沿轨迹逐步读局部误差（每步对两个半步，再按动力学带到输出）：PGC3D 上 τ = 0.625 µs 读到 T_x +3.2 %（真值 −1 %）、1.25 µs 读到 +37 %（真值 −3 %）；读数用的"轴能量"在近共振光自己给力时不是运动守恒的量。三种局部形式都没有在三个轴上同时对。
  - e = C τ^p 要求 2τ 那一层也分辨得了决定误差的过程。PGC3D 1 ms：τ = 1.25（伴随 2.5 µs）读到 T 的 e = +11 到 +28 %，真值 −3 %：2.5 µs 分辨不了内态，差偏大一个量级；τ = 0.625（伴随 1.25 µs）读到的与真值同量级（1 % 上下）。偏大只会让步长更细。
- 实测（同一条线 e125aa2f 上各跑一次；上限与取到的步长；筛在这四个场景上都没有再减半）：
  - PGC3D 1 ms：阱 τ < 4.97 µs；光 K_max = 25.5 /µm（簇的参考系里最大的残余波矢，√10·k），v_max = 0.2185 µm/µs 下 τ < 1.13 µs，方均根速率 0.093 µm/µs 下伴随层 < 2.66 µs：起始档 0.625 µs（伴随 1.25 µs）。840 条，CPU 117 s（原来逐步读数的做法 362 s、0.3125 µs）；T 在 250 与 500 µs 处与真值在误差内一致。
  - R3_DOPPLER：K_max = 16.1 /µm；可达范围 30 µK 时起始档 1.25 µs（伴随 2.5 < 4.20 µs），原子升温、范围长到 124 µK 后（τ < 0.88 µs，伴随 < 2.07 µs）是 0.625 µs：解析参照通过，1408 条，CPU 177 s。
  - R4_LIN_1：K_max = 32.2 /µm（4k），τ < 0.89 µs，伴随 < 2.10 µs：起始档 0.5 µs（只看阱时是 16 µs，原子被加热出阱）。T_z 在 0.4/0.8/1.2/1.6 ms 处 11.46/11.32/11.64/11.21 ± 0.25 µK，与 0.25 µs 下的 11.40/11.31/11.28/11.59 在误差内一致；CPU 397 s。
  - R1_RETRO（阱 0.549 µs 起限制作用：0.3125 µs 稳定，它的两倍不稳定，起始档 0.15625 µs）、R10_HELD_ANTINODE、R9_PUSH（单束行波不留残余波矢）：与只看阱时相同。
- 模型的决策（§5.2）里步长误差一律按份额 s·ε 取。定模型不用整套试探：scout（11 条的两层）筛过步长后，在它 τ 层的状态上测各被消去单元的误差；要显式跟踪某个单元、或原子超出了取值范围，就在这里换模型重来。模型各单元的误差在每组第一条**仍被俘获的**轨迹的状态上测（每个输出 11 个状态）。
- 格式在任何长度上都做不出某一步（中点不动点不收敛到时间的舍入，或状态超出浮点范围）的轨迹：从做不出的时刻起不计入任何估计，单独计数并标记。它不是损失。
- 求积节点：一步内的时间积分（冲量、平均布居、范数的根）在 Gauss–Legendre 节点上读，节点数由被积二次型的带宽定，不调用模型；τ 减半节点随之减半。
- 每步内态只传播一次：沿直线路径，路径速度取预测的步中动量（起点态在步中点受的力算出的半步冲量）。原来的"预测再校正一遍"删掉了。无光时一步与反向一步仍回到舍入；有光时来回的偏差是"一步对两个半步"之差的 5e-5 到 2e-4（缀饰态出发），随 τ 下降快于 τ³，是步长误差的一部分。实测（PGC3D 100 µs，单线程）：一步 92 → 60 µs，结果在误差内一致。
- 路径速度 v_m：只预测（κ_h 加上起点态在 r_h 的剪切与参考力给出的半步冲量），不校正。预测差的是"态的变化带给冲量的那部分"的一半，O(τ²)；冲量对 v_m 的敏感度是 O(τ)，所以冲量差 O(τ³)，就是格式自己的局部阶。
- 损失：步长对损失的误差与显示行、T 同一个量（试探两层的损失之差的 1/(2^p − 1)）；没有损失能量的窗口。

### 2.3 表（定义：`table`、`model::tabulate`）
- 表化的对象：每个簇、每组光下，近光消去的非线性部分，即该簇的"近光形式"——光移与耦合 S 及其多普勒伴随项、跳跃 C_aT 与 C_aT2、显式激发态的 van Vleck 移、响应 T 与 T2（读出用）——都写在各载波的场基上，是若干复数。线性部分（场分量 e_k、多普勒移 w_l、平面波相位）在原子处精确计算，不进表。表化与不表化用的是同一个组装（§1.4），只是这些形式的来源不同。
- 坐标：消去通过分母里的能级和各载波的缀饰、自能依赖位置。不是载波的频率以它的相干矩阵进入能级，即该频率坐标图的函数（光强、偏振角、相对相位）；载波以它的缀饰进入：T̄ 下是它每个偏振单元的光强 I_u（它所在频率的静态形式也按 I_u 进入，§1.4），缀饰单元被保留时是它的坐标图。每个坐标取它的整个值域，所以原子走不到表的边上。
- 轴：一个坐标的先验权重 = 它在可达范围内把簇的谱线移动多少个半宽（响应是谱线失谐的极点，它的相对变化至多是这个数）。光强坐标的权重 = 单位光强的移动 × 可达范围内光强离焦点值的可证界（§1.8），所以平面波的光强处处相同、权重为零。权重不低于布居目标的坐标从重到轻取作轴，直到一次插值不比它替代的消去便宜、或首个网格超出工作量界、或已有 6 个轴（`table::MOST_AXES`，查表时各轴模板的容量，不是推导出的数）为止；一个都没有时，表就是焦点处的一组值。不作轴的坐标固定在焦点值，它带来的误差由下面的整体读数读出。
- 插值：每轴三次 Hermite（Catmull–Rom 斜率，C¹）；周期相位轴用周期插值。力取插值自身沿各轴的导数乘坐标的梯度。于是表化的生成元的力就是它自己厄米部分的梯度。衰减取表里另存的乘积 Σ J†J 的插值，跳跃取 J 的插值（§1.4）：两者差一个插值误差，在节点上严格相等，所以表化的生成元只在节点上严格是 Lindblad 的，节点之间到表的误差为止（这个差含在整体读数里）。表代表的是"近光形式为插值"的那个模型。表只在各轴的值域内取值，不外推；越界是调用方的错误，直接拒绝。
- 加密，在使用之前做完。响应是失谐的极点，轴把谱线带过共振是阱中近共振光的常态，首个网格分辨不了它。把一个轴的间距减半，新节点正好落在原来各区间的中点。那里并不是插值误差最大的地方：三次插值的首项误差 (h³f‴/6)·u(1 − u)(1 − 2u) 在中点为零，最大在 u ≈ 0.21 与 0.79（`table`），所以这个检查读到的是下一阶 h⁴f⁗，不是减半之前那张表的误差的界；保留下来的表到底差多少，由原子处的整体读数读出。在这些节点上，把减半之前的表与消去本身比较（消去的值就是新节点的值，所以这个检查不另花消去），范围是可达范围碰到的所有区间：光强轴取焦点值 ± 光强变化的可证界，角与相位取整个值域。量度有两个，各取这些节点上的最大值：
  - 响应的相对误差 (‖ΔT‖ + w‖ΔT2‖)/‖T‖，w 是该载波各光束在可达速度下最大的多普勒移；速率是响应的二次式，所以取它的两倍；
  - 势的误差的界：‖H̃_h − H_h‖ 按行的界，每项按两个场分量的峰值。
  一直减半到"减半之前的表"落在份额之内，保留更细的那张，它自己的误差比验证过的再小插值的阶（值三阶、梯度二阶）。下一个网格超出工作量界就停，误差按整体读数记账。不是数的误差（节点落在实分母的极点上）算作读不出，记 +∞，永远不在份额内。
- 表的份额。表的误差要低于任何一次运行读得出的量，所以取最大系综的分辨率，N_max = 2¹⁴ 条轨迹、置信度 z：
  - 显示量，绝对：z/(2√N_max) = 0.0078（一个份额 p 的标准误差至多 1/(2√N)）；
  - T，相对：z√(2/N_max) = 0.022（方差的标准误差，正态理论）；势的误差按 T 的份额乘 k_BT_r。
  误差在这两个数以内，就没有哪次运行会受表的限制。
- 表的误差在账本里的形式（整体读数）：在试探状态上把表给出的近光形式与精确消去比较，按它对该状态的生成元造成的误差记。δ = ‖(Ñ − N)ψ‖/‖Nψ‖，N 是近光在生成元里的部分（多普勒伴随项取原子的动量）。布居（绝对）记 δ·P_g，P_g 是该状态的基态布居；T（相对）记 δ·P_g 与 |ΔV|/k_BT_r 中较大的，ΔV = ⟨ψ|H̃_h − H_h|ψ⟩ 是势的改变（保守的改变，动能至多跟着变这么多）。力的误差不另记：它是小量 ΔV 的梯度。每个轴另有自己的插值误差读数（同一点上粗、细两套插值之差），用来指出是哪个轴。

### 2.4 随机数（定义：`random`）
- Philox4x32-10。键为（种子, 用途），计数器为（轨迹, 事件）。
- 第 j 次跳跃用第 j 个流：只差步长或模型的两次运行，在同一跳跃序号上抽到同样的数（共同随机数）。抽取顺序固定。
- 每条轨迹有自己的布朗路径（三个独立的标准布朗运动，§1.6 的扩散），它是时间的函数，与步长无关（定义：`adapt::Path`；只有这一种实现）：
  - 时间按输出间隔分成格子。每个格子上路径的那一段（增量 ΔW 与关于中点的一阶矩 ΔZ）取自该格子自己的流（用途 Diffusion）；格子的两半是两端之间的布朗桥（`step::Brownian::split`），取自那个节点的流，逐层往下：任何一档的任何一个区间上的那一段都是（种子，轨迹号，区间）的函数，并且等于它两半之和——2τ 的一步取的正是它跨过的两个 τ 步之和。
  - 不落在网格上的步（结束在跳跃处，或跳跃之后的那个 τ）把所在区间在该时刻再切一次（同一个布朗桥，取自以该时刻为键的流，用途 Bridge），剩下的部分留给下一步。
  - 每一段的分布都严格是布朗路径在该段上的分布，不相交的段相互独立。产品只用到这个分布；试探的两层用到"同一条路径"。
  - 读树是增量的：记住上一个区间从格子到它的那条枝，下一个区间只从两条枝分开的那一层往下算（相邻区间平均只差两个节点），结果逐位相同。
  - 实测（`adapt::tests`）：τ = 1、2、4 µs 三档，每个 2τ 步与它的两个 τ 步之和相差 ≤ 1e-13；乱序读各区间与各自从头读逐位相同；切出的一段的方差为 s 与 s³/12、协方差为零。

### 2.5 初始系综（定义：`ensemble`）
- 每个初态分量在自己的准备阱里：降低的等温分布乘每轴谐振子的 Wigner 因子；精确拒绝抽样，包络用证明的上界。

## 3 统计（定义：`estimate`）

- 所有轨迹都跑到最后一个输出时刻。每个输出的估计是全部轨迹的样本均值，按组 jackknife，区间用 Student t_{g−1}。
- 显示行直接对 A·ρ_s 做 jackknife；T 的 plug-in 方差补上 s²/n 项。
- N 次抽样里出现 n 次的份额只有一个函数：Wilson 远端（`wilson`）；n = 0 时是 z²/(N + z²)（`unseen`）。
- 批次：每批之后，对每个计入目标的量（每个输出的显示量；每个输出的总温度）算总误差 E² = A² + c² + S²：A 是模型误差、c 是步长检查读清的部分（§2.2），两者都由试探固定；S 是统计区间。全部在目标内就停——这就是账本标记一个输出所用的同一个判据（§4）。停止只依赖本次的标准误差，不依赖估计值本身。
- 统计的余地：R² = ε² − A² − c²。所需轨迹数按 S ∝ N^{−1/2} 预测（显示量不少于"零计数的 Wilson 远端不超过余地"所要的条数）。没有余地的量（A² + c² ≥ ε²，模型的决策已经保留了能保留的）不追：由账本标记。
  - 总温度的统计读不出的时刻（被俘获的原子不足两组）没有可以外推的区间：所需轨迹数按一个轴的方差的正态理论预测，相对区间 z√(2/(N h))（N h 是被俘获的原子数；三个轴的平均不会比它大）。这是同一个量的第二条预测规则，只用在这种时刻。
- 试探的大小（`solve::pilot_size`）：试探是运行的头一批轨迹，任何运行都不会停在比它更少的轨迹上。显示量的统计不小于零计数的 Wilson 远端（§4），所以在步长份额旁、模型没有误差时，N 至少要使 z²/(N + z²) ≤ √(1 − s²)·ε：N ≥ z²(1/(√(1 − s²) ε) − 1) = 85.4（z = 2，s² = 1/5，ε = 0.05），取整组是 11 组、88 条。
- 一批至多把轨迹数翻倍：所需轨迹数是由已有各组的方差预测的（起初只有试探的 11 组），一批至多跑到这次预测所依据的轨迹数的 2 倍。各批累加，运行停在第一个满足目标的总数上；所以最后的总数不超过刚好够用的 2 倍。
- T 的目标在总温度上：用户的 10 %（相对，置信度 z）说的是三个实验室轴的 T 的平均（总温度），它的统计误差是这个平均值自己的刀切误差。t > 0 的每个输出、只要读得出，就计入目标。
  - 为什么不逐轴：用户（2026-11-11）："不用每个轴，我要的 10 % 是总的温度 10 % 相对；两倍标准差还是要保证。" 逐轴时，能量占比很小的一个轴（例如冷到几 µK 的弱束缚轴）决定了整次计算的轨迹数。
  - 跟着总温度走的：步长的筛（§2.2，两层之差取总温度的）、记账的步长项、停止与所需轨迹数、账本里 T 的总误差与标记（§4）。各轴的 T 照常给出，只带它自己的统计误差，不计入任何目标。
  - 经典区 k_BT_a ≥ 4ħω_a 只作报告（逐时刻、逐轴的 `classical`），不参与求解的任何决定。
- 轨迹数上限 2¹⁴：到了照常返回，状态为 partial。

## 4 账本（定义：`ledger`）

- 每个输出的总误差 E² = A² + b² + S²：
  - A：模型误差，即各单元的实测误差，加模型的可达范围（§1.8）留在外面的那部分初始系综：范围的水平按谐振阱的分位数留出份额 s，真实的阱留在外面多少由初始系综密度的求积给出（§1.8，不抽样）——布居上是范围之外的原子份额，T 上是它们占的动能份额，各自加上求积最后两级之差；与本次实际跑了多少条无关。账本里各列一条；
  - b：步长项，即试探的两层之差在全程上的方均根里读清的部分 c（§2.2；没看到变化时为 0）；对显示量取各显示行与损失中最大的；试探读完之前（scout、试探途中的结果）按步长份额 s·ε 记；检查以"看不见"结束时（§2.2）记它没有排除的上限，并标记。它是检查的结果，不是界：检查的分辨率写在方法说明里，不进总误差；
  - S：统计误差，jackknife 的区间 t·SE（§3）。对显示量（各显示行与损失）它不小于零计数的 Wilson 远端 z²/(N + z²)，N 是本次已跑的轨迹数：N 条轨迹都没有出现的事件（一次损失、一个没到过的态），jackknife 读不出它的离散。
  - A 里范围之外的份额与 S 的这个下限是两笔不同的误差，不重复：前者是模型判定范围之外的系综份额（求积），后者是有限样本对零计数的统计（本次的 N，§3 的 Wilson 远端）。
- t = 0：布居是请求的初态，没有误差。T(0) 是初始系综的精确矩，由求积算出；它的账目只有 b 一项，取求积最后两级之差（相对）。b 是把离散加密就会消失的那一项：t > 0 时是时间步长的，t = 0 时是求积节点的。
- t > 0：总温度有一份账目（步长项是它自己读数里读清的部分，统计是它自己的区间），只在统计、模型误差、步长误差三者都读得出的时刻才有；三项都按持有份额 1 − L 计权（§0）。
- totals 是先验部分 √(A² + b²) 在各输出上的最大值：布居取所有输出；T 取所有有账目的输出（总温度）——totals 说的是所显示的 T 被近似留下多少误差。flagged 对 T 标的是总温度，只标它有账目的时刻；统计读得出而模型或步长对温度的误差读不出的时刻另标一条。
- 条目逐条列出（label, estimate, action）。action 写明这个数是怎么得到的：单元的误差沿试探轨迹实测，或按可达范围上的界记账（§5.4）；表的误差在试探状态上对照消去本身实测；范围之外的份额按初始系综的密度求积；步长项是两层配对比较里读清的部分。flagged 是总误差超出目标的时刻段；没有原子的时刻不参与显示的最大值。
- 没有"只记说明"的精度结论。

## 5 决策（一条规则；定义：`decide`）

### 5.1 形式
- 每个决策都由四样东西构成：当前一级、更精确的一级、比较的输出、代价。
- 读 = 同一批轨迹（共同随机数）或同一批采样态上的差 d 及其误差。
- 三种结果：
  - 在内：|d| + z·SE ≤ 份额 → 保留；
  - 超出：|d| − z·SE > 份额 → 细化到下一级（步长减半，表的一个轴减半），到了再读；不按实测比值算细化的倍数；
  - 读不清：在工作量界内细化；界用完就标记，把可读的界 |d| + z·SE 计入总误差。
- 一个决策同时看许多个读数时：判"超出"用整族的区间（Šidák：最大的那个噪声读数不该触发细化），判"在内"每个读数各用自己的区间（每一个都得自己落在份额内）。
- 否证是另一种决策：当前一级已经按某个界记账，读数只能推翻它；在内与读不清都让记账的界保持不变。可达范围（§1.8）对试探的 T 也是这样一个否证。
- 花费：pays = 预计节省 − z·SE(节省) > 花费。
- 工作量 = 引擎按算法计数的乘加数（推导，不标定）。

### 5.2 模型单元
- 单元（没有按光分类的单元：没有“远分量”“远拍频”）：
  - 每个驱动一个。按裸能级折叠的：保留 → 按原子处的能级折叠；按原子处能级折叠的：保留 → 显式。它的激发态已被别的驱动变成显式时（两级都一样），它是拉曼对的一条腿：折叠的值（激发态块取双光子距离，§1.2；响应里的自能，§1.4）、门与记账的误差（§1.5）都按这一对，仍是同一个单元；
  - 两个态在一个精确拍频上的耦合（两个基态，或一个显式激发态与另一个激发态）：保留 → 进入生成元，两态并成一个簇，帧差等于拍频；
  - 一个簇按原子处能级的折叠的阶（有四阶的簇，§1.4）：保留 → 该簇的折叠取到四阶。它没有存在门：折叠存在处，它的下一阶也存在；折叠不存在的驱动仍由它自己的单元保留为显式。
  - 载波的缀饰（§1.4）；每对两源光子相干。
- 单元是相对于当前模型的：保留一个单元会重新闭包，簇和帧随之改变，候选单元要在新模型上重新列出（例如光子相干只在两个不同帧频率落到同一簇时才是单元）。保留的单元按值携带到下一个模型。簇内残余拍频恰为零的耦合，保留没有代价，误差为零。
- 存在门（§1.5）不成立的，必须保留。
- 成立时，单元的输出误差 = 沿试探轨迹、在误差产生处实测的小参数，经 §1.5 的推导关系映射到各输出。
- 保留的两条规则，每保留一个就重新闭包、重新试探：
  - 某个输出时刻已经没有统计的余地（模型误差加步长份额占满目标）：保留在这些时刻上误差权重最大的单元，权重 = 持有份额 ×（布居误差/0.05 + T 误差/0.10）；只算有试探状态被读到、且还有原子被俘获的时刻（没读到状态的时刻每个单元都取同一个界，分不出哪个）；
  - 否则按 pays：保留"预计总工作量下降的份额，扣掉它的 z·SE，仍大于 0"且下降最多的单元（保留后要的轨迹更少，但每步更贵，并且要重做试探）。
    - 只给这样的单元建保留后的模型并计价：假设保留后每 µs 不比现在更贵，单是去掉它的误差就付得起重做试探。
    - 不去找"保留比折叠更便宜"的单元：折叠就是为了更便宜；哪里不是，是那个折叠的缺陷，不由这里的选择来补。
    - 实测（PGC3D，100 µs）：原先对 528 个单元逐个建模型计价要 7.4 s，而产品轨迹只要 1 s；计价选中的一个拉曼耦合（预计更便宜）保留后每步实际贵 7.5 倍。
    - 计价读的每 µs 工作量、表的整体读数（§5.4）都是"全程上被俘获状态的平均"：Σ_i Σ_{k∈H_i} f_ik / Σ_i |H_i|，H_i 是第 i 条轨迹在 t > 0 仍被俘获的那些输出（一条轨迹的工作量是它被俘获期间的速率之和；误差记在被俘获的原子上）。轨迹是系综里独立的那一份，它沿时间的各个状态不是，所以每条试探轨迹只读一个状态，代表它自己的整个和（一点求积，权重 |H_i|）：平均 = Σ_i |H_i| f_i / Σ_i |H_i|（`solve::one_each`、`solve::over_the_run`）。读的位置在全程上均匀铺开：第 i 条取 H_i 里位于 u_i = (ρ_i + ½)/n 处的那个输出（n 是轨迹数，即把全程分成 n 等份的各个中点）；G 组里第 g 组的第 m 条的序号是 ρ = m·G + g，所以每一组自己的各条就相隔 1/(组内条数) 铺满全程，各组之间错开 1/n——删一组的 jackknife 不会把运行的某一段整个删掉。位置只由轨迹的编号决定，对每个模型都是同一批状态。t > 0 没有任何输出被俘获的轨迹不给状态。（原来的规则取"各组第一条轨迹、在 1 + 编号 mod (输出数 − 1) 那个输出"：编号相差 8，11 个状态落在相连的 80 个输出里，t > 0 的输出数能整除 8 时落在同一个输出上。）
    - 撤销。计价知道的是保留后每步的工作量，不知道保留后的模型需要多小的步长（计价不读步长）。所以按 pays 保留的单元是试着保留的：下一次尝试里，步长检查要走到的那一档若使保留后的模型比保留前更贵，(1 − 预计节省的份额)·τ_前/τ > 1，就撤销这次保留（`Attempt::Undo`），回到保留前的模型与步长，该折叠的误差照旧实测、记账。按 pays 保留过的单元在本次求解里不再计价，不论是否被撤销（`barred`）。这是 pays 之外的第二个机制，起因是上一条的实测。
- 试探在某个时刻没有被俘获的原子时，单元在该时刻的误差取它的界：布居 1，T 未知。
- 不做"再多保留一个单元"的配对否证。实测（88 对，PGC3D、R2、R3、R5、R1 五个）：配对差的区间是该单元记账误差的 3–30 倍，从未推翻过什么；它只检验记账最大的那个单元，被低估的单元（如 R6 的远失谐拉曼对）它测不到；而它占一次运行的 10–40 %（要另建模型和表）。单元的误差由 §1.5 的推导与试探上的实测负责，被低估的情形由解析参照（§6）来查。

### 5.3 步长
- 按 §2.2：一个全局常数 τ。四样东西（§5.1）：当前一级是 τ；比较的一级是更粗的 2τ（只花一半的步数），按阶 p 推出 τ 自己的误差；比较的输出是全部显示的输出；代价是试探的伴随层（88 条，检查看不见时再加的对各半条）。
- 梯子的起始档由"节点分辨得了格式所采样的东西"定（运行的步长与伴随层各有条件，§2.2）；只有一处定步长：scout 与试探上的检查（§2.2：两层之差在全程上的均方，对步长份额的平方；超出则减半，读不清则在加对与下一档之间取预计工作量较小的）。产品里不再改步长。
- 这是近似收敛的检查（与 QuTiP 里把步长减半看结果变不变是同一件事），不是保证：分辨率以下的步长误差看不到，也不记账。

### 5.4 表
- 四样东西（§5.1）：当前一级是表；更精确的一级是把一个轴的间距减半，极限是该点的消去本身；比较的输出是整体读数映射到的布居与 T（§2.3）；代价是新节点的消去。
- 建表时就按 §2.3 加密到份额内，份额是最大系综的分辨率，所以表不是任何一次运行的限制，它不参与统计与步长之间的分配。
- 不必在状态上读的单元：耦合单元与相干单元的误差被它自己的门在可达范围上界住（`Gate::error_bound`）。把这些界从小到大累加，只要总和不超过一次求解在显示量上可能记的最小统计份额 2.44e-4（`unseen(MOST_TRAJECTORIES)`），这些单元就按界记账、不在状态上读；其余单元照常在侦察与试探的状态上读。依据：读一个单元的代价与它的大小无关，而账本感受不到比这个份额更小的总和。实测：D1 灰色黏团 2130 个单元里 927 个耦合合计只值 1.7e-11，却占读数时间的 96 %；改后侦察加试探的判断从一次计算的 41 % 降到 5 %（PGC3D 25 % → 6 %），模型、步长、轨迹数、账本前五项都不变。按时间抽稀输出不采用：取相邻两次读数的较大者，在灰色黏团上会把 3.3e-3 的误差少记到 2e-3。
- 试探之后，在试探状态上读整体误差，记入模型误差 A（§4），与单元的实测误差并列。读数超出份额的表（固定在焦点的坐标在动，或加密停在了工作量界上）：先把读数最大的轴减半；到工作量界仍超出，就标记并按读数记账。

- 少而物理上不同，用解析或近似解析解，每个几秒到一两分钟。R0–R9 的公式、条件和场景见 contract.md §6：

  - R2 二能级辐射压与反冲；
  - R3 一维多普勒极限；
  - R4 西西弗斯（含 TW1/TW2）；
  - R5 光泵；
  - R6 拉曼 Λ；
  - R7 共振壳穿越；
  - R8 QRT 扩散（只作表征）；
  - R9 损失与逃逸。
- 通过条件（定义与推导：`refs/check.mjs` 文件头；常数都由 z = 2 得出）：
  - 有用户目标的量（布居、组、损失 0.05；总温度 10 %）：|d| − 2σ ≤ 目标（不放宽），σ² = SE² + u²；2σ 超过目标而又没有失败的输出不判（噪声带比目标宽，分辨不了目标大小的误差）。
  - 自报误差盖住实际偏差，按它报告时的置信度比：|d| ≤ B，B² = E² + (2u)²（布居与损失的 E 是 `sampleErrors`；T 的 E 是 2·SE ⊕ 账本总量 × T）。两个检验：(a) 超出 B 的输出数，在有效独立输出数 n/(1 + 2Σρ_k²) 下的二项检验不拒绝 2Φ(−2) = 4.55 % 的超出率（双侧超出事件的协方差不超过 ρ²，所以取平方：振荡的残差与漂移的残差一样算）；(b) 平均偏差不超过平均界 √((模型⊕步长的平均)² + (2·u 的平均)² + (统计区间的平均)²)：所有输出共有的偏差平均不掉，这是 (a) 测不到的（残差为常数时它的有效数是 1）。
  - 没有用户目标的量（阱频、平均位置与速度、单轴 T——引擎不对单轴 T 作任何保证）：只对参照自己的 u 与结果的统计误差，用同样两个检验；单个确定量（阱频）即 |d| ≤ 2u。没有借来的目标，也没有零目标。
  - R4 标度律 T(4I) − 3T(2I) + 2T(I) = 0 只检验稳态 T 对光强是带正斜率的仿射函数（|D| ≤ 2√(SE² + u²)，且 T(4I) − T(I) 分辨得出），不检验斜率、截距与 T 本身。点粒子模型在这些场景里 T 偏低（Ehrenfest 平均力丢掉一阶的无迹部分），由工具参照 R4D_TW2 报告（只报告）；同一分解下系综平均力是精确的，由 R4D_FORCE 判定（`refs/r4d.mjs`）。
- 旧真值表只作回归。锚点：RETRO、F5、R5051、R5031、SHALLOW、F10、CONTROL、R5038；布居与损失另有 R5033、R5066、R5040、R5004。k_BT < 4ħω 的 T 不作物理参照。

## 8 已知限制（照实写给用户）
- **点粒子（Ehrenfest）假设：亚多普勒冷却的温度偏低。这是模型自身的缺陷，不是数值误差，不进误差预算（用户 2026-11-11 定）。**
  - 是什么：一条轨迹是一个点（r, κ）带一个内态 ψ，质心按当前内态上的平均力 ⟨F̂⟩ 运动。精确的半经典理论里内态的各分量各受各的力，在动量上彼此分开，再经光泵与飞行反过来影响受力；点粒子带不了这个关联（缺的一项是 ½(|χ⟩⟨ψ| + |ψ⟩⟨χ|)，χ = (F̂ − ⟨F̂⟩)ψ）。平均力不受影响——摩擦是精确的（参考 R4D_FORCE）；受影响的是力的慢关联，也就是温度。
  - 何时为零：跳跃后的态是力的本征态时（多普勒冷却、反冲、驻波中的闭合跃迁：R2、R3、R10）。偏振梯度里基态带相干的冷却（F = 2 → 3 的 lin⊥lin、σ⁺σ⁻、灰色黏团）都有。
  - 多大（实测，同一模型的全量子参考对真实引擎）：
    - 光镊紧束缚轴上的 lin⊥lin，一维：−2 %（100 µs）、−9 %（500 µs）、−15 %（1 ms）（参考 R4D_TW2）；R4_LIN 场景一维 −18 % 至 −27 %。
    - 一维自由空间，−6Γ：lin⊥lin 每束 3–12 mW/cm² 时低 11–21 %，48 mW/cm² 时只有真值的 0.44；σ⁺σ⁻ 在 6–12 mW/cm² 时只有真值的 1/4 到 1/3，48 mW/cm² 时 0.42；3 mW/cm² 时真值是两群原子（核心 10.8 µK，一成很热），引擎的核心是 2.5 µK。σ⁺σ⁻ 的差距里混着半经典理论自身收敛慢的部分，没有分开。
    - 三维六束光：没有可用的量子参考，偏差未知；只能由实验数据判定。
  - 为什么不修：点粒子轨迹带不了这项关联；带上一阶矩的闭合（M、M+N）线性不稳定；既精确又为正的做法是在紧束缚轴上给每条轨迹一个波函数（一维代价 ×7.5，三维每量子化一个轴再 ×64–128），超出这个引擎的定位。推导与数值在 `motion3d_status/rewrite/diffusion.status.md`、`mscheme.status.md`。
  - 三维光镊里两个简并的紧束缚轴经阱的非谐势交换能量是模型内真实的物理（引擎与经典二维运动一致），拿三维结果去比一维参考不是有效的检验。
  - 经典区 k_BT_a ≥ 4ħω_a 只作报告，不参与任何决定；同一模型的精确半经典解在 4ħω 处与全量子只差 1.4 %，阱的量子化不是这里的主要限制。
- 傍轴近似，不含纵向场；所有光束共焦于原点。
- 同频光束相干，相位取请求的值。
- 原子冷到被局域在近共振光的晶格格点里时，经典区判据只反映光镊尺度的量子化，不反映格点的。

## 9 接口契约（详见 contract.md）
- 请求：native JSONL 一行（options、model、motion 块）。只收有限轨迹请求；`device` 照收，一律在 CPU 上算，结果报 `device:"cpu"`，并附 deviceNote"GPU 计算尚未提供：本次在 CPU 上计算"。
- 请求的字段：
  - motion 块的每个字段都必需（契约的 `MotionModel`）。引擎不读的字段只检查存在、不解析内容：`fieldVectorG`、每束光的 `intensityMWcm2` 与 `outsideShift`（它们已经在 H0、耦合与外层形式里）；
  - 初始密度矩阵 `initialReal`/`initialImag` 必需，不读 `initialIndex`；
  - 模型基里基态排在最前：第 s 个态是基态，当且仅当 s < 8。请求校验一次，此后一律按下标。
- 拒绝（返回错误，界面显示"运动计算失败：…"）。contract.md §2.4 列出的之外，引擎还拒绝下面四种；消息是中文，界面原样显示：
  - 初态在激发态上有布居（超出密度矩阵自身的舍入 γ₃₂）：初始系综是各基态分量在自己的准备阱里的原子（§2.5），激发态的运动没有准备阱可言；
  - 阱光（与光镊同频的全部光束，§1.3）里有平面波：平面波的势在远处不降为零，被俘获原子的初始系综无从定义；
  - 阱光对某个初态分量的势的包络界不为正：这个分量没有被俘获的原子（"光镊不约束原子"）。
  - 每条轨迹至多 2²⁴ 步之内没有可用的步长（§2.2 起始档）。
- native 的 `gpu` 操作立刻回答同一句错误，不让界面卡在编译窗口。
- 结果：
  - 键集合固定；第 0 行等于初态；`requestedTolerance` = 0.05；`estimatedMaximumError` = max(`sampleErrors`)；
  - 部分结果不扣留；每批一个检查点，第一个在试探之后。
- 公开面：`Request`、`solve(&Request, &mut checkpoint) -> Result<Solution, String>`、`Solution`、账本类型、`POPULATION_TARGET`。

## 10 模块（每个量的唯一定义处）

| 模块 | 内容 |
|---|---|
| `units` | 常数与推导值（目标、阶、z、份额 s、物理常数） |
| `linalg` | 复数、小稠密矩阵、LU、厄米与一般本征、指数（算到舍入） |
| `special` | 不完全 Γ 函数（级数与连分式）；高斯–勒让德的节点与权 |
| `random` | Philox 与流 |
| `request` | 契约的请求类型与校验 |
| `field` | 光束振幅及其解析导数、每频率的相干场与它张成的基、坐标图、区域（光强判据） |
| `model` | 各频率的常数形式（按裸能级的折叠）、势 V_L、阱心与解析 Hessian、reach；单元、驱动的三级、存在门（一条规则）、簇、帧、按原子处能级的消去（RS、缀饰、一阶多普勒）、唯一的生成元组装（H、G、跳跃算符）、消去的表（坐标、轴、加密、整体读数）、读出、危险率、光子、吸收的光每单位时间给动量的两个矩 |
| `table` | 每轴三次表（通用插值、轴的误差读、间距减半） |
| `spectral` | 步中点生成元的相互作用绘景：本征分解、快对的跟随、慢对的两跳、步内任意时刻的态；病态处的 CF4 |
| `step` | 一步（A、B、参考、冲量）、内态传播的求积、步内路径、跳跃根与跳跃 |
| `adapt` | 常数步长的推进（步、步内读数、跳跃时刻、布朗路径） |
| `ensemble` | 初始系综 |
| `estimate` | 输出、估计量、jackknife、Student t、Wilson；步长误差：两层系综的成对差（`between`） |
| `decide` | 读、三种结果、pays、工作量计数 |
| `ledger` | 账本 |
| `solve` | 流水线：请求 → 范围与模型 → 试探（两层） → 决策 → 两层的批次（停、续、减半步长） → 检查点 → 结果 |
