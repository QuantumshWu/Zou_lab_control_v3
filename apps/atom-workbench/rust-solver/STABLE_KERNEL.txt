Atom Workbench stable kernel source staging

The numerical base is the exact 40-file v23 source snapshot for native binary
56a26af78dae3d0cbc32b330d0082f3a75443b4cf07472bc5ca447f024c483f6.
All 40 original hashes were verified before any overlay.

Only these overlays are included:
- Static native LP64 OpenBLAS/SuperLU ABI selection; dynamic loader remains available.
- A public entry for the same-source embedded worker and its build manifest.
- Default output samples=200, including Options::default.
- The validated exact declared-MHz period clock, with no phase snapping.
- Append-only projected-operator reuse and direct transpose-left GEMM.
- Enable the existing complete structured outer A*Q product in desktop defaults.

The clock source matches the six-test v24 validation snapshot and its native
population/F-group comparison with the frozen reference (below7.4e-13).
Static ABI files come from the successfully linked native platform candidate,
but this exact stable tree still requires a fresh build and targeted validation.

V24 research routes (phase lifting, finite Magnus/Strang, shifted-core/star,
mean-shift reuse, axis caps, refinement diagnostics, modified short-time shift
and automatic finite-only routing) are NOT included. Other existing v23
diagnostic switches are unchanged. Only the two computation-reuse switches
listed above are newly enabled in shipping desktop defaults.

Eight literal compile-time test fixtures are present (535736 bytes total).
Normal compilation and production numerical paths do not require Python or
external research artifacts. Some original v23 ignored performance-audit tests
still read/write historical artifacts/v4 datasets; those optional audits were
not copied, run, or presented as fresh-checkout regression tests. Static linking
inputs and the embedded worker build script come from the desktop build project;
the dynamic development worker still needs its selected numerical DLLs.

The original restoration performed source/hash/fixture auditing only.
The 2026-10-24 projection overlay passed three targeted tests and paired
research-worker checks: beat100-long 4.067 -> 3.799 s (population difference
4.73e-11), user-long 3.020 -> 2.776 s (5.77e-9); means were unchanged.
A reverse-order repeat without profiling measured beat100 off/on
4.269/3.957 s and user-long 2.378/2.518 s. The latter reversed direction,
so overall timings are variable; no general or two-case speedup is claimed.
The short full32 QuTiP comparison remained 2.54e-6. In the long two-axis K1
stage, A*Q took 3.163 -> 0.463 s and Gram projection 0.964 -> 0.103 s.
These are measured cases/stages, not a general performance guarantee. The
complete two-axis 20 us request still timed out at 25 s. This primary source
transplant awaits root-coordinated build and verification; it imports no
GCRO, CVODE, Filon, unitary-kick or other unvalidated research solver.
